### Phase 2 — B20 Reject-Until-Target (2일)

```cpp
// B20_Ble_0415.h
enum EN_B20_AdvMode_t : uint8_t {
    EN_B20_ADV_IDLE   = 0,
    EN_B20_ADV_CYCLE  = 1,   // 기존 whitelist 대체
    EN_B20_ADV_TARGET = 2,   // 신규 reject-until-target
};
volatile EN_B20_AdvMode_t _advMode = EN_B20_ADV_IDLE;
volatile uint8_t  _targetPeerIdx = 0xFF;
volatile uint32_t _advModeStartMs = 0;
volatile uint32_t _advModeTimeoutMs = 10000;

struct ST_PeerKindCache_t {
    uint8_t       count;
    uint8_t       kinds[3];
    NimBLEAddress addrs[3];
};
ST_PeerKindCache_t _peerKindCache = {};
```

핵심 로직:

1. selectHostIdx(): 기존 peer가 target이면 no-op, 아니면 강제 disconnect + 500ms settle + 재광고
2. _peerKindCache 사전 채움 (파일 I/O 1회)
3. onConnect 콜백: TARGET 모드 시 캐시 비교 → 비대상이면 disconnect(handle, 0x16)
4. tick(): 타임아웃 10초 → IDLE + E10에 TIMEOUT 통지
5. isSelecting() 게이트 → sensorTask sleep 조건에 !_ble.isSelecting() 추가
