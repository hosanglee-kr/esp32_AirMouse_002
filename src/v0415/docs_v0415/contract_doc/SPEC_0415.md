이 프로젝트를 수정하기 전 반드시 알아야 할 12가지:

1. **모듈 약어**: `B20`(BLE), `C10`(Config), `C20`(Action), `D10`(Logger), `E10`(AirMouse), `HW_DEF`(핀 SSOT), `L10`(LED), `M10`(모션엔진), `M20`(BiasTracker), `M30`(제스처), `P20`(전원), `W10`(웹서버). 접두사가 파일/클래스/심볼에 그대로 반영. **v0415: A40(공용 유틸) 삭제**.

2. **명명 규칙**: 전역 상수 `G_`, 전역 변수 `g_`, 클래스 `CL_`, struct `ST_`, enum `EN_`, private `_`접두사, 로컬 `v_`, 파라미터 `p_`. **위반 시 리뷰 반려.**

3. **ArduinoJson v7 정책**: `JsonDocument` 단일 타입만. `containsKey`·`createNestedArray/Object` **금지**. `doc["a"]["b"].to<JsonObject>()` 패턴 사용.

4. **E10은 7파일 분할**: `.h` + `Core/Hid/Motion/Diag/Task/Action_0415.cpp`.

5. **태스크 & 상태 소유권**: sensorTask(Core 1)와 commTask(Core 0)가 큐로 통신. **웹 태스크는 HID 직접 접근 금지**. **Special 액션은 sensorTask 단독 실행**.

6. **다중 프로파일 & 슬롯 리졸버**: 최대 5개 독립 프로파일(0~4). 각 프로파일은 27개 고정 트리거(버튼 15, Flick 4, Linear 4, Tilt 4). `_resolveSlot(mode, trigIdx)`에서 Global 기본값 + Mode별 Override(M1/M2/M3) 2단 리졸빙.

7. **매크로 시퀀서 (8×8)**: 프로파일당 최대 8개 매크로, 매크로당 최대 8 step. `EN_C20_ACT_MACRO (10)`. **`_macroAbortToken` 카운터 기반 취소**, `_startMacro`(스냅샷) + `_tickMacro`(상태머신). **v0415: `_macroState` lock 하 원자화, active 마지막 write**.

8. **4대 필수 슬롯 잠금 (🔒)**: S1(Top L Click), S5(Top M Hold), S12(Side C Double), S13(Side C 2s Hold)은 브릭 방지를 위해 서버/웹 양측에서 수정 원천 차단.

9. **Action Registry**: 슬롯 값은 `{k, h, p16, p32}` 4-tuple. `k`=kind, `h`=holdMode.

10. **프론트엔드 8-모듈 구조 & i18n 표준화**: `_0415` 파일명 규칙 준수. `am_base` → `am_i18n` → `am_offline` → `am_profile` → `am_macro` → `am_config` → `am_status` → `am_remote` → `app_0415_0001` 순 로드. KO/EN 371개 키 1:1 도메인 표준어 체계.

11. **[v0415] Motion Advanced 파이프라인 (10단계)**: `NaN Guard → BiasTracker → [M10: Adaptive EMA] → [M10: Zero Snap + Sigmoid] → [E10: DPI + Accel] → [E10: Front Hold] → [E10: Move Gate] → [E10: Precision] → [E10: Snap-to-Axis] → [E10: Click-Freeze]`. **Click-Freeze는 HID 전송 직전 최종 게이트**. **M10 Click-Lock 삭제** (Click-Freeze가 대체).

12. **[v0415] 전원/버튼/Consumer 라이프사이클**:
    - **P20 Wake Mask**: `buildWakeMaskNormal()` (MPU+6버튼) / `buildWakeMaskSafe()` (Side C 단독) / `buildWakeMaskButtons()` (6버튼, Deep). Safe/Pairing → Safe 마스크.
    - **LED thread-safety**: L10 Recursive Mutex (외부 태스크 상태 변경 안전).
    - **C20 버튼**: 비대칭 디바운스 (Press 32ms / Release 16ms), 2-stage 시간+틱 판정, 16ms 미만 글리치 폐기.
    - **Consumer Mask**: **Descriptor SSOT** (24-bit HID Report Descriptor). `POWER/CH_UP/CH_DOWN/TV_INPUT`은 Descriptor 미지원 → NONE. Power는 Keyboard Page 0x66.
    - **스키마 411**: `_migrateProfileV410ToV411` 자동 변환.

## 🎯 프로젝트 개요

ESP32-S3-Zero + MPU6050 기반 **자이로 전용 공간 포인팅 에어마우스**. BLE HID Composite로 호스트(PC/macOS/Linux/Android TV/iOS)에 연결되며, 웹 UI로 실시간 커스터마이징을 제공.

### 핵심 특징

- **다중 프로파일 시스템**: 최대 5개 독립 프로파일(작업/게임/발표/미디어 등) 지원, 인덱스 기반 원자적 스위칭
- **Global + Override 2단 슬롯 매트릭스**: 27개 고정 트리거 대상 Global 공통 기본값 + Mode 1~3(PC/PPT/TV) 오버라이드 마스크
- **8×8 매크로 라이브러리**: 최대 8개 매크로, 각 8단계(키/마우스/소비자키 + 0~2000ms 딜레이), 비동기 Live Test 지원
- **4대 필수 기능 잠금 🔒**: 좌클릭/포인팅게이트/모드순환/BLE페어링 수정 차단으로 브릭 원천 방지
- **3-Mode 시스템**: PC / Presentation / Smart TV
- **자이로 전용**: 상보 필터 + 시그모이드 가속 + **Adaptive Variable EMA** + Zero Snap
- **제스처 3계층**: Flick (P2P) / Linear (임펄스) / Tilt Hold (Mode 3 전용)
- **Front Hold 스크롤**: Side F 누름 중 커서 감쇠 + 수직 휠 + 수평 팬
- **Action Registry**: ~40종 액션 + 매크로 시퀀스, 사용자 자유 배정
- **Zero-rate Bias Tracking**: 드리프트 자동 흡수 + Fast Recalibrate (Wake 후)
- **SafeBoot / OTA Guard**: 브릭 방지 (SafeMode method-aware 게이트)
- **WS2812 LED**: Mode 색상 / Flash / Blink / Fadeout / Fadein / Suspend & Resume (**v0415: Recursive Mutex 보호**)
- **전원 관리 (P20)**: Light-sleep (Mode별/BLE/Pairing 타임아웃) + Deep-sleep (600s) + MPU6050 WoM(800mg) 및 버튼 wake, **v0415 Safe/Pairing Wake Mask 분기**
- **버튼 정밀 디바운스 (C20)**: 비대칭 누름(32ms)/뗌(16ms) 디바운스, 2-Stage 하이브리드(시간+틱) 판정, 16ms 미만 초단 글리치 필터링
- **Multi-Host**: 최대 3 peer bond, disconnect-only 재연결
- **Atomic Config (Schema 411)**: `/json/profiles/` 디렉토리 기반 원자적 IO
- **AP Fallback**: STA 실패 시 자동 AP (브릭 방지)
- **Consumer Mask Descriptor 정합**: 24-bit HID Report Descriptor가 SSOT. v410 프로파일 자동 마이그레이션

### main.cpp 부팅 시퀀스

```cpp
void setup() {
    // 1) D10 로깅 초기화
    CL_D10_Logger::begin(Serial);
    CL_D10_Logger::setLevel(EN_D10_LOG_INFO);

    // 2) C10 매니저 초기화
    g_cfg.begin(false);

    // 3) Boot-time Factory Reset (Side C 6초 hold)
    if (_holdAtBoot(HW_DEF::PIN_BTN_SIDE_C, 6000)) {
        (void)g_cfg.factoryReset(true);
        ESP.restart();
    }

    // 4) SafeMode 스냅샷
    const bool v_safe = g_cfg.isSafeMode();

    // 5) E10 초기화
    g_e10.begin(&g_cfg);
    if (v_safe) g_e10.setSafeMode(true);

    // 6) W10-E10 브릿지 바인딩 (함수 포인터 테이블)
    //    v0415: setPptMode 콜백 삭제
    g_w10E10If.ctx = (void*)&g_e10;
    // ... 20개 콜백 등록 (setPptMode 제외)

    // 7) W10 웹 서버 시작
    g_w10.begin(&g_cfg, &g_w10E10If);
}

void loop() {
    if (!g_bootOkDone && g_cfg.bootMarkOkIfGracePassed(8500)) {
        g_bootOkDone = true;
    }
    g_e10.tickConfigSave();
    delay(200);
}
```

- **HW_Def_0415.h**: GPIO 핀 SSOT (HW_DEF 네임스페이스)

### Mutex 정책

- **E10 `_mutex`**: Recursive Mutex. 이유: `setSafeMode`/`setOtaGuard`가 락 보유 중 `_pushErr` 재진입.
- **L10 `_mutex` (v0415)**: Recursive Mutex. 이유: `Adafruit_NeoPixel::show()`의 RMT semaphore take → portMUX critical section 불가.
- `_lock()` / `_unlock()`: RAII 아님. 모든 경로에서 짝 맞춤.
- `_qFrame` overwrite: 무조건 성공(size=1).
- `_qHidCmd` / `_qActionExec` enqueue: `timeout=0`. 웹 태스크 블로킹 금지.

### 태스크 간 Special 액션 라우팅

**핵심 규칙:** Special 액션(`EN_C20_ACT_SPECIAL`)은 **sensorTask에서만 실행**.

```
_handleSlotButton / _handleGesture
  ├─ kind == SPECIAL → _handleSpecial() 직접 호출 (sensorTask 컨텍스트)
  └─ kind != SPECIAL → _sanitizeMomentarySlot() → _enqueueAction() → commTask
```

`CL_C20_ActionExec::exec()`의 `EN_C20_ACT_SPECIAL` case는 안전망으로 무시(drop).

### 매크로 실행 (비동기 상태머신)

```
commTask 큐 드레인
  ├─ MACRO kind → _startMacro(p_idx)  ← _lock 하 스냅샷 + state 초기화 (active 마지막 write)
  └─ 기타       → _actExec.exec()     ← 즉시 실행

commTask 매 루프 후반
  └─ _tickMacro()  ← delay 경과 시 다음 스텝 실행 (lock 없음, 성능)
```

**취소**: `_macroAbortToken` 카운터. `_lock()` 하 `_macroAbortToken++` + `active=false` (v0415 원자화).

### MPU6050 설정

- Gyro Range: 250°/s
- Accel Range: 2G
- DLPF: 21Hz
- I2C: 400kHz
- INT: open-drain, active-low, latch
- WoM: MOT_THR=25 (800mg), MOT_DUR=4ms, PWR_MGMT_1=0x20 (CYCLE), PWR_MGMT_2=0xC7 (LP_WAKE 5Hz)

### 좌표계 규약 (필수)

| 물리 축 | 사용자 용어 | 용도 |
|---|---|---|
| gx | **Roll** (긴 축) | 커서 Y, Linear U/D, Flick U/D, **Front Hold 수평 팬** |
| gy | **Pitch** (좌우 축) | 휠, Linear L/R, **Front Hold 수직 휠** |
| gz | **Yaw** (수직 축) | 커서 X, Flick L/R |

**상보 필터:**
```cpp

```

### 버튼 디스패처 (C20)

#### 설정 구조체 (`ST_C10_ButtonConfig_t`)

| 필드 | 기본값 | 검증 범위 | 설명 |
|---|---|---|---|
| `debounce_press_ms` | 32 | 8~100 (8ms 배수) | DOWN 디바운스 (Press ≥ Release 강제) |
| `debounce_release_ms` | 16 | 8~100 (8ms 배수) | UP 디바운스 |
| `long_delay_ms` | 800 | 300~2000 | Long press 판정 임계 |
| `double_delay_ms` | 320 | 150~800 | Double click 최대 윈도우 |
| `hold_2s_ms` | 2000 | 1000~5000 | Hold 2s (Side C Pairing) |
| `hold_3s_ms` | 3000 | 2000~8000 | Hold 3s (Side C Host Cycle) |
| `min_click_ms` | 16 | 0~100 (8ms 배수) | 초단 클릭 필터 (DISCARD) |
| `debounce_min_ticks` | 3 | 1~10 | 2-Stage 하이브리드 카운터 |

#### 핵심 알고리즘

1. **비대칭 디바운스**: Press 32ms (접촉 안정화) / Release 16ms (지연 최소화). `validateE10`에서 `press ≥ release` 강제.
2. **2-Stage 하이브리드**: `(now - lastRawChangeMs) >= debounce_ms` AND `stableCount >= debounce_min_ticks`.
3. **최초 접점 시점 보존 (`rawDownMs`)**: 최초 누름 에지 시각 고정.
4. **초단 클릭 DISCARD**: `heldMs < min_click_ms` 시 CLICK 대기 진입 취소.
5. **동적 타이밍 반영**: `_btnDisp.setTimings()` (**v0415: 8-param 단일, 5-param 삭제**).

## 🎬 Action Registry & 매크로 라이브러리

### Action Kind

| Kind | 이름 | 파라미터 |
|:---:|---|---|
| 0 | `NONE` | – |
| 1 | `MOUSE_CLICK` | `p16`: 5버튼 mask |
| 2 | `MOUSE_HOLD` | `p16`: 5버튼 mask |
| 3 | `MOUSE_WHEEL` | `p16`: `(axis << 8) \| dir` |
| 4 | `KB_TAP` | `p16`: usage, `p32`: modifier |
| 5 | `KB_COMBO` | `p32`: `mod \| (u1<<8) \| (u2<<16) \| (u3<<24)` |
| 6 | `KB_REPEAT` | `p16`: usage, `p32`: modifier |
| 7 | `CONSUMER_TAP` | `p32`: 24-bit mask |
| 8 | `CONSUMER_REPEAT` | `p32`: 24-bit mask |
| 9 | `SPECIAL` | `p16`: Special ID (sensorTask 단독) |
| 10 | `MACRO` | `p32`: 매크로 인덱스 (0~7) |

### 매크로 시퀀서 규칙 (8×8)

- 프로파일당 최대 8개 매크로, 매크로당 최대 8개 Step
- 각 Step: `{k, h, p16, p32}` + `d` (0~2000ms delay)
- 중첩 방지: Step 내 `SPECIAL` / `MACRO` 사용 불가
- **안전 취소**: `_macroAbortToken` 카운터, `_lock()` 하 원자화 (v0415)
- **대체(Replace)**: 실행 중 `_startMacro(newIdx)` 시 `WARN` 로그 후 조용히 대체
- **비동기 실행**: `_startMacro`(스냅샷) + `_tickMacro`(commTask 매 루프). step 실행만 ~28ms 블로킹.

### Special Action

| 값 | 이름 | 처리 |
|---|---|---|
| 0 | NONE | – |
| 1 | GYRO_RECALIB | `requestGyroCalibration()` |
| 2 | **SLEEP_NOW** | **v0415: LED suspend → sleepNow(now, safeOrPair) → LED resume → Fast Recalib** |
| 3 | MODE_CYCLE | `_setActiveMode(next)` |
| 4 | PAIRING | `_ble.enterPairing(30000)` + LED blink |
| 5 | HOST_CYCLE | `_ble.exitPairing()` + `cycleActivePeer()` + `reconnectToActivePeer(10000)` |

## 🛡️ SafeBoot / OTA Guard

### Boot State (`/json/boot_state_0415.json`)

```json
{
  "safe_mode": false,
  "fail_count": 0,
  "pending": false,
  "boot_ms": 0,
  "last_reset_reason": 0
```

### 절차
1. `begin()` → boot state 로드
