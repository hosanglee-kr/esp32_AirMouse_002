## 📖 이 설명서 사용법

이 설명서는 처음 사용하는 분부터 오래 쓰신 분까지 모두를 위한 안내입니다.

- **처음 쓰시는 분**: 1장(30초 요약) → 3장(기본 연결) → 5장(PC 모드) 순서로 보세요.
- **더 잘 쓰고 싶은 분**: 11장(웹 설정 화면)부터 보시면 됩니다.
- **문제가 생겼을 때**: 16장(자주 묻는 문제)을 참고하세요.
- **핵심만 알고 싶은 분**: 17장(핵심 조작 요약표)을 책상 옆에 붙여두세요.

## 1. 30초 요약 (처음 사용자용)

1. **전원 켜기** — 측면 스위치 ON → 파란색 불빛이 켜집니다 (PC 모드)
2. **기기 연결** — PC나 스마트폰 블루투스 목록에서 "Elite AirMouse S3" 선택
3. **화살표 움직이기** — 윗면 가운데 버튼(Top M)을 누른 채 공중에서 손목을 움직입니다
4. **좌클릭 / 드래그** — 윗면 왼쪽 버튼(Top L)을 누르면 클릭, 누른 채 움직이면 드래그
5. **우클릭** — 윗면 오른쪽 버튼(Top R) 누름
6. **모드 변경** — 측면 가운데 버튼(Side C)을 연속 두 번 누름 (PC → 발표 → TV 순환)
7. **스크롤 / 좌우 이동** — 측면 앞쪽 버튼(Side F)을 누른 채 앞뒤/좌우로 기울임
8. **상세 설정** — WiFi에서 "EliteAirMouse" 접속 → 인터넷 주소창에 `192.168.4.1`

## 2. 제품 소개

### 2.1 이 제품은 무엇인가요?

Elite AirMouse S3는 **공중에서 손목을 움직여 컴퓨터나 TV를 조작하는 무선 마우스**입니다. 책상 위에서 밀지 않고, 손에 쥔 채로 팔을 움직이면 화면의 화살표가 따라 움직입니다.

### 2.2 어떤 기능이 있나요?

| 기능 | 설명 |
|---|---|
| **3가지 모드** | PC 마우스 / 프레젠테이션 / 스마트 TV |
| **다중 프로필** | 최대 5개의 맞춤 설정 저장 (예: 사무용, 게임용, 강의용) |
| **매크로** | 버튼 하나로 여러 키를 자동 실행 |
| **다중 기기** | 최대 3대의 컴퓨터/TV를 등록하고 즉시 전환 |
| **웹 설정** | 스마트폰이나 PC 브라우저에서 모든 설정 변경 |
| **자동 절전** | 안 쓰면 자동으로 잠들고, 흔들면 깨어남 |
| **정밀 보정** | 클릭할 때 화살표가 튀지 않게 자동으로 잡아줌 |

### 2.3 안전한 충전과 보관

- **충전**: USB-C 케이블 (5V 충전기)
- **주의**: 물기, 낙하 주의 (내부에 정밀 센서 있음)

## 3. 구성품 및 처음 사용하기

### 3.1 상자 안에 들어있는 것

- 본체 1개
- USB-C 케이블 1개 (충전 + 소프트웨어 업데이트 겸용)
- (선택 구매) 손목 스트랩, 파우치

### 3.2 처음 전원 켤 때

1. 측면 또는 하단 스위치를 ON
2. 파란색 불빛이 켜지면 정상 (PC 모드로 대기)
3. 불빛이 안 들어오면 충전이 필요합니다

### 3.3 컴퓨터/스마트폰과 연결하기 (페어링)

**처음 한 번만 하면 됩니다.**

1. 기기의 측면 가운데 버튼(**Side C**)을 **2초간 길게** 누릅니다
2. 파란 불빛이 **1초에 한 번씩 깜빡이기 시작**합니다 (30초 동안 대기)
3. 연결할 기기(PC, 스마트폰, TV)의 블루투스 설정 화면을 엽니다
4. 목록에서 **"Elite AirMouse S3"** 를 찾아 선택
5. 연결이 완료되면 깜빡임이 멈추고 원래 색으로 돌아옵니다

> **30초가 지나도 연결 안 되면?** 자동으로 대기 모드가 꺼집니다. 다시 Side C를 2초간 누르세요.

### 3.4 두 번째, 세 번째 기기 등록하기

최대 **3대까지** 등록할 수 있습니다. 새 컴퓨터를 등록하려면:

1. 위 3.3 과정을 반복합니다
2. 자동으로 다음 빈 자리에 등록됩니다

### 3.5 다른 컴퓨터로 빠르게 전환하기

이미 등록해둔 다른 컴퓨터/TV로 바꾸고 싶을 때:

- **버튼으로 순환**: Side C를 **3초간 길게** 누름 → 다음 기기로 자동 연결
- **웹 화면으로 지정**: 홈 탭의 "호스트 기기 전환" 카드에서 원하는 기기 클릭
- **자동 재연결**: 기기 전원을 켜면 **직전에 쓰던 컴퓨터로 자동 연결 시도** (10초)

> **알아두세요**: 3초가 지나면 2초 시점의 페어링 모드는 자동으로 취소되므로, 실수로 페어링 모드에 들어가도 안전합니다.

## 4. 버튼 이름과 위치

```

┌─────────────┐
[F]│             │
[C]│             │        ← 측면 3개 버튼 (앞/가운데/뒤)
[R]│             │
└─────────────┘

```

| 버튼 이름 | 위치 | 기본 역할 |
|---|---|---|
| **Top L** | 윗면 왼쪽 | 좌클릭 / 드래그 |
| **Top M** | 윗면 가운데 | 커서 이동 스위치 (누르고 있을 때만 화살표 활성) |
| **Top R** | 윗면 오른쪽 | 우클릭 |
| **Side F** | 측면 앞쪽 | 화면 스크롤 / 좌우 이동 |
| **Side C** | 측면 가운데 | 모드 변경 / 페어링 / 기기 전환 |
| **Side R** | 측면 뒤쪽 | 보조 기능 |

## 5. 모드 1: PC 모드 (파란 불빛)

### 5.1 커서 움직이기

- **Top M** 버튼을 누른 상태로 공중에서 손목을 움직입니다
- 버튼에서 손을 떼면 화살표가 **즉시 멈춥니다**
- 이렇게 하면 손을 내려놓을 때 화살표가 저절로 움직이는 오작동이 없습니다

### 5.2 기본 버튼 동작

| 버튼 조작 | 실행되는 동작 |
|---|---|
| Top L 한 번 | 좌클릭 |
| Top L 길게 | 좌클릭 누른 채 유지 (드래그) |
| Top L 두 번 | 더블클릭 |
| Top R 한 번 | 우클릭 (오른쪽 버튼 메뉴) |
| Top R 두 번 | ESC 키 (취소) |
| Top R 길게 | 화면 캡처 (Win + Shift + S) |
| Top M 한 번 | 마우스 휠 클릭 |
| Side F 한 번 | 소리 크게 |
| Side F 길게 | 다음 곡 재생 |
| Side R 한 번 | 소리 작게 |
| Side R 길게 | 이전 곡 재생 |
| Side C 한 번 | 재생 / 일시정지 |

### 5.3 화면 스크롤과 좌우 이동

**Side F** 버튼을 누른 상태에서:

- 기기를 **앞뒤로 기울이면** → 위아래 스크롤
- 기기를 **좌우로 기울이면** → 좌우 화면 이동 (가로 스크롤)

스크롤 중에는 화살표 속도가 평소의 25%로 느려져서 정밀 조작이 가능합니다.

### 5.4 공중 제스처 (손목 휙 돌리기)

- **손목 좌/우로 휙** → 가상 바탕화면 전환
- **손목 위로 휙** → 바탕화면 보기 (모든 창 내리기)
- **손목 아래로 휙** → 실행 중인 창 전환

> 위/아래 제스처는 Top M 버튼에서 손을 뗀 상태에서만 작동합니다.

### 5.5 자동으로 켜지는 정밀 기능

- **클릭 튐 방지**: 클릭할 때 손가락 힘으로 화살표가 살짝 튀는 것을 자동 감지하여 순간적으로 잡아줍니다
- **손떨림 완화**: 정지 상태의 미세한 떨림은 부드럽게 걸러내고, 빠른 움직임은 즉시 반응합니다

별도 설정 없이 자동 작동합니다.

## 6. 모드 2: 발표 모드 (초록 불빛)

발표(프레젠테이션)를 할 때 슬라이드를 넘기고, 레이저 포인터를 켜는 데 최적화된 모드입니다.

### 6.1 모드 진입 방법

- Side C를 **두 번 연속** 누름 → 초록 불빛 + 흰색으로 0.5초 깜빡임

### 6.2 발표 중 버튼 동작

| 버튼 조작 | 실행되는 동작 |
|---|---|
| Top L 한 번 | 다음 슬라이드 |
| Top L 두 번 | 이전 슬라이드 |
| Top L 길게 | 현재 슬라이드부터 쇼 시작 (Shift + F5) |
| Top R 한 번 | 쇼 종료 (ESC) |
| Top R 두 번 | 검은 화면 (B 키) |
| Top R 길게 | 흰 화면 (W 키) |
| Side F 한 번 | 다음 슬라이드 |
| Side R 한 번 | 이전 슬라이드 |
| Side R 길게 | 쇼 종료 (ESC) |

### 6.3 포인터와 레이저

- **Top M 누른 채** → 화살표 이동
- **Top M 한 번** → 레이저 포인터 켜기 (Ctrl + L)
- **Side C 한 번** → 펜 → 레이저 → 일반 화살표 순환

### 6.4 발표 중 제스처

- 손목 좌측으로 휙 → 다음 슬라이드
- 손목 우측으로 휙 → 이전 슬라이드
- 손목 위로 휙 → 검은 화면 (화면 숨김)

### 6.5 자동 수평/수직 정렬 (축 스냅)

발표 자료에 밑줄을 긋거나 도표를 가리킬 때, 손이 살짝 흔들려도 **자동으로 수평/수직**을 유지해줍니다.

- 화살표를 대략 수평으로 움직이면 → 자동으로 수평선 유지
- 대각선으로 방향을 바꾸면 → 자동으로 해제되어 자유 이동
- **발표 모드에서만 작동**합니다 (PC 모드, TV 모드에서는 자동 비활성)

## 7. 모드 3: 스마트 TV 모드 (주황 불빛)

TV 리모컨처럼 사용할 수 있는 모드입니다.

### 7.1 모드 진입 방법

- 발표 모드에서 Side C를 **두 번 연속** 누름 → 주황 불빛

### 7.2 TV 조작 버튼

| 버튼 조작 | 실행되는 동작 |
|---|---|
| Top L 한 번 | 뒤로 가기 |
| Top L 두 번 | 홈 화면 |
| Top L 길게 | 전원 켜기/끄기 (일부 TV만) |
| Top M 한 번 | 확인 (Enter) |
| Top R 한 번 | 홈 화면 |
| Top R 두 번 | 검색 창 열기 |
| Top R 길게 | 전원 끄기 (일부 TV만) |
| Side F 한 번 | 볼륨 크게 |
| Side R 한 번 | 볼륨 작게 |
| Side C 한 번 | 재생 / 일시정지 |
| 제스처 좌/우 | 10초 뒤로 / 10초 앞으로 |
| 제스처 위 | 음소거 켜기/끄기 |

### 7.3 TV 모드에서 안 되는 기능

**TV 전원, 채널 변경, 외부 입력 전환**은 TV 제조사마다 반응이 다릅니다.

| 기능 | 이 기기 지원 여부 | 대안 |
|---|---|---|
| TV 전원 | 일부 TV만 작동 | TV 리모컨 사용 권장 |
| 채널 올리기/내리기 | 지원 안 함 | TV 리모컨 사용 |
| 외부 입력 전환 | 지원 안 함 (검색으로 대체) | TV 리모컨 사용 |

> **왜 안 되나요?** 블루투스 표준에 채널/입력 전환 기능이 정의되어 있지 않기 때문입니다. 이전 버전에서는 억지로 매핑했으나 실제로는 다른 기능(예: 볼륨)으로 오작동했기에 삭제했습니다.

### 7.4 기울여 방향키 조작 (Tilt Hold)

TV 화면 메뉴를 넘길 때 유용한 기능입니다.

1. **Top M에서 손을 뗀 상태**로
2. 기기를 전후좌우로 **15도 이상 기울여** 유지
3. 0.3초 후부터 해당 방향의 방향키가 **초당 3회** 연속 입력됨
4. 기기를 평평하게 세우면 정지

> 이 기능은 **TV 모드 전용**입니다. PC나 발표 중에는 손목이 자연스럽게 기울어지는 상황이 많아 오작동 위험이 있기 때문입니다.

### 7.5 커서가 필요한 앱에서

넷플릭스나 TV 웹브라우저처럼 화살표가 필요한 앱에서는 **Top M을 누르면** 에어마우스 화살표가 즉시 활성화됩니다.

## 8. 모드 전환과 상태 표시등

### 8.1 모드 순환 방법

- Side C를 **두 번 연속** 누름
- 1번 PC → 2번 발표 → 3번 TV → 다시 1번 순서로 순환
- 마지막 사용한 모드는 **자동 저장**되어 재부팅 후에도 그 모드로 시작합니다

### 8.2 불빛(상태 표시등) 의미

| 불빛 색 | 상태 |
|---|---|
| 🔵 파란색 | PC 모드 정상 작동 중 |
| 🟢 초록색 | 발표 모드 정상 작동 중 |
| 🟠 주황색 | TV 모드 정상 작동 중 |
| ⚪ 흰색 (반짝) | 명령이 전송되는 중 |
| 🔴 빨간색 | 오류 / 절전 모드 진입 |
| 💡 파란 불빛 1초 주기 | 새 기기 연결 대기 중 (페어링) |

### 8.3 모드 전환 시 자동 정리

모드를 바꾸면 다음이 자동으로 처리됩니다:

- 진행 중이던 매크로 즉시 취소
- 눌려있던 모든 키와 마우스 버튼 자동 해제 (키가 눌린 채 멈추는 문제 방지)
- 손목 제스처와 버튼 상태 초기화
- 스크롤 상태 초기화
- 페어링 대기 중이었다면 자동 취소
- 진행 중이던 기기 전환 시도 자동 취소

## 9. 여러 대의 컴퓨터/TV 관리하기

### 9.1 기기 등록 (최대 3대)

- Side C를 **2초간** 누름 → 파란 불빛 1초 주기로 깜빡임
- 연결할 기기의 블루투스 목록에서 "Elite AirMouse S3" 선택
- 30초 이내에 연결되지 않으면 자동 종료

### 9.2 다른 기기로 전환하는 4가지 방법

**방법 1 — 버튼으로 순환 (가장 간편)**
- Side C를 **3초간** 누름 → 다음 기기로 자동 연결

**방법 2 — 웹 화면에서 지정**
- 홈 탭의 "호스트 기기 전환" 카드에서 원하는 기기의 `전환` 버튼 클릭

**방법 3 — 버튼에 특수 기능 배정**
- 27개 버튼 슬롯 중 아무 곳에나 다음 기능을 배정:
  - 1번 기기로 바로 전환
  - 2번 기기로 바로 전환
  - 3번 기기로 바로 전환
  - 최근 2대 기기 빠른 맞교환
  - 진행 중인 전환 취소

**방법 4 — 자동 재연결**
- 전원을 켜면 **직전에 쓰던 컴퓨터로 자동 연결** (10초 시도)

### 9.3 전환 중 안전장치

**다른 기기가 먼저 접속하면?**
- 지정한 목표 기기가 아닌 다른 기기가 먼저 연결을 시도하면 **즉시 연결을 끊습니다** (사용자가 지정한 기기만 연결되도록)
- 목표 기기가 10초 안에 연결되지 않으면 **다른 기기로 자동 연결하지 않고** 대기 상태로 돌아갑니다 (빨간 불빛 3회 점멸)

**전환 중에 잠들지 않게**
- 기기 전환 시도 중에는 자동 절전 모드로 들어가지 않습니다 (연결 도중 잠들어 끊기는 문제 방지)

### 9.4 기기에 별명 붙이기

- 웹 화면의 홈 탭에서 각 기기에 **최대 16자 별명** 지정 가능
- 예: "회사 노트북", "집 PC", "거실 TV"
- 색상 태그로 구분 가능
- 별명과 색상은 기기에 저장되어 재부팅 후에도 유지

### 9.5 기기 상태 확인

진단 탭의 "호스트 기기 전환" 도구에서:
- 등록된 기기 목록 (주소, 별명, 색상)
- 현재 연결된 기기
- 전환 진행 상태
- 활성 기기 이름

## 10. 충전과 자동 절전

### 10.1 충전

- 표준 USB-C 단자로 충전 (5V 충전기)
- 완충까지 걸리는 시간은 충전기 성능에 따라 다름

### 10.2 자동 절전 1단계: 라이트 슬립 (가벼운 잠)

**언제 들어가나요?**

| 사용 상황 | 절전 진입까지 대기 시간 |
|---|---|
| PC 모드 | 60초 |
| 발표 모드 | 120초 |
| TV 모드 | 300초 (5분) |
| 블루투스 연결 중 | 300초 |
| 페어링 대기 | 30초 |

**절전에 들어갈 때**
- 빨간 불빛이 약 0.5초 동안 서서히 꺼집니다

**깨어나는 방법**
- 기기를 가볍게 흔들기 (내장 센서가 감지)
- 아무 버튼이나 누르기

**깨어날 때**
- 현재 모드 색 불빛이 약 0.3초 동안 서서히 켜집니다
- 자이로 센서가 0.3초 동안 자동으로 영점을 다시 잡습니다 (커서 쏠림 방지)

### 10.3 자동 절전 2단계: 딥 슬립 (깊은 잠)

**언제 들어가나요?**
- 기본 **10분 (600초)** 동안 아무 조작이 없을 때
- 웹 화면에서 시간을 조절할 수 있습니다 (0 또는 300~7200초)

**절전에 들어갈 때**
- LED가 완전히 꺼집니다
- 센서가 저전력 수면 모드로 전환됩니다 (배터리 절약)

**깨어나는 방법**
- 본체의 아무 버튼이나 누르기

### 10.4 안전 상태에서의 깨어남 제한

일반적인 상황에서는 흔들기/버튼 모두 작동하지만, **안전 모드(SafeBoot)나 페어링 모드**에서는 **측면 가운데(Side C) 버튼만** 반응합니다.

> **왜 제한하나요?** 기기 고장으로 안전 모드에 들어간 상태에서 실수로 다른 버튼이 눌려 예상치 못한 동작을 하는 것을 막기 위함입니다. Side C 버튼은 6초간 누르면 공장 초기화가 되는 응급 복구 버튼이기도 합니다.

### 10.5 절전에 안 들어가는 상황

다음 상황에서는 자동 절전이 작동하지 않습니다:

- 커서 이동 버튼(Top M)을 누르고 있을 때
- 스크롤 버튼(Side F)을 누르고 있을 때
- 매크로가 실행 중일 때
- 안전 모드 또는 업데이트 잠금 중일 때
- **기기 전환을 시도하는 중일 때**

## 11. 웹 화면으로 상세 설정하기

### 11.1 웹 화면 접속 방법

**방법 1: 기기 자체 와이파이로 접속 (권장)**
1. 스마트폰이나 PC의 WiFi 목록에서 **"EliteAirMouse"** 선택
2. 비밀번호: **12345678** 입력
3. 브라우저 주소창에 **`192.168.4.1`** 입력

**방법 2: 공유기를 통한 접속**
1. 기기를 공유기에 연결한 경우 (자세한 방법은 14.6 참고)
2. 브라우저 주소창에 **`elite-airmouse.local`** 입력

### 11.2 웹 화면 좌측 메뉴 (햄버거 ☰ 버튼)

좌측 상단의 ☰ 버튼을 누르면 슬라이드 메뉴가 나타납니다:

| 메뉴 | 하는 일 |
|---|---|
| 🏠 **홈** | 가상 컨트롤러, 기기 전환 카드, 필수 조작 안내 |
| 🎮 **버튼 및 동작 할당** | 27개 버튼/제스처에 원하는 기능 배정 |
| 📜 **매크로 관리** | 자동 연속 동작 만들기 |
| ⚙️ **포인터 및 센서 설정** | 커서 속도, 손떨림 보정, 절전, 버튼 타이밍 |
| 🔧 **진단 및 입력 테스트** | 기기 상태, 문제 해결 도구, 키 테스트 |
| ⬆️ **무선 펌웨어 업데이트** | 새 소프트웨어 설치 |
| 🌙 **테마 전환** | 밝은/어두운 화면 전환 |
| 🌐 **언어 (KO/EN)** | 한국어 ↔ 영어 즉시 전환 |
| 🔄 **새로 고침** | 최신 상태 다시 불러오기 |
| ⚡ **다시 시작** | 기기 재부팅 |
| 🌐 **NET: ONLINE** | 온라인/오프라인 모드 전환 |

### 11.3 프로필 관리 (드로어 상단)

**프로필이란?** 여러분의 모든 설정(버튼 배정, 매크로, 감도 등)을 담는 "설정 뭉치"입니다. 최대 5개까지 만들 수 있습니다.

- **현재 프로필 배지**: 지금 사용 중인 프로필 이름
- **프로필 드롭다운**: 다른 프로필로 즉시 전환
- **+ 새로**: 새 빈 프로필 만들기 (예: '회사용', '집용')
- **✏️ 이름**: 현재 프로필 이름 변경 (15자까지)
- **🗑️ 삭제**: 프로필 삭제 (현재 사용 중인 것은 자동으로 다른 것으로 전환됨)

### 11.4 상단 노란색 알림 띠

**"다시 시작이 필요합니다"** 라는 노란 띠가 뜨면, 설정 변경이 저장되었지만 완전히 적용되려면 재부팅이 필요하다는 뜻입니다.

- `지금 다시 시작` 버튼으로 즉시 재부팅
- × 버튼으로 닫아도, 새로운 변경 사항이 생기면 다시 나타납니다
- **원래 값으로 되돌리면 자동으로 사라집니다**

## 12. 홈 탭 사용하기

홈 탭에서 자주 쓰는 기능을 바로 사용할 수 있습니다.

### 12.1 필수 조작 카드

가장 자주 쓰는 4가지 동작을 요약해서 보여줍니다:
- Side C 더블클릭 = 모드 전환
- Side C 2초 유지 = 페어링 모드
- Side C 3초 유지 = 기기 전환
- Side F 유지 = 스크롤 모드

### 12.2 기기 전환 카드

**"💻 호스트 기기 전환"** 카드에서 여러 컴퓨터/TV를 관리할 수 있습니다.

- **목록**: 등록된 모든 기기 (별명, 색상, 주소)
- **현재 연결된 기기**: 파란색 테두리로 표시
- **전환 대상**: 주황색으로 깜빡임
- **전환 버튼**: 해당 기기로 즉시 전환
- **취소 버튼**: 진행 중인 전환 중단
- **별명 편집**: 카드에서 직접 클릭하여 수정 (16자)
- **자동 새로고침**: 2.5초마다 상태 갱신

### 12.3 가상 컨트롤러 (Virtual Remote)

웹 화면에서 직접 마우스, 발표, TV 기능을 조작할 수 있습니다. 실제 기기를 손에 들지 않아도 됩니다.

**모드 1 (PC)**:
- 방향키 링 + 조이스틱
- 시작 메뉴 / 화면 캡처 / 음소거 / 볼륨

**모드 2 (발표)**:
- 슬라이드 이동 (이전/다음)
- 처음부터(F5) / 현재부터(Shift+F5) / 종료(ESC)
- 레이저 포인터 / 검은 화면 / 흰 화면 / 펜 도구

**모드 3 (TV)**:
- 4방향 탐색 링
- 전원 / 홈 / 뒤로 / 확인 / 검색 / 볼륨 / 재생

**조이스틱 사용법**:
- 중앙 노브를 드래그 → 방향 반복 입력
- **링(원형 배경)의 어느 위치든 드래그 가능**
- 중앙 노브를 살짝 탭 → Enter/OK 한 번 전송

**접기/펼치기**: `접기 ▲` 버튼으로 컨트롤러를 축소 가능

> **PC 넓은 화면에서**: 컨트롤러와 도구 카드가 좌우 2단으로 배치되어 화면을 효율적으로 씁니다.

## 13. 버튼 및 동작 맞춤 할당

### 13.1 슬롯이란?

**슬롯**은 27개의 버튼/제스처 동작에 "이걸 누르면 무슨 일이 일어날지"를 지정하는 자리입니다.

### 13.2 27가지 동작 분류

| 종류 | 개수 | 예시 |
|---|---|---|
| 버튼 조작 | 15개 | Top L 한 번/두 번/길게, Side C 한 번/두 번/2초/3초 등 |
| 공중 제스처 | 4개 | 손목을 좌/우/위/아래로 휙 |
| 선택적 제스처 | 4개 | Top M 누른 채 상하좌우 |
| 기울여 유지 | 4개 | TV 모드 전용, 15도 이상 기울여 유지 |

### 13.3 절대 바꿀 수 없는 4개 동작 🔒

다음 4가지는 기기 오작동 방지를 위해 **잠겨 있어** 변경할 수 없습니다:

| 동작 | 이유 |
|---|---|
| Top L 짧게 누름 | 좌클릭 (기본 마우스 기능) |
| Top M 누르고 있음 | 화살표 이동 스위치 |
| Side C 두 번 연속 | 모드 변경 |
| Side C 2초 길게 | 페어링 모드 |

### 13.4 "기본 공통" vs "모드별 재정의"

화면 상단의 뷰 탭에서 선택합니다:

- **기본 공통**: 모든 모드에 공통 적용
- **모드 1 / 2 / 3**: 특정 모드에서만 다르게 동작

**파란색 [G] 표시** = 기본 공통 설정을 그대로 따름
**주황색 [M] 표시** = 이 모드에서만 다르게 지정함

- **[G] 클릭** → [M]으로 바뀌며 이 모드 전용 설정 생성
- **[M] 다시 클릭** → [G]로 되돌아감

### 13.5 배정할 수 있는 10가지 동작 종류

| 종류 | 설명 |
|---|---|
| **NONE** | 아무 동작 안 함 |
| **MOUSE_CLICK** | 마우스 한 번 클릭 (좌/우/가운데/뒤로/앞으로) |
| **MOUSE_HOLD** | 마우스 버튼 누른 채 유지 (드래그) |
| **MOUSE_WHEEL** | 휠 스크롤 |
| **KB_TAP** | 키보드 한 키 (예: Enter, Esc) |
| **KB_COMBO** | 단축키 조합 (Ctrl+C 등 최대 3개) |
| **KB_REPEAT** | 키 반복 입력 (누르는 동안) |
| **CONSUMER_TAP** | 미디어/리모컨 키 (볼륨, 재생 등) |
| **SPECIAL** | 특수 기기 제어 (아래 10종) |
| **MACRO** | 매크로 실행 |

### 13.6 특수 기기 제어 (SPECIAL) 10가지

| 이름 | 하는 일 |
|---|---|
| GYRO_RECALIB | 자이로 영점 조절 |
| SLEEP_NOW | 지금 즉시 절전 |
| MODE_CYCLE | 모드 순환 (PC→발표→TV) |
| PAIRING | 블루투스 페어링 시작 |
| HOST_CYCLE | 등록 기기 순환 |
| **HOST_SELECT_0** | **1번 기기로 바로 전환** |
| **HOST_SELECT_1** | **2번 기기로 바로 전환** |
| **HOST_SELECT_2** | **3번 기기로 바로 전환** |
| **HOST_TOGGLE** | **최근 2대 기기 빠른 맞교환** |
| **HOST_CANCEL** | **진행 중 기기 전환 취소** |

### 13.7 미디어/리모컨 키 (Consumer) 24가지

재생, 일시정지, 녹음, 빨리감기, 되감기, 다음곡, 이전곡, 정지, 꺼내기, 무작위재생, 반복재생, 재생/일시정지, 음소거, 볼륨올리기, 볼륨내리기, 홈화면, 내컴퓨터, 계산기, 즐겨찾기, 검색창, 페이지중지, 뒤로가기, 미디어선택, 메일

### 13.8 실시간 시험 및 저장

- **Test 버튼**: 저장하기 전에 실제로 어떻게 동작하는지 즉시 시험
- **저장 버튼**: 기기 내부 메모리에 영구 저장 (**반드시 눌러야 함**)

> **자이로 영점 조절이란?** 손을 움직이지 않아도 화살표가 혼자 흐르거나 움직일 때, 평평한 바닥에 기기를 두고 센서의 기준점(0점)을 다시 잡는 작업입니다.

## 14. 매크로 관리 (자동 연속 동작)

### 14.1 매크로란?

**버튼 한 번으로 여러 키를 자동으로 순서대로 실행**하는 기능입니다. 예를 들어 "복사 → 0.1초 대기 → 붙여넣기"를 버튼 하나로 만들 수 있습니다.

### 14.2 만들 수 있는 규모

- 프로필당 최대 **8개 매크로**
- 매크로 1개당 최대 **8단계**
- 각 단계 사이 대기 시간: **0초 ~ 2초** (2000ms)

### 14.3 만드는 순서

1. **+ 새 매크로** 클릭 → 이름 입력 (예: "복사붙여넣기")
2. **+ 단계 추가** 버튼으로 실행할 동작을 순서대로 추가
3. 각 단계 사이에 적당한 대기 시간 입력 (100~500ms 권장)
4. **저장** 버튼
5. 버튼 배정 화면으로 돌아가 원하는 버튼에 이 매크로 배정

### 14.4 실생활 활용 예시

| 만들고 싶은 동작 | 매크로 단계 |
|---|---|
| 작업 관리자 열기 | Ctrl+Shift+ESC |
| 자동 복사 붙여넣기 | Ctrl+C → 0.1초 → Ctrl+V |
| 화면 캡처 후 저장 | Win+Shift+S → 0.5초 → 저장 |
| 화상회의 즉시 끄기 | 마이크 음소거 → 화면 끄기 |

### 14.5 안전장치

매크로 실행 중에:
- **다른 모드로 전환**하거나
- **블루투스 연결이 끊어지면**

누르고 있던 키가 컴퓨터에 계속 눌린 채 남지 않도록 **모든 키를 자동으로 떼어냅니다**.

## 16. 진단 및 문제 해결

### 16.1 시스템 현황 보기

진단 탭에서 다음을 한눈에 확인:
- 가동 시간
- 여유 메모리
- WiFi 상태
- 현재 프로필
- 등록 기기 수 / 활성 기기

### 16.2 기기 건강 상태 카드

- **health_score** (0~1000점):
  - 820 이상 → 정상 (초록)
  - 620~819 → 주의 (주황)
  - 620 미만 → 위험 (빨강)
- 센서 / 블루투스 / 가동시간 / 온도 요약

### 16.3 문제 해결 도구

**포인터 관련**
- **자이로 영점 조절**: 화살표가 저절로 흐를 때 (2초 소요)
- **눌린 키 강제 해제**: 키가 눌린 채 멈췄을 때

**무선 연결 관련**
- **기기 전환**: 다른 컴퓨터/TV로 이동
- **페어링 모드**: 새 기기 등록
- **센서 연결(I2C) 복구**: 센서가 응답하지 않을 때

**시스템 관련**
- **지금 절전 모드**: 즉시 잠자기
- **안전 모드 토글**: 안전 모드 켜고/끄기
- **공장 초기화**: 모든 설정 초기화

**안전 부팅 (SafeBoot)**
- **상태 보기**: 안전 모드 여부, 실패 횟수
- **모드 종료**: 안전 모드 해제 + 재부팅

### 16.4 입력 신호 테스트

키보드 키 또는 미디어 키를 즉시 전송해서 잘 동작하는지 확인합니다:
- KB(키보드) / Consumer(미디어) 선택
- 조합 키 (Ctrl/Shift/Alt/Win)
- 키 코드 입력
- `전송` 버튼

### 16.5 최근 명령 로그

가상 컨트롤러, 도구에서 발생한 모든 명령을 시간순으로 보여줍니다:
- 성공: 초록색
- 실패: 빨간색

### 16.6 기기 전환 상태 조회

진단 탭의 "호스트 기기 전환" 도구에서:
- 등록된 기기 목록 (주소, 별명, 색상)
- 현재 활성 기기
- 전환 진행 상태

### 16.7 무선 업데이트 (OTA)

- 펌웨어 파일(.bin)을 무선으로 전송
- 업데이트 중에는 입력이 자동으로 잠깁니다 (OTA Guard)
- **반드시 충전선을 연결한 상태**에서 진행

## 17. 자주 묻는 문제 (FAQ)

### 화살표가 움직이지 않아요

1. Top M 버튼을 **누른 채로** 움직이고 있는지 확인
2. 컴퓨터의 블루투스 연결 상태 확인 → Side C를 2초간 눌러 재연결
3. 평평한 곳에 두고 웹 화면에서 "자이로 영점 조절" 실행

### 버튼이 계속 눌린 것처럼 멈췄어요

- 문제 해결 도구의 "눌린 키 강제 해제" 버튼 클릭

### 클릭할 때마다 화살표가 튀어요

- Click-Freeze 기능이 기본으로 켜져 있어 자동 억제됩니다
- 그래도 심하면 Config 탭에서 '정지 판단 감도'를 20~25로 높이세요

### 화살표가 손떨림으로 흔들려요

- '포인터 및 센서 설정' 탭에서 **정밀 작업 프리셋** 적용
- 또는 'Alpha Min' 값을 0.03~0.04로 낮춤

### 발표 중 수평선이 흔들려요

- 발표 모드에서는 축 스냅이 기본 ON입니다
- '고정 강도'를 0.6~0.7로 낮추면 부드러워짐
- 전혀 작동 안 하면 → '직선 스냅' 사용 여부와 '적용 모드'에 2번 체크 확인

### 스크롤이 너무 둔하거나 빨라요

- Config 탭에서 '휠 스크롤 감도' 값을 조절

### 손목 제스처가 자주 잘못 발동해요

- Config 탭에서 '휘두르기 감도' 값을 높임 → 더 강하게 휘둘러야 반응

### 안전 모드로 켜져요 (SafeBoot)

- 비정상 종료가 반복되면 자동 진입
- 웹 화면 → 진단 탭 → "안전 부팅 모드 종료" 클릭

### 한 번 누르는데 두 번 눌려요 (더블클릭 오탐)

- 스위치 노후화로 접점이 떨리는 채터링 현상
- Config 탭 → 버튼 타이밍 → '뗌 디바운스'를 30~50ms로, '글리치 필터'를 30~40ms로 조정

### 절전에서 깨어난 직후 화살표가 쏠려요

- 슬립 중 센서 온도 변화로 생기는 자연 현상
- **자동 보정**: 깨어난 후 0.3초간 자동 영점 재수집. 잠시 멈춘 뒤 조작하면 자동 보정됨

### 배터리를 더 오래 쓰고 싶어요

- Config 탭 → 절전 → '딥슬립 대기'를 300초(5분)로 줄임

### 배터리 표시가 "N/A"예요

- 이 기기는 배터리 잔량 측정 회로가 없습니다 (정상)

### 설정을 저장하기 전에 다른 걸 눌렀어요

- 저장 안 한 변경사항이 있으면 경고창이 뜹니다
- **반드시 저장 버튼을 누르세요**

### 프리셋을 적용했더니 이전 설정이 사라졌어요

- 프리셋은 19개 항목 전체를 재설정합니다
- 이전 설정을 지키려면 미리 '백업 내보내기' 하세요

### 다시 시작 알림 띠를 닫았는데 다시 나타나요

- 같은 사유에 대해서만 안 나타납니다
- 새 변경 사항이 생기면 다시 나타남 (정상)

### 조이스틱 중앙 노브가 아닌 주변을 잡아도 되나요?

- 네, 링(원형 배경)의 어느 위치든 드래그 가능
- 중앙 노브를 살짝 탭하면 Enter/OK 입력

### Side C 2초와 3초가 어떻게 달라요?

- **2초**: 페어링 모드 (새 기기 등록)
- **3초**: 다른 등록 기기로 순환
- 3초가 되면 2초 시점 페어링은 자동 취소

### 웹 화면 접속이 안 돼요

- 기기 전원 켤 때 Side C를 6초 이상 눌러 응급 초기화

### 업데이트 후 설정이 바뀐 것 같아요

- 첫 부팅 시 자동으로 새 형식으로 변환됩니다
- TV 전원 슬롯은 "Keyboard Power" 키로, TV 채널 슬롯은 "할당 해제" 됩니다
- 프로필 이름, 매크로, 나머지 슬롯은 그대로 유지

### TV 전원이 안 켜져요

- 일부 TV는 이 기능을 지원하지 않습니다 (기기 오류 아님)
- **TV 리모컨 사용 권장**

### TV 채널 조절이 안 돼요

- 설계상 정상 (블루투스 표준에 없는 기능)
- **TV 리모컨 사용 권장**

### 안전 모드/페어링에서 마우스를 흔들어도 안 깨어나요

- 설계상 정상 (Side C 버튼만 반응)
- 이는 안전 상태에서 예상치 못한 입력을 막기 위함

### 기기 전환 중에 다른 기기가 먼저 연결되면 어떻게 되나요?

- 지정한 기기가 아니면 즉시 연결을 강제 해제합니다
- 목표 기기가 10초 안에 안 오면 다른 기기로 자동 연결하지 않고 대기 (빨간 불빛 3회)

### 기기 전환 실패는 어떻게 알 수 있나요?

- **빨간 불빛 3회 점멸** → 목표 기기 연결 실패
- 홈 탭 카드에서 '전환 중' 표시가 사라짐

### 기기에 별명을 붙일 수 있나요?

- 네, 홈 탭의 기기 카드에서 **최대 16자 별명** 인라인 편집 가능
- 색상 태그도 지정 가능
- 저장된 별명은 재부팅 후에도 유지

### WiFi 설정을 바꿨는데 언제 적용돼요?

- 저장 시 상단 노란 배너 표시
- `지금 다시 시작` 버튼으로 재부팅해야 적용
- 원래 값으로 되돌리면 배너 자동 사라짐

### "휘두르기 감도"를 조정해도 반응이 없었는데 v0415에서 달라졌나요?

- 네, v0415에서 해결되었습니다
- 이전 버전에서는 실제로 사용되지 않는 항목을 편집하고 있었습니다
- v0415부터 실제 동작에 반영됩니다 (UI 라벨은 그대로)
