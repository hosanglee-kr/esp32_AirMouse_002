# 버튼·기능 설계 — 요구사항 및 용어 표준화 사양서

## 1. 물리 자산 명세
- 버튼 구성 (총 6개)
  - Top 면 (3개): Top L, Top M, Top R (전방 배치, 좌→우 순서)
  - Side 면 (3개): Side F, Side C, Side R (좌측면 배치, Front / Center / Rear)
- 물리 자산 목록

| 자산 | 개수 | 물리 위치 |
| :--- | :--- | :--- |
| 버튼 | 6 | Top L/M/R, Side F/C/R |
| IMU | 1 | MPU6050 (자이로 + 가속도) |
| LED | 1 | WS2812 RGB |

## 2. 파지 자세 정의 및 좌표계 불변식
- 자세 A (데스크 마우스 모드)
  - Top 면: UP (상향)
  - Side 면: LEFT (좌측 수평)
  - 파지 기준: 손등 상향, 손바닥 하향
- 자세 B (에어 프리젠터 모드)
  - Top 면: RIGHT (우측 수평)
  - Side 면: UP (상향)
  - 파지 기준: 롤 축(Long Axis) 기준 90° 시계방향 회전, 손등 우향, 손바닥 좌향
- 두 자세의 관계

| 축 | 자세 A | 자세 B |
| :--- | :--- | :--- |
| top면 방향 | UP | RIGHT |
| 좌측면 방향 | LEFT (수평) | UP |
| 회전 | – | 마우스 long axis 기준 90° |

- 핵심 불변식
  - 두 자세에서 손가락-버튼 상대 관계 불변 (엄지 = 좌측면, 검지·중지 = top면)

## 3. 손가락-버튼 접촉 (자세 무관)

| 손가락 | 자연 접촉 | 확장 접촉 |
| :--- | :--- | :--- |
| 검지 | Top L | Top M |
| 중지 | Top R | Top M |
| 엄지 | Side C | Side F, Side R |
| 약지·소지 | (파지 지지) | – |

- 자연도 순위
  - `Side C > Top L ≈ Top R > Top M ≈ Side F ≈ Side R`

## 4. 용어 표준화 (SSOT)
- 3계층 입력 모델
  - [L3] 기능 계층 (Function Layer): 사용자가 의도하는 결과 (예: 좌클릭, 모드 전환, 볼륨 ↑)
  - [L2] 제어 계층 (Control Layer): 트리거를 게이트·모드·프로파일로 필터링 (예: IMU Gate, active_mode, 슬롯 매트릭스)
  - [L1] 입력 계층 (Input Layer): 물리 입력에서 발생하는 원시 이벤트 (예: Top L DOWN, Side C HOLD, Flick Left)
- 용어 정의 (SSOT)

| 용어 | 영문 | 정의 |
| :--- | :--- | :--- |
| 트리거 | Trigger | 사용자 입력 이벤트. 버튼 이벤트 또는 제스처 이벤트 |
| 버튼 이벤트 | Button Event | 물리 버튼에서 발생. CLICK / DOUBLE / LONG / HOLD_2S / HOLD_3S |
| 제스처 이벤트 | Gesture Event | IMU에서 발생. FLICK / LINEAR / TILT |
| 게이트 | Gate | 트리거 발화를 조건부 활성하는 상태 |
| 모드 | Mode | 시스템 작동 상태 (PC / PPT / TV) |
| 프로파일 | Profile | 슬롯·매크로·설정 묶음 (최대 5개) |
| 슬롯 | Slot | 트리거 → 기능 매핑 한 칸 (27개) |
| 매크로 | Macro | 순차 실행 스텝 묶음 (8×8) |
| 기능 | Function | 슬롯에 매핑되는 실제 동작 |

- 계층별 어휘 예시

| 계층 | 어휘 예시 |
| :--- | :--- |
| L1 입력 | Top L DOWN, Side C HOLD, Flick Left |
| L2 제어 | IMU Gate ON, Mode 1, Profile 0, Slot S1 |
| L3 기능 | Left Click, Page Down, Vol Up, Mode Cycle |

- 게이트 목록 (개념)

| 게이트 | 정의 | 활성 조건 |
| :--- | :--- | :--- |
| IMU Gate | 커서·제스처 활성 (설계 중) | 특정 트리거 Hold |
| 모드 게이트 | Mode별 슬롯 리졸브 | 자동 (active_mode) |
| 프로파일 게이트 | 활성 프로파일 슬롯 선택 | 자동 (active_index) |

## 1. IMU 물리 신호 4종 (원천)

MPU6050이 제공하는 **원시 신호**:

| 신호 | 물리량 | 단위 | 시간 특성 | 소스 |
|---|---|---|---|---|
| **자이로 각속도** | ω (회전 속도) | deg/s | 연속, 아날로그 | gx, gy, gz |
| **가속도** | a (선형 가속) | g | 연속, 아날로그 | ax, ay, az |
| **자세** | θ (기울기) | 도 | 정적 (유지) | roll, pitch (상보필터) |
| **선형 가속도** | a_lin (중력 제거) | m/s² | 순간 (임펄스) | ax-중력성분 |

**여기서 파생**:
- **P2P 피크** = 각속도의 짧은 시간(200ms) 최대-최소 차이
- **임펄스 적분** = 선형 가속도의 시간 적분 (∫a·dt)

## 3. 각 기능의 자연성 근거

### 3.1 마우스 포인터 이동

**자연 소스: 자이로 각속도 (gx, gz)**

| 축 | 자이로 | 의미 |
|---|---|---|
| 커서 Y | **gx** (Roll) | 손의 앞뒤 기울임 |
| 커서 X | **gz** (Yaw) | 손의 좌우 회전 |

**근거**:
- PC 마우스의 이동 = **손 위치 상대 변화** = 회전 속도의 시간 적분
- 각속도는 **연속 아날로그** → 커서 이동의 자연 소스
- **Damping + Sigmoid + Zero-Snap** 필터 체인 자연 적용

**부적합 소스**:
- ❌ 가속도: 중력 영향, 미분 노이즈
- ❌ 자세: 절대 각도, 손 위치와 무관
- ❌ 선형 가속: 이동 임펄스, 지속 신호 아님

### 3.2 스크롤 휠 (수직)

**자연 소스: 자이로 각속도 (gy)**

| 축 | 자이로 | 의미 |
|---|---|---|
| 휠 Y | **gy** (Pitch) | 손의 상하 기울임 |

**근거**:
- 스크롤 = 손의 **위아래 지향 움직임**
- 각속도가 임계 초과 시 **1스텝** 발생
- `wheelThDeg`(기본 90°/s), `wheelStepMax`(기본 6) 파라미터와 자연 정합

**시간 스케일**:
- 연속 아날로그 신호를 **임계 기반 이산 스텝**으로 변환
- 커서(순수 연속)와 구분되는 특성

### 3.3 스크롤 팬 (수평)

**자연 소스: 자이로 각속도 (gx)** — 커서 Y와 충돌

| 축 | 자이로 | 커서 Y와 충돌 |
|---|---|---|
| 팬 X | **gx** (Roll) | 🔴 커서 Y가 gx 사용 |

**충돌 해소 필요**:
- 커서 억제 (스크롤 모드 진입 시 커서 0)
- 또는 팬 축 이전 (gz? 여전히 커서 X와 충돌)
- 또는 팬 기능 제거

### 3.4 D-Pad (방향키 반복)

**자연 소스: 자세 (roll/pitch)**

| 축 | 자세 | 의미 |
|---|---|---|
| 상하 | **pitch** | 손 앞뒤 기울기 유지 |
| 좌우 | **roll** | 손 좌우 기울기 유지 |

**근거**:
- D-Pad = TV 메뉴의 **지속적 방향 이동**
- 기기를 특정 방향으로 **기울여 유지** → 방향키 **반복 입력**
- Tilt Hold FSM과 완벽 정합 (`tilt_hold.angle_deg = 15도`, `hold_ms = 300`, `repeat_hz = 3Hz`)

**부적합 소스**:
- ❌ Flick: 단발 이벤트, 반복 불가
- ❌ Linear: 순간 임펄스, 지속성 없음

### 3.5 Flick (4방향 단발)

**자연 소스: 자이로 각속도 (P2P 피크)**

| 축 | 자이로 | 방향 |
|---|---|---|
| Flick L/R | **gz** (Yaw) | 좌/우 |
| Flick U/D | **gx** (Roll) | 상/하 |

**근거**:
- 손목의 **빠른 스냅** = 짧은 시간 큰 각속도 변화
- `p2p_th`(기본 400°/s), `window_ms`(200), `cooldown_ms`(600) 파라미터와 정합

**특성**:
- **단발 이벤트** (재발동 쿨다운)
- 슬롯 매핑 4방향 (F1~F4)

### 3.6 Linear (4방향 단발)

**자연 소스: 선형 가속도 (임펄스)**

**근거**:
- 손의 **선형 가속** (중력 제거 후)
- `linear.th`, `linear.impulse_th`, `linear.window_ms` 파라미터
- 중력 제거 필수 (roll/pitch 회전 반영)

**특성**:
- **단발 이벤트**
- 각속도와 독립적 (회전 아님)

### 3.7 Tilt Hold (방향 유지)

**자연 소스: 자세 (roll/pitch) 유지**

**근거**:
- 3.4 D-Pad와 동일 소스
- **Mode 3 전용** (TV)
- 유지 시간 기반 판정

### 3.8 클릭/드래그

**자연 소스: 물리 버튼**

**근거**:
- IMU 무관
- 버튼 이벤트 (DOWN~UP = 드래그, 짧은 탭 = 클릭)

### 3.9 Snap-to-Axis

**자연 소스: 자이로 각속도**

**근거**:
- 커서 이동 중 **수평/수직 우세 판정**
- 각속도 비율 (`ratio_enter = 4.0`)
- 커서 파이프라인의 **후처리 게이트**

### 5.2 게이트 × 자연 소스 (자연 매핑)

| 게이트 조합 | 자연 소스 | 자연 기능 |

| **Top M 단독** | 자이로 (gy) | **스크롤 휠** |
| **Side C + Top M** | 자이로 (gy, gx) | **스크롤 팬 (커서 억제)** |
| **Top M (Mode 3)** | 자세 (roll/pitch) | **D-Pad** |
| **Side C (자세)** | 자세 (roll/pitch) | **Tilt Hold** (Mode 3) |

│    ├─ 자이로 gz → 커서 X                                 │
│    ├─ 자이로 P2P → Flick (4방향)                         │

┌─────────────────────────────────────────────────────────┐
│  Top M 단독 (검지, 자세 무관)                             │

│    └─ 자세 roll/pitch → D-Pad (Mode 3)                  │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  Side C + Top M (엄지 + 검지)                            │
│    ├─ 커서 억제 (커서 출력 0)                             │
│    ├─ 자이로 gy → 스크롤 휠                              │
│    └─ 자이로 gx → 스크롤 팬                              │
