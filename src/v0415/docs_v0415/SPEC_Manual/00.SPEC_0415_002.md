## 마이그레이션 노트

v0412 사용자가 v0415로 업그레이드 시:
1. **자동 마이그레이션**: 첫 부팅 시 `C10_Config_0415::_migrateProfileV410ToV411()` 실행
2. **Consumer 매핑**: old 16-bit → new 24-bit (자동 변환)
   - `0x0001(VOL_UP)` → `0x2000` (Bit 13)
   - `0x1000(POWER)` → `NONE` (Descriptor 미지원 → 사용자 수동 재설정)
3. **TV 모드 재배치**: POWER → `KB_TAP(0, 0x66)`, CH_UP/DOWN → NONE
4. **스키마 411 저장**: 첫 저장 시 자동 반영

자세한 내용은 `00.UserManual_0415_003.md` §"스키마 411 마이그레이션" 참조.
