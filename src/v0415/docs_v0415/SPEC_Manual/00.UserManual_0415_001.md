# Elite AirMouse S3 — 사용자 매뉴얼

- 파일명: 00.UserManual_0415_001 ㅁ.md
- 문서 버전: v0415 (2026-10-09)

* **기기 개요**
  * 모델: 모션 센서 기반 3가지 모드(모드 1: PC (마우스), 모드 2: 프레젠테이션, 모드 3: 스마트 TV)
  * 연결 및 기능: 무선 블루투스(마우스·키보드·미디어 제어 통합 지원), WS2812 RGB 상태 표시등, 지능형 2단계 자동 절전
  * 주요 기능: 최대 5개 맞춤 설정 저장 공간(프로필), 8단계 연속 동작(매크로) 8개 지원, 2단 기능 배정 방식(기본 공통 및 모드별 덮어쓰기)
  * 웹 설정 환경: 한국어/영문 원클릭 전환(KO/EN), 하이브리드 가상 컨트롤러(Virtual Remote), 모드별 빠른 도구
  * **동작 정밀도**: 클릭 시 포인터 고정(Click-Freeze), 적응형 손떨림 보정(Adaptive EMA), 프레젠테이션 축 스냅(Snap-to-Axis)
  * **전원 관리**: 2단계 절전(라이트 슬립 + 딥 슬립), 모션 흔듦 감지(WoM) 및 버튼 즉시 깨어남, 부드러운 LED 페이드 복원, 슬립 복귀 후 자이로 영점 고속 재수집
  * **버튼 타이밍**: 비대칭 디바운스(누름/뗌 별도), 2-Stage 하이브리드 판정, 스위치 채터링 방지(초단 글리치 필터)
  * **Consumer 키 정밀화 (v0415)**: 미디어/리모컨 키가 HID Descriptor 표준과 완벽 정합되어 매뉴얼과 실동작이 일치
  * 문서 대상: 최종 사용자(일반 사용자, 발표자, 게이머, 스마트 TV 사용자)

> **⚠️ v0415 주요 변경 안내 (v0412 사용자 필독)**
> * **Consumer 키 매핑 전면 재정합** — 이전 버전(v0412)에서는 볼륨/재생 키 일부가 실제로는 다른 키로 오작동했습니다. v0415에서 HID Descriptor 표준과 100% 일치하도록 수정되었습니다.
> * **스마트 TV 모드 일부 기능 조정** — TV 전원 키는 HID Keyboard Power로 대체되었고, 일부 TV에서 미지원되는 채널/외부입력 키는 삭제되었습니다.
> * **프로파일 자동 마이그레이션** — v0412 프로파일이 v0415 기기에서 자동으로 변환됩니다. 사용자가 별도로 조치할 필요가 없습니다.

## 1. 30초 요약 (처음 사용자용)

* **1단계: 전원 켜기**
  * 스위치 ON 조작 시 상태 표시등 파란색 점등 확인 (모드 1: PC 모드 진입)
* **2단계: 기기 연결(페어링)**
  * PC나 스마트폰의 블루투스 설정 화면에서 "Elite AirMouse S3" 검색 후 연결
* **3단계: 포인터(화살표) 이동**
  * 윗면 가운데 버튼(Top M)을 누른 상태에서 손목을 움직여 마우스 화살표 조작
* **4단계: 좌클릭 및 끌기(드래그)**
  * 윗면 왼쪽 버튼(Top L)을 누르면 클릭, 누른 채로 움직이면 끌기(드래그)
* **5단계: 우클릭**
  * 윗면 오른쪽 버튼(Top R) 누름
* **6단계: 모드 변경**
  * 측면 가운데 버튼(Side C)을 연속 두 번 누름 (더블클릭)
  * 1번 PC → 2번 프레젠테이션 → 3번 스마트 TV 순환
  * **마지막 사용한 모드는 자동 저장되어, 기기를 다시 시작해도 동일 모드로 복귀**
* **7단계: 화면 스크롤 및 좌우 이동(팬)**
  * 측면 앞쪽 버튼(Side F)을 누른 상태에서 마우스를 위·아래로 기울이면 상하 스크롤
  * 측면 앞쪽 버튼(Side F)을 누른 상태에서 마우스를 좌·우로 기울이면 좌우 화면 이동(팬)
* **8단계: 상세 설정 웹 화면 접속**
  * WiFi 연결 후 웹브라우저 주소창에 `http://192.168.4.1` 입력하여 가상 컨트롤러, 한국어/영어(KO/EN) 선택, 맞춤 프로필(최대 5개), 27개 동작 매핑, 연속 동작(매크로) 설정 화면 접근

> **각주 (팬 / Pan):** 카메라나 시선을 좌우로 돌리듯, 긴 문서나 넓은 웹페이지를 좌우로 밀어서 이동하는 기능(가로 스크롤)을 의미함.

## 3. 기본 연결 및 작동법

### 3.1 전원 켜기

* 측면 또는 하단 스위치를 켜면 상태 표시등이 파란색으로 켜지며 PC 기본 모드로 대기

### 3.2 기기 연결(블루투스 페어링) 및 등록 기기 전환

* **PC (Windows / Mac / Linux)**: 블루투스 설정에서 "Elite AirMouse S3" 선택 후 연결
* **스마트폰 및 태블릿 (Android / iOS)**: 블루투스 검색 창에서 기기 선택 후 등록
* **스마트 TV (Android TV / Tizen / webOS)**: 기기 추가 화면에서 등록
* **새 기기 페어링(연결 대기) 진입**: 측면 가운데 버튼(Side C)을 **2초간 길게 누르면** 상태 표시등이 깜빡이며 페어링 대기 모드(30초)로 진입합니다.
* **등록된 기기 전환 (호스트 순환)**: 측면 가운데 버튼(Side C)을 **3초간 길게 누르면**, 2초 시점에 진입했던 페어링 모드가 자동으로 즉시 취소되고 이전에 등록된 다른 컴퓨터/기기(최대 3대)로 순환하여 재연결됩니다.

### 3.3 기본 마우스 조작

* 윗면 가운데 버튼(Top M) 누름 유지: 마우스 화살표 이동 허용
* 윗면 가운데 버튼(Top M) 뗌: 화살표 이동 즉시 정지 (내려놓았을 때 제멋대로 움직이는 오작동 차단)
* 윗면 왼쪽(Top L): 좌클릭
* 윗면 오른쪽(Top R): 우클릭

### 3.4 v0412 프로파일 자동 마이그레이션 (v0415 신규)

이전 v0412 펌웨어를 사용하던 기기를 v0415로 업데이트한 경우, 첫 부팅 시 저장된 모든 프로파일이 **자동으로 스키마 411로 변환**됩니다.

| 항목 | v0412 (구) | v0415 (신) |
|---|---|---|
| 스키마 버전 | 410 | 411 |
| Consumer 키 매핑 | 16-bit 자체 압축 | 24-bit HID Descriptor 표준 |
| TV 전원 키 | Consumer `POWER` (오작동) | Keyboard Page `Power (0x66)` |
| TV 채널 키 | Consumer `CH_UP/DOWN` (오작동) | (삭제 — 일부 TV 미지원) |

**사용자가 별도로 조치할 필요가 없습니다.** 다만 다음 항목은 자동 변환 후 확인이 필요합니다:

1. **TV 전원**: v0412에서 "전원"으로 매핑했던 슬롯은 v0415에서 **Keyboard Power 키**로 자동 변환됩니다.
2. **TV 채널/외부입력**: v0412에서 채널/외부입력으로 매핑했던 슬롯은 v0415에서 **할당 해제(빈 슬롯)** 됩니다. 필요 시 웹 UI에서 다시 지정할 수 있습니다.
3. **기타 미디어 키**: 볼륨, 재생/일시정지, 다음/이전 곡 등은 **동일한 기능으로 유지**됩니다.

## 4. 버튼 배치 및 명칭

```
        [윗면 조작부]
     [L]   [M]   [R]      ← 상단 3개 버튼
     
   ┌─────────────┐
[F]│             │
[C]│             │        ← 좌측 측면 3개 버튼 (앞/가운데/뒤)
[R]│             │
   └─────────────┘
```

* **Top L (윗면 왼쪽)**: 좌클릭, 누른 채 이동 시 끌기(드래그)
* **Top M (윗면 가운데)**: 화살표 이동 스위치(누르고 있을 때만 커서 활성화)
* **Top R (윗면 오른쪽)**: 우클릭
* **Side F (측면 앞쪽)**: 화면 스크롤 전환 스위치
* **Side C (측면 가운데)**: 사용 모드 변경 및 연결(페어링) 스위치
* **Side R (측면 뒤쪽)**: 보조 기능 스위치

## 5. 모드 1: PC 일반 작업 모드 (표시등: 파란색)

### 5.1 커서 조작 방식

* 윗면 가운데(Top M)를 누른 상태로 공중에서 손을 움직이면 마우스 화살표가 반응
* 버튼을 떼면 화살표가 멈추므로 조작 안전성이 확보됨

### 5.2 공장 초기 버튼 매핑

| 버튼 | 동작 |
|---|---|
| Top L 한 번 누름 | 좌클릭 |
| Top L 길게 누름 | 좌클릭 누른 상태 유지(끌기/드래그) |
| Top L 두 번 연속 누름 | 더블클릭 |
| Top R 한 번 누름 | 우클릭 |
| Top R 두 번 연속 누름 | 취소(ESC 키) |
| Top R 길게 누름 | 화면 캡처 창 열기(Win + Shift + S) |
| Top M 한 번 누름 | 마우스 휠 클릭 |
| Side F 한 번 누름 | 음량 키우기 |
| Side F 길게 누름 | 다음 곡 재생 |
| Side R 한 번 누름 | 음량 줄이기 |
| Side R 길게 누름 | 이전 곡 재생 |
| Side C 한 번 누름 | 재생 및 일시정지 |

### 5.3 화면 스크롤 및 가로 화면 이동(팬)

* Side F를 누른 채 기기 앞머리를 위나 아래로 기울임: 상하 페이지 스크롤
* Side F를 누른 채 기기를 좌측이나 우측으로 기울임: 좌우 가로 화면 이동(팬)
* 손을 놓으면 일반 화살표 조작 상태로 복귀, 조작 중에는 화살표 이동 속도가 평소의 25% 수준으로 정밀 감속됨

### 5.4 공중 제스처 조작(선택 기능)

* 손목을 좌/우로 휙 돌림: 가상 바탕화면 전환(Ctrl + Win + 방향키)
* 손목을 위로 휙 올림: 모든 창 내리고 바탕화면 보기(Win + D)
* 손목을 아래로 휙 내림: 실행 중인 창 전환(Alt + Tab)
* 상하 제스처는 윗면 가운데(Top M) 버튼에서 손을 뗀 상태에서만 인식됨

### 5.5 클릭 정밀도 향상 (자동)

* **클릭 순간 커서 동결**: 마우스 좌클릭 시 손가락 압력으로 화살표가 미세하게 튀는 현상을 자동 감지하여 순간적으로 잡아줌 (기본 활성화)
* **지능형 손떨림 억제**: 정지 상태의 미세한 떨림은 부드럽게 걸러내고, 빠른 손목 동작은 지연 없이 즉시 반응
* 별도 설정 없이 자동 작동하며, 세부 조정은 웹 UI의 '포인터 및 센서 설정' 탭에서 가능

## 6. 모드 2: 발표 모드 (표시등: 초록색)

### 6.1 진입 방법

* 측면 가운데(Side C)를 두 번 연속 누름 (표시등이 초록색으로 변경되며 흰색으로 0.5초 깜빡임)

### 6.2 발표 화면 제어 버튼 매핑

| 버튼 | 동작 |
|---|---|
| Top L 한 번 누름 | 다음 슬라이드 넘김(PageDown) |
| Top L 두 번 연속 누름 | 이전 슬라이드 넘김(PageUp) |
| Top L 길게 누름 | 현재 쪽부터 슬라이드 쇼 재생(Shift + F5) |
| Side F 한 번 누름 | 다음 슬라이드 |
| Side R 한 번 누름 | 이전 슬라이드 |
| Side R 길게 누름 | 슬라이드 쇼 종료(ESC) |
| Top R 한 번 누름 | 쇼 종료(ESC) |
| Top R 두 번 연속 누름 | 화면 일시 숨김(검은 화면 전환, B 키) |
| Top R 길게 누름 | 흰 화면 전환(W 키) |

### 6.3 포인터 및 가상 레이저 조작

* Top M 누른 채 이동: 화살표 포인터 이동
* Top M 한 번 누름: 화면 내 빨간색 레이저 포인터 켜기(Ctrl + L)
* Side C 한 번 누름: 펜 → 레이저 → 일반 화살표 모드 순환 변경

### 6.4 발표 공중 제스처

* 손목 좌측 털기: 다음 슬라이드
* 손목 우측 털기: 이전 슬라이드
* 손목 위로 털기: 화면 일시 숨김(검은 화면)

### 6.5 발표용 축 스냅 (자동)

* **수평/수직 자동 정렬**: 슬라이드 위에서 화살표로 밑줄을 긋거나 도표를 가리킬 때, 손목이 살짝 흔들려도 자동으로 수평 또는 수직 방향으로 정렬됨
* **동작 방식**: 화살표를 대략 수평으로 움직이면 자동으로 수평선 유지, 수직으로 움직이면 수직선 유지
* **자연스러운 탈출**: 대각선으로 방향을 바꾸면 자동으로 축 스냅 해제되어 자유롭게 이동
* **발표 모드 전용**: 1번 PC 모드나 3번 TV 모드에서는 자동으로 비활성화됨
* **세부 설정**: 웹 UI '포인터 및 센서 설정' 탭에서 축 스냅 강도·민감도 조정 가능

## 7. 모드 3: 스마트 TV 모드 (표시등: 주황색)

### 7.1 진입 방법

* 2번 발표 모드 상태에서 측면 가운데(Side C)를 두 번 연속 누르면 주황색으로 전환됨

### 7.2 스마트 TV 전용 버튼 매핑 (v0415 갱신)

> **⚠️ v0415 변경사항**
> 이전 버전에서 스마트 TV의 전원/채널/외부입력 기능은 실제로 다른 키로 오작동했습니다. v0415에서는 HID 표준에 맞게 재정렬되었으며, 일부 기능은 TV 제조사 표준에서 지원되지 않아 조정되었습니다.

| 버튼 | 동작 | 비고 |
|---|---|---|
| Top L 한 번 누름 | 뒤로 가기 | – |
| Top L 두 번 연속 누름 | 홈 화면 이동 | – |
| Top L 길게 누름 | **전원 켜기/끄기 (일부 TV 미지원)** | **v0415: Keyboard Power (0x66)** |
| Top M 한 번 누름 | 선택(확인/Enter) | – |
| Top R 한 번 누름 | 홈 화면 이동 | – |
| Top R 두 번 연속 누름 | **검색 창 열기** | **v0415: 외부 입력 → 검색으로 대체** |
| Top R 길게 누름 | **전원 끄기 (일부 TV 미지원)** | **v0415: Keyboard Power (0x66)** |
| Side F 한 번 누름 | 음량 키우기 | – |
| Side F 길게 누름 | **(미할당)** | **v0415: 채널 올리기 삭제** |
| Side R 한 번 누름 | 음량 줄이기 | – |
| Side R 길게 누름 | **(미할당)** | **v0415: 채널 내리기 삭제** |
| Side C 한 번 누름 | 영상 재생 및 일시정지 | – |
| 제스처 좌/우 | 10초 되감기 / 10초 빨리 감기 | – |
| 제스처 위 | 음소거 토글 | – |

### 7.3 TV 모드 기능 제약 안내 (v0415)

다음 TV 제어 기능은 **HID Bluetooth 표준에서 지원되지 않아 v0415에서 삭제**되었습니다:

| 기능 | v0412 상태 | v0415 상태 | 대안 |
|---|---|---|---|
| TV 전원 | Consumer `POWER` (오작동) | Keyboard Power (0x66) | 최신 TV는 반응, 구형 TV는 미지원 |
| 채널 올리기/내리기 | Consumer `CH_UP/DOWN` (오작동) | 삭제 (미할당) | TV 자체 리모컨 사용 권장 |
| 외부 입력 전환 | Consumer `TV_INPUT` (오작동) | 삭제 → "검색"으로 대체 | TV 자체 리모컨 사용 권장 |

> **왜 삭제되었나요?** HID(휴먼 인터페이스 장치) 표준에는 채널/외부입력 제어가 정의되어 있지 않습니다. 이전 버전에서는 임의로 매핑했으나 실제로는 다른 기능(예: 볼륨)으로 오작동했습니다. v0415에서는 오작동을 방지하기 위해 미지원 기능을 삭제하고, 사용자가 웹 UI에서 다른 기능으로 재지정할 수 있도록 했습니다.

> **TV 전원은 왜 "일부 TV 미지원"인가요?** HID Keyboard Page에는 Power 키(0x66)가 정의되어 있으나, TV 제조사가 이를 인식하는지는 기기마다 다릅니다. Android TV, 일부 webOS/Tizen TV는 반응하며, 구형 TV는 IR(적외선) 신호가 아니라 블루투스이므로 반응하지 않을 수 있습니다.

### 7.4 기울여 유지하기(틸트 홀드)를 통한 4방향 키 제어

* 윗면 가운데(Top M)에서 손을 뗀 상태로 기기를 전후좌우로 15도 이상 기울여 유지
* 0.3초 이상 유지 시 해당 방향의 방향키가 연속 입력됨 (초당 3회)
* 기기를 평평하게 세우면 방향키 입력이 멈춤
* **해당 기능은 TV 화면 메뉴를 쉽게 넘기기 위한 3번 모드 전용 기능임**

> **왜 TV 모드에서만 작동하나요?** PC나 발표 중에는 손목을 자연스럽게 기울이는 상황이 많아 오작동 위험이 큽니다. TV 리모컨의 방향키 대체 용도에만 활성화했습니다.

### 7.5 커서 방식 지원

* 넷플릭스나 TV 웹브라우저 등 화살표가 필요한 앱에서는 윗면 가운데(Top M)를 누르면 에어마우스 화살표가 즉시 활성화됨

### 7.6 TV 공중 제스처

* 손목 좌측 털기: 10초 뒤로 감기 (Rewind)
* 손목 우측 털기: 10초 앞으로 빨리 감기 (Fast Forward)
* 손목 위로 털기: 음소거 켜기/끄기 (Mute)

### 8.1 모드 순환

* Front Hold(스크롤) 상태 리셋
* Pairing(연결 대기) 중이었다면 자동 취소
* 화면 정밀도 필터 상태 리셋

## 10. 충전 및 절전 모드

### 10.1 충전

* 표준 USB-C 단자를 통해 충전 진행 (5V 충전기 사용)

### 10.2 2단계 지능형 자동 절전 시스템

**1단계: 라이트 슬립 (Light-sleep)**

* 유휴 시간이 아래 조건에 도달하면 자동으로 라이트 슬립에 진입합니다.
  - 모드 1 (PC): 60초
  - 모드 2 (프레젠테이션): 120초
  - 모드 3 (스마트 TV): 300초
  - BLE 연결 중: 300초
  - 페어링 대기 중: 30초
* 진입 시 상태 표시등이 빨간색으로 약 0.5초간 서서히 어두워지며 꺼집니다(Fadeout).
* **깨우기**: 마우스를 가볍게 흔들거나(WoM 모션 센서 감지) 본체의 아무 버튼이나 누르면 즉시 깨어납니다.
* **부드러운 복귀**: 깨어날 때 현재 모드 색상 불빛이 약 0.3초간 서서히 밝아지며(Fadein) 원래 상태로 복원됩니다.
* **자이로 영점 자동 보정**: 슬립 중 발생할 수 있는 센서 온도 변화로 인한 커서 쏠림을 방지하기 위해 깨어난 직후 0.3초간 자동으로 영점을 신속하게 재수집합니다.

**2단계: 딥 슬립 (Deep-sleep)**

* 장시간(기본 10분, 600초) 동안 아무 조작이 없으면 센서 및 LED 전원을 완전히 차단하는 초절전 딥 슬립 상태로 진입하여 배터리 방전을 완벽하게 방지합니다.
* **깨우기**: 본체의 버튼을 누르면 기기가 다시 켜집니다.

**안전 상태별 깨어남 제약 (v0415)**

* **일반 모드**: 마우스 흔들기 및 6개 버튼 모두로 깨어남
* **안전 모드(SafeBoot)**: **측면 가운데(Side C) 버튼만** 깨어남 (다른 버튼은 무시됨)
* **페어링 모드**: **측면 가운데(Side C) 버튼만** 깨어남

> **왜 안전 모드에서는 깨어남 버튼이 제한되나요?** 기기 브릭(작동 불능) 상태에서 예상치 못한 버튼 입력을 방지하기 위함입니다. 안전 모드에서는 Side C 버튼(6초 hold 시 공장 초기화)만 활성화됩니다.

### 10.3 사용 중 오작동 방지

* 마우스 조작 버튼을 누르고 있거나 제스처/입력 동작 중일 때, 또는 웹 설정 모드 중에는 절전 모드로 진입하지 않습니다.

## 11. 브라우저 기반 상세 설정 화면 (웹 UI)

### 11.1 접속 방식

* **기기 자체 와이파이 직접 연결 방식**: PC나 스마트폰의 WiFi에서 SSID "EliteAirMouse"(비밀번호: 12345678)에 연결, 웹브라우저로 `http://192.168.4.1` 주소 입력
* **공유기 연결 방식**: 공유기 연결 후 웹브라우저로 `http://elite-airmouse.local` 주소 입력

### 11.2 네비게이션 드로어 및 언어 전환 (KO / EN)

* **좌측 메뉴 햄버거 버튼 (☰)**: 클릭 시 슬라이드 드로어가 열리며 6대 탭(홈, 버튼 및 동작 할당, 매크로 관리, 포인터 및 센서 설정, 진단 및 입력 테스트, 무선 펌웨어 업데이트) 및 프로필 관리 메뉴 제공
* **언어 선택 (🌐 KO / EN)**: 드로어 하단에서 한국어(KO) 또는 영문(EN)을 클릭하면 전체 항목이 새로고침 없이 즉시 표준 용어로 전환됨
* **프로필 드롭다운**: 최대 5개(0~4번)의 사전 맞춤 프로필을 전환하여 즉시 적용
* **+ 새로**: 새로운 빈 프로필 생성 (예: '사무용', '게임용', '강의용')
* **이름**: 현재 프로필 이름 변경 (최대 15자)
* **삭제**: 불필요한 프로필 삭제 (현재 활성 프로필 삭제 시 타 프로필로 자동 전환)
* **상단 노란색 알림 띠**: 기기 다시 시작이 필요한 설정 변경 시 화면 상단에 표시되며 `지금 다시 시작` 버튼 제공

> **참고**: 노란 알림 띠의 × 버튼을 눌러 닫아도, 새로운 다시 시작 사유가 발생하면 띠가 다시 나타납니다.

### 11.3 홈 탭의 하이브리드 가상 컨트롤러 (Virtual Remote)

* **가상 컨트롤러**: 웹 화면에서 마우스 없이도 마우스, 프레젠테이션, 스마트 TV 주요 기능을 직접 원격 클릭 조작 가능
  * **모드 1: PC**: 방향키 링 + 조이스틱 반복 입력 + 시작 메뉴 / 화면 캡처 / 음소거 / 볼륨 제어
  * **모드 2: 프레젠테이션**: 슬라이드 이동 링(이전/다음) + 처음부터(F5) / 현재부터(Shift+F5) / 쇼 종료(ESC) / 레이저 포인터 / 검은 화면 / 흰색 화면 / 펜 도구
  * **모드 3: 스마트 TV**: 4방향 탐색 링 + 전원 / 홈 / 뒤로 가기 / 확인 / 검색 / 볼륨 / 재생 제어
    * **v0415 변경**: TV 전원은 Keyboard Power(일부 TV 미지원), 채널 버튼은 삭제됨. 자세한 내용은 §7.3 참조.
* **모드 배지**: 컨트롤러 상단 좌측에 현재 활성 모드가 `PC` / `PPT` / `TV` 로 짧게 표시됨
* **조이스틱 사용법**: 중앙 원형 노브(Enter/OK)뿐 아니라 **링(원형 배경)의 어느 위치든 드래그**하면 방향 입력이 반복 실행됨. 중앙 노브를 살짝 탭하면 Enter/OK 입력이 한 번 전송됨
* **접기 / 펼치기 토글**: `접기 ▲` 버튼을 누르면 컨트롤러가 콤팩트하게 축소되어 화면 공간 절약

> **PC 화면(넓은 화면) 사용 시**: 브라우저 창이 넓으면 가상 컨트롤러와 도구 카드가 좌우 2단으로 배치되어 화면 공간을 효율적으로 사용합니다.

## 12. 버튼 및 동작 맞춤 할당 화면 (슬롯 관리)

### 12.1 개념 정의

**슬롯(Slot)** 이란 27개의 물리적 누름이나 제스처 동작에 원하는 키나 마우스 기능을 배정하는 매핑 단위임

### 12.2 27가지 조작 동작 분류

* **버튼 조작 (15개)**: Top L/M/R 및 Side F/C/R의 단일 누름, 길게 누르기, 두 번 연속 누르기
* **공중 제스처 (4개)**: 기기를 손목 스냅으로 동서남북 방향으로 휘두르기 (Flick)
* **선택적 제스처 (4개)**: 윗면 가운데(Top M)를 누른 상태에서 상하좌우로 이동 (Linear)
* **기울여 유지 (4개)**: 모드 3 (스마트 TV) 전용으로 특정 방향으로 기울인 채 유지하기 (Tilt & Hold)

### 12.3 절대 수정 불가 잠금 동작 (오작동 방지용)

| 트리거 | 동작 | 잠금 사유 |
|---|---|---|
| S1 | Top L 짧게 누름 | 기본 마우스 좌클릭 및 선택 기능 (고정) |
| S5 | Top M 누르고 있음 | 포인터 이동 허용 스위치 (Move Gate 고정) |
| S12 | Side C 두 번 연속 누름 | 모드 변경 필수 스위치 (Mode Cycle 고정) |
| S13 | Side C 2초 길게 누름 | 블루투스 페어링 모드 진입 스위치 (Pairing 고정) |

### 12.4 전체 공통 적용 vs 모드별 덮어쓰기

* 상단 뷰 탭에서 **기본 공통**, **모드 1: PC**, **모드 2: 프레젠테이션**, **모드 3: 스마트 TV** 중 하나를 선택하여 화면을 전환함
* 동작 이름 옆 파란색 **[G]** 표시는 기본 공통 설정을 그대로 상속받는다는 의미임
* 특정 모드에서 [G]를 클릭하면 주황색 **[M]** 표시로 바뀌며 해당 모드 전용 재정의(오버라이드)가 생성됨
* **[M] 표시를 다시 클릭하면 기본 공통 설정으로 되돌아감**

### 12.5 지원되는 10가지 실행 동작 종류

| 종류 | 설명 |
|---|---|
| NONE | 동작 없음 (할당 안 함) |
| MOUSE_CLICK | 마우스 단일 클릭 (왼쪽, 오른쪽, 가운데 휠, 뒤로 가기, 앞으로 가기) |
| MOUSE_HOLD | 마우스 버튼 누른 상태 유지 (드래그용) |

## 13. 자동 연속 동작 화면 (매크로 관리)

### 13.1 개념 정의

단 한 번의 버튼 조작으로 복잡한 단축키나 연속 입력을 정해진 순서와 시간 간격에 맞춰 자동으로 실행해 주는 기능임

### 13.2 시스템 제약 규격

* 설정 세트당 최대 8개의 연속 동작을 보관 가능함
* 연속 동작 1개당 최대 8단계의 순차 명령을 넣을 수 있음
* 단계별 대기 시간(지연 시간)은 0초에서 2초(2000밀리초)까지 지정 가능함

### 13.3 생성 및 편집 절차

* **1단계**: + 새 매크로 선택 후 알기 쉬운 이름 입력
* **2단계**: + 단계 추가 버튼으로 실행할 키보드나 마우스 조작을 순서대로 나열
* **3단계**: 각 단계 사이에 프로그램이 반응할 수 있도록 적절한 지연 시간(예: 100~500밀리초) 입력
* **4단계**: '저장' 버튼을 누른 뒤 버튼 매핑 화면으로 돌아가 원하는 버튼에 해당 매크로를 연결

### 13.4 실생활 추천 활용 구성

* **작업 관리자 호출**: Ctrl + Shift + ESC 단축키를 묶어 측면 뒤쪽 버튼에 배정
* **자동 복사 후 붙여넣기**: Ctrl + C 실행 후 0.1초 뒤 Ctrl + V가 바로 실행되도록 구성
* **원터치 화면 캡처**: Win + Shift + S 실행 후 0.5초 뒤 저장 단축키가 연쇄 작동하도록 구성
* **화상회의 즉시 끄기**: 마이크 음소거(Ctrl + Shift + M)와 화면 끄기(Ctrl + Shift + V)를 연달아 실행

### 13.5 비상 중단 안전장치

동작 도중 다른 모드로 전환하거나 블루투스 연결이 끊어지면 누르고 있던 키가 컴퓨터에 계속 눌린 채로 멈추지 않도록 모든 키를 즉시 자동으로 떼어줌

> **참고**: 매크로 저장이 실패한 경우 화면 하단의 최근 명령 로그에 `MACRO_SAVE_FAIL` 항목이 나타나 실패를 확인할 수 있습니다.

## 14. 포인터 및 센서 세부 설정 (Config 탭)

### 14.1 기본 파라미터

* **커서 속도(DPI)**: 1~3단계로 마우스 화살표의 기본 반응 민감도 설정
* **손떨림 보정 기능**: 공중에서 버튼을 딸깍 누를 때 손목이 흔들려 화살표가 빗나가지 않도록 일시적으로 화살표를 잡아줌
* **상태 표시등 밝기**: 본체 불빛의 밝기를 조절
* **스크롤 중 커서 속도 감속**: 화면을 위아래로 넘기는 도중에는 화살표가 마구 튀지 않도록 속도를 느리게 줄여주는 비율 설정
* **제스처 감도**: 손목을 털었을 때 이를 명령으로 인식할 회전 속도 기준 설정
* **설정 파일 백업 및 복원**: 내가 세팅한 모든 버튼 설정을 파일로 내려받거나 다른 사람의 설정을 불러오기 가능

> **⚠️ v0415 변경: "클릭 중 포인터 잠금" 옵션**
> 기존 v0412에서 제공하던 "하드 클릭 방지(클릭 중 포인터 잠금)" 옵션은 **v0415에서 기능이 삭제**되었습니다.
> 대신 **"클릭 시 포인터 고정(Click-Freeze)"** 기능이 이를 대체하며, 클릭 순간 더 정교하게 화살표 튐을 방지합니다.
> 웹 UI에서 "하드 클릭 방지" 옵션은 여전히 보이지만 **실제 동작에는 영향을 주지 않습니다** (호환성 유지용).

### 14.5 공장 초기화

기기의 모든 프로필과 설정을 지우고 최초 출고 상태로 복원하는 방법은 두 가지가 있습니다.

#### 방법 1: 웹 화면에서 초기화
* 웹 UI Config 탭의 시스템 관리 영역에서 `공장 초기화` 버튼을 클릭
* 저장하지 않은 변경사항이 있으면 진행 전에 경고 대화상자가 표시되며, 승인 시 플래시 파일시스템을 포맷하고 기본값으로 재부팅

#### 방법 2: 하드웨어 부팅 버튼으로 초기화 (응급 복구)
* 기기 전원을 켤 때(또는 재부팅 시) **측면 가운데 버튼(Side C)을 6초(6,000ms) 이상 계속 누르고 있습니다.**
* 6초가 지나면 상태 표시등(LED)이 **주황색으로 5회 점멸**한 후 모든 프로필과 설정이 완전히 공장 기본값으로 복원되며 자동으로 다시 시작됩니다.
* 웹 UI 접속이 불가능하거나 설정 오류로 기기가 비정상 동작할 때 물리적으로 안전하게 복구할 수 있는 비상 수단입니다.

* **Raw JSON 보기**: 접힌 상태의 `<details>` 블록을 펼치면 원시 JSON 응답 확인 가능

### 15.3 최근 명령 로그

* 가상 컨트롤러, 모드 도구, 진단 도구에서 발생한 모든 명령이 시간 순서대로 표시됨
* 성공 항목은 초록색, 실패 항목은 빨간색으로 구분됨

### 15.4 입력 신호 테스트 (Key Test)

* 키보드 개별 신호 또는 미디어 키를 즉시 전송하여 정상 동작 여부 확인 가능
* 키보드(KB) / 미디어(Consumer) 선택, 조합 키(Ctrl/Shift/Alt/Win), 키 코드 입력 후 `전송` 클릭

### 15.5 자이로 영점 조절 피드백

* 평평한 책상에 올린 뒤 '자이로 영점 조절'을 실행하면, **약 2초 후 자이로 RMS 변화량과 보정된 바이어스 좌표가 메시지로 표시됩니다.**
* 예: `자이로 영점 조절 완료 · RMS 0.45 → 0.12 deg/s · Bias: (0.02, -0.01, 0.03)`

### 15.6 I2C 복구 피드백

* '센서 연결(I2C) 복구'를 실행하면, **약 3초 후 복구 성공/실패 여부와 누적 복구 횟수가 표시됩니다.**
* 복구 실패 시 하드웨어 연결 점검 안내가 함께 표시됩니다.

### 15.7 안전 부팅 (SafeBoot) 상태

* **안전 부팅 상태**: 서버에서 관리되는 실제 SafeMode 상태, 실패 횟수(fail_count), 부팅 대기 여부(pending)를 표시
* **안전 부팅 모드 종료**: SafeMode를 해제하고 기기를 자동으로 다시 시작함

### 15.8 무선 펌웨어 업데이트 (OTA)

* 펌웨어 파일(.bin)을 무선으로 전송하여 기기 소프트웨어를 최신 버전으로 업데이트
* 업데이트 중에는 보안 잠금(OTA Guard)이 활성화되어 마우스/키보드 입력이 안전하게 일시 중단됨

## 16. 자주 묻는 문제 및 해결책

### 마우스 화살표가 움직이지 않는 현상

* 윗면 가운데(Top M) 버튼을 꾹 누른 채로 움직이고 있는지 확인 필요함
* 컴퓨터의 블루투스 설정에서 연결이 끊어졌는지 확인하고 측면 가운데(Side C)를 2초간 눌러 재연결함
* 책상 위에 평평하게 내려놓은 뒤 웹 화면에서 '자이로 영점 조절'을 진행함

### 버튼이 계속 눌린 것처럼 작동하는 현상

* 무선 신호 일시 혼선으로 발생할 수 있으며 웹 화면 문제 해결 도구의 '눌린 키 강제 해제' 버튼을 클릭함

### 클릭할 때마다 화살표가 살짝 튀는 현상

* **자동 해결**: 클릭 시 포인터 고정(Click-Freeze) 기능이 기본 활성화되어 있어 자동으로 억제됨
* 그래도 문제가 지속되면 웹 UI '포인터 및 센서 설정' 탭에서 '정지 판단 자이로 임계값'을 20~25로 높임

### 화살표가 손 떨림으로 흔들리는 현상

* 웹 UI '포인터 및 센서 설정' 탭에서 **정밀 작업 프리셋**을 적용하면 저속 스무딩이 강화됨
* 'Alpha Min'을 0.03~0.04로 낮추면 더 부드러워짐

### 프레젠테이션 중 수평선이 흔들리는 현상

* **자동 해결**: 2번 프레젠테이션 모드에서는 축 스냅이 기본 활성화되어 자동으로 수평 정렬됨
* 만약 스냅이 너무 강하게 느껴지면 '고정 강도'를 0.6~0.7로 낮춤
* 스냅이 전혀 작동하지 않으면 웹 UI '포인터 및 센서 설정' 탭에서 '직선 스냅'이 '사용'인지, '적용 모드'에 2번 모드가 체크되어 있는지 확인

### 화면 스크롤이 지나치게 둔하거나 빠른 현상

* 세부 설정 화면에서 휠 스크롤 감도(휠 스크롤 민감도) 값을 조절함

### 손목 제스처가 내 의도와 달리 자주 발동하는 현상

* 세부 설정에서 휘두르기 제스처 감도 수치를 높여 조금 더 강하게 털었을 때만 반응하도록 조정함

### 안전 부팅 모드로 켜지는 현상 (SafeBoot)

* 비정상적인 전원 종료가 반복되었을 때 시스템 보호를 위해 진입함
* 웹 화면 대시보드에서 '안전 부팅 모드 종료'를 누르면 기기가 다시 시작되며 일반 모드로 돌아옴

### 버튼을 한 번만 눌렀는데 두 번 연속 눌리는 현상 (더블클릭 오탐)

* 스위치 부품 노후화로 버튼에서 손을 뗄 때 접점이 미세하게 떨리는 채터링 현상입니다.
* 웹 설정 화면의 Config 탭 → `버튼 타이밍` 항목에서 `뗌 디바운스`를 **30~50 ms** 로 늘리고, `글리치 필터`를 **30~40 ms** 로 조정하면 스위치 교체 없이도 더블클릭 오탐이 크게 줄어듭니다.

### 절전 모드에서 깨어난 직후 화살표가 살짝 쏠리는 현상

* 슬립 중 내부 센서 온도가 미세하게 변화하여 발생할 수 있는 자연스러운 현상입니다.
* **자동 보정**: 마우스가 깨어난 직후 0.3초간 자이로 영점을 자동으로 고속 재수집합니다. 마우스를 쥐고 약 0.3초간 잠시 멈춘 뒤 조작을 시작하면 화살표 쏠림이 자동으로 보정됩니다.

### 배터리를 더 오래 절약하고 싶은 경우

* 웹 설정 화면의 Config 탭 → `절전 및 전원 관리` 항목에서 `딥슬립 대기` 시간을 **300초 (5분)** 정도로 줄이면 장시간 미사용 시 완전 전원 차단 상태로 신속하게 전환되어 배터리를 최대한 아낄 수 있습니다.

### 상단 배터리 표시가 "N/A"로 표시되는 현상

* 이 기기 버전은 **배터리 잔량 측정 ADC 회로가 미구현 상태**입니다.
* 따라서 상단 상태 바의 배터리 항목이 `N/A` 로 표시되며, 이는 정상 동작입니다.

### 설정을 변경했는데 저장 전에 다른 조작을 한 경우

* Config 탭에서 값을 변경한 뒤 **저장 버튼을 누르지 않고** 다시 시작 또는 공장 초기화를 시도하면, 미저장 변경사항을 잃을 수 있다는 경고 대화상자가 표시됩니다.
* 반드시 저장 버튼을 눌러 플래시 메모리에 기록하십시오.

### 프리셋을 적용했더니 이전 설정이 사라진 경우

* 프리셋은 5종 모두 **동작 정밀도 설정 19개 항목 전체**를 프리셋 기본값으로 재설정합니다.
* 확인 대화상자에서 승인한 경우에만 실행되며, 승인 이후에는 되돌릴 수 없습니다.
* 이전 설정을 보존하려면 프리셋 적용 전에 `백업 내보내기`로 저장해 두십시오.

### 왼쪽 상단 노란색 다시 시작 알림 띠를 닫았는데 다시 나타나는 경우

* 노란 띠의 닫기(×) 버튼은 **동일한 다시 시작 사유에 대해서만** 다시 나타나지 않도록 기억합니다.
* 와이파이 설정 등 새로운 다시 시작 사유가 발생하면 띠가 다시 표시됩니다.

### 조이스틱 중앙 노브가 아닌 주변 원을 잡아도 반응하나요?

* 네, 조이스틱의 **원형 배경(링) 어느 위치를 잡아도** 드래그가 인식되어 방향 입력이 반복 실행됩니다.
* 중앙 노브를 탭하면 Enter/OK 입력이 한 번 전송됩니다.

### 측면 가운데(Side C) 버튼을 길게 누를 때 페어링과 호스트 전환이 어떻게 다른가요?

* **2초 누름**: 새 기기와 연결하기 위한 **페어링 대기 모드**(LED 점멸)로 진입합니다.
* **3초 이상 누름**: 이전에 등록된 **다음 호스트(컴퓨터/기기)로 순환 재연결**합니다. 3초가 되는 순간 2초 지점에서 진입했던 페어링 모드는 자동으로 즉시 취소되므로 오작동 없이 깔끔하게 다른 기기로 전환됩니다.

### 웹 화면 접속이 안 되거나 설정을 완전히 초기화하고 싶을 때는 어떻게 하나요?

* 기기 전원을 켤 때 **측면 가운데(Side C) 버튼을 6초 이상 계속 누르고 있으면**, 하드웨어 응급 공장 초기화가 실행됩니다.
* 주황색 LED가 5회 점멸한 뒤 모든 프로필과 설정이 출고 기본값으로 복원되며 기기가 자동 재부팅됩니다.

### (v0415 신규) 기기를 v0412에서 v0415로 업데이트했더니 설정이 바뀐 것 같습니다

* 첫 부팅 시 저장된 프로파일이 **자동으로 v0415 스키마로 변환**됩니다. 이전 버전에서 매뉴얼과 다르게 동작했던 몇몇 키(볼륨, 재생, TV 전원)가 v0415에서는 표준에 맞게 정상 작동합니다.
* v0412에서 "TV 전원"으로 매핑했던 슬롯은 v0415에서 **Keyboard Power 키**로 자동 변환되며, "TV 채널"로 매핑했던 슬롯은 **할당 해제(빈 슬롯)** 됩니다.
* 프로파일 이름, 매크로, 그 외 슬롯 설정은 그대로 유지됩니다.
* 상세 내용은 §3.4 "v0412 프로파일 자동 마이그레이션"을 참조하십시오.

### (v0415 신규) 스마트 TV 모드에서 전원 키가 TV를 켜지 못합니다

* v0415에서 TV 전원은 **Keyboard Page의 Power 키(0x66)**로 전송됩니다.
* Android TV, 일부 webOS/Tizen TV는 이 키를 인식하여 반응하지만, **일부 구형 TV는 HID 표준에 반응하지 않아 동작하지 않습니다**.
* 이는 기기의 오류가 아니라 TV 제조사의 HID 지원 여부 차이입니다. 반응하지 않는 TV에서는 **본체 리모컨을 사용**하시기 바랍니다.

### (v0415 신규) 스마트 TV 모드에서 채널 올리기/내리기가 동작하지 않습니다

* **설계상 정상 동작**입니다. v0415에서 TV 채널 조절 기능은 HID 표준에 없어 삭제되었습니다.
* 이전 버전(v0412)에서는 채널 올리기/내리기가 매핑되어 있었으나 실제로는 다른 키(예: 볼륨)로 오작동했습니다.
* 채널 조절이 필요하면 **TV 본체 리모컨을 사용**하시기 바랍니다.

### (v0415 신규) 안전 모드나 페어링 모드에서 마우스를 흔들어도 깨어나지 않습니다

* **설계상 정상 동작**입니다. 안전 모드(SafeBoot)와 페어링 모드에서는 **측면 가운데(Side C) 버튼만** 기기를 깨울 수 있습니다.
* 이는 안전 상태에서 예상치 못한 입력을 방지하기 위한 v0415 정책입니다.
* 측면 가운데 버튼을 누르면 정상적으로 깨어납니다.

## 18. 안전 주의사항

* **물기 및 습기 차단**: 방수 설계가 적용되지 않았으므로 액체 노출 주의 필요함
* **충격 및 낙하 주의**: 내부에 정밀 모션 센서가 장착되어 있어 바닥 낙하 시 센서가 영구 파손될 위험이 있음
* **정격 전압 충전기 사용**: 일반 규격의 5V 충전기 사용 권장
* **시스템 무선 업데이트 주의**: 소프트웨어 업데이트 진행 중 배터리가 방전되거나 전원이 꺼지면 기기가 작동 불능 상태에 빠질 수 있으므로 충전선을 연결한 상태에서 진행 권장됨
