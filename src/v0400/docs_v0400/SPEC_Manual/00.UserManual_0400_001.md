# Elite AirMouse S3 — v0400 사용자 매뉴얼

> ESP32-S3-Zero + MPU6050 기반 3-Mode Air Mouse
> BLE HID Composite (Mouse + Keyboard + Consumer) / WS2812 LED / Light-sleep

**문서 대상: 최종 사용자 (일반 사용자, 프레젠테이션 발표자, TV 사용자)**
**소프트웨어 버전: v0400**

---

## 📌 30초 요약 (처음 사용자용)

1. **전원 켜기** → LED 파란색 점등 (Mode 1: PC)
2. **호스트에 페어링** → "Elite AirMouse S3" 선택
3. **Top M (가운데 위 버튼) 누르고 있으면** → 커서 이동
4. **Top L (왼쪽 위)** → 마우스 좌클릭
5. **Top R (오른쪽 위)** → 마우스 우클릭
6. **Side C 더블클릭 (측면 가운데)** → Mode 전환 (PC → PPT → TV → PC)
7. **Side F 누르고 있으면** → 스크롤 모드

**끝.**

---

## 📦 구성품

- 본체 1개 (ESP32-S3-Zero + MPU6050 탑재)
- USB-C 케이블 1개 (충전 + 펌웨어 업데이트용)
- (선택) 스트랩, 파우치

**배터리 내장 여부는 사용 모델에 따라 다릅니다.**

## 🔋 처음 시작하기

### 1단계: 전원 켜기

- 측면 또는 하단의 전원 스위치를 ON
- LED가 파란색으로 켜짐 → Mode 1 (PC Air Mouse) 진입

### 2단계: 호스트에 페어링

**PC (Windows / macOS / Linux)**

1. PC의 Bluetooth 설정 열기
2. "Elite AirMouse S3" 검색
3. 페어링 클릭 → 자동 연결
4. LED가 파란색으로 안정화되면 완료

**스마트폰 / 태블릿 (Android / iOS)**

1. Bluetooth 설정 열기
2. "Elite AirMouse S3" 선택
3. 연결

**스마트 TV (Android TV / Tizen / webOS)**

1. 설정 → Bluetooth 입력 장치 → 추가
2. "Elite AirMouse S3" 선택
3. 연결 완료

> **팁:** 페어링이 안 되면 Side C를 **2초간 눌러** 페어링 모드로 진입하세요. LED가 1Hz로 깜빡입니다.

### 3단계: 첫 사용

- **Top M (가운데 위) 을 누른 채** 손목을 움직임 → 커서 이동
- **Top M 을 놓으면** 커서 정지
- Top L 클릭 → 좌클릭
- Top R 클릭 → 우클릭

## 🎛️ 버튼 레이아웃

```
        [Top 면]
     [L] [M] [R]      ← 위쪽 3버튼
     
   ┌─────────────┐
[F]│             │
[C]│             │  ← 왼쪽 측면 (Front/Center/Rear)
[R]│             │
   └─────────────┘
```

| 약자 | 위치 | 주요 역할 |
|---|---|---|
| **Top L** | 위 왼쪽 | 좌클릭 / (드래그) |
| **Top M** | 위 가운데 | 커서 이동 게이트 (Hold) |
| **Top R** | 위 오른쪽 | 우클릭 |
| **Side F** | 측면 앞 | 스크롤 모드 (Hold) |
| **Side C** | 측면 가운데 | Mode 전환 / 페어링 |
| **Side R** | 측면 뒤 | 보조 기능 |

## 🖱️ Mode 1: PC Air Mouse

**PC 작업에 최적화된 기본 모드. LED: 파란색**

### 커서 이동

- **Top M 누른 채** 손목 움직임 → 커서 이동
- **Top M 놓음** → 커서 정지 (오작동 방지)

> **왜 버튼을 눌러야 하나요?** 책상에 내려놨을 때 커서가 저절로 움직이는 것을 방지하기 위함입니다.

### 버튼 조작

| 버튼 | 동작 |
|---|---|
| Top L 클릭 | 마우스 좌클릭 |
| Top L 길게 | 마우스 좌클릭 유지 (드래그) |
| Top L 더블클릭 | (기본) 마우스 더블클릭 |
| Top R 클릭 | 마우스 우클릭 (컨텍스트 메뉴) |
| Top R 더블클릭 | ESC |
| Top R 길게 | 화면 캡처 (Win+Shift+S) |
| Top M 클릭 | 마우스 휠클릭 |
| Side F 클릭 | 볼륨 업 |
| Side F 길게 | 다음 트랙 |
| Side R 클릭 | 볼륨 다운 |
| Side R 길게 | 이전 트랙 |
| Side C 클릭 | 재생/일시정지 |

### 스크롤 (Front Hold)

- **Side F 를 누른 채** 마우스 위/아래 기울임 → 페이지 스크롤
- **Side F 를 누른 채** 좌/우 기울임 → 가로 스크롤
- Side F 놓음 → 원래 커서 속도 복귀
- 스크롤 중엔 커서가 25% 속도로 느려짐 (미세 조정 가능)

### 제스처 (선택)

- **손목 좌/우 빠르게 회전** → 가상 데스크톱 전환 (Ctrl+Win+Left/Right)
- **손목 위로 빠르게** → Win+D (바탕화면 보기)
- **손목 아래로 빠르게** → Alt+Tab (작업 전환)

> **참고:** 상하 제스처는 Top M 을 놓은 상태에서만 동작합니다.

### DPI 조절

- 화면 하단 또는 웹 UI의 DPI 버튼 1/2/3
- 높은 해상도 모니터에선 3 권장
- 낮은 해상도에선 1~2 권장

## 🎤 Mode 2: Presentation (프레젠테이션)

**파워포인트 / Keynote / Google Slides 발표용. LED: 초록색**

### 진입 방법

- **Side C 더블클릭** (Mode 1 → Mode 2)
- LED가 초록색 + 흰색 0.5초 깜빡임

### 슬라이드 조작

| 버튼 | 동작 |
|---|---|
| Top L 클릭 | 다음 슬라이드 (PageDown) |
| Top L 더블클릭 | 이전 슬라이드 (PageUp) |
| Top L 길게 | 현재 슬라이드부터 쇼 시작 (Shift+F5) |
| Side F 클릭 | 다음 슬라이드 |
| Side R 클릭 | 이전 슬라이드 |
| Side R 길게 | 쇼 종료 (ESC) |

### 포인터 / 레이저

- **Top M 누른 채** 움직임 → 포인터 이동
- **Top M 클릭** → 레이저 포인터 모드 (Ctrl+L)
- **Side C 클릭** → 펜 / 레이저 / 화살표 순환 (Ctrl+P → Ctrl+L → Ctrl+A)

### 화면 제어

| 버튼 | 동작 |
|---|---|
| Top R 클릭 | ESC (발표 종료) |
| Top R 더블클릭 | B (블랙아웃 토글) |
| Top R 길게 | W (화이트아웃 토글) |

### 제스처

- **손목 좌 회전** → 다음 슬라이드
- **손목 우 회전** → 이전 슬라이드
- **손목 위로** → B (블랙아웃)

### 발표 중 스크롤

- **Side F 누른 채** 위/아래 기울임 → 페이지 스크롤 (긴 슬라이드/웹 페이지용)

## 📺 Mode 3: Smart TV Remote

**TV 리모컨 대체용. LED: 주황색**

### 진입 방법

- **Side C 더블클릭** (Mode 2 → Mode 3)
- LED가 주황색 + 흰색 0.5초 깜빡임

### TV 조작

| 버튼 | 동작 |
|---|---|
| Top L 클릭 | 뒤로가기 (AC Back / Android Back) |
| Top L 더블클릭 | 홈 (Home) |
| Top L 길게 | 전원 (Power) |
| Top M 클릭 | 확인 (Enter) |
| Top R 클릭 | 홈 (Home) |
| Top R 더블클릭 | 입력 소스 (TV Input) |
| Top R 길게 | 전원 끄기 (Power Off) |
| Side F 클릭 | 볼륨 업 |
| Side F 길게 | 채널 업 |
| Side R 클릭 | 볼륨 다운 |
| Side R 길게 | 채널 다운 |
| Side C 클릭 | 재생/일시정지 |

### D-Pad 네비게이션 (Tilt Hold)

- **Top M 을 놓은 상태**에서 마우스를 **위/아래/좌/우로 기울여 유지**
- 15° 이상 기울임 + 300ms 유지 → 방향키 자동 반복 입력 (3Hz)
- 중립 복귀 → 정지

### TV 브라우저 / 넷플릭스 등

- **Top M 누른 채** 움직임 → 커서 이동 (TV의 웹 브라우저 조작)
- Top M 놓으면 → D-Pad 모드 복귀

### 제스처

- **손목 좌 회전** → 10초 되감기 (Rewind)
- **손목 우 회전** → 10초 빨리감기 (Fast Forward)
- **손목 위로** → 음소거 (Mute)

### 채널/볼륨 스크롤

- **Side F 누른 채** 위/아래 기울임 → 볼륨 스크롤

## 🔄 Mode 전환 방법

### 순환 (Cycle)

- **Side C 더블클릭** → Mode 1 → 2 → 3 → 1 순환
- LED 색상: 파랑 → 초록 → 주황 → 파랑
- Mode 진입 시 흰색 0.5초 깜빡임 (시각 피드백)

### LED 색상으로 현재 Mode 확인

| LED 색 | Mode |
|---|---|
| 🔵 파랑 | Mode 1 (PC) |
| 🟢 초록 | Mode 2 (Presentation) |
| 🟠 주황 | Mode 3 (Smart TV) |
| ⚪ 흰색 | 액션 실행 중 (flash) |
| 🔴 빨강 | 경고 / 슬립 진입 |
| 💡 1Hz 깜빡임 | 페어링 대기 |

## 📡 페어링 / 재연결

### 새 기기 페어링

1. **Side C 를 2초간 누름** (LED가 1Hz 깜빡임)
2. 새 기기에서 "Elite AirMouse S3" 검색
3. 페어링 클릭 → 자동 연결
4. LED가 현재 Mode 색으로 복귀

### 다른 기기로 전환 (Multi-Host)

**최대 3개 기기 저장 가능.**

1. **Side C 를 3초간 누른 채 유지**
2. **Top L 을 클릭** (Side C 누른 상태에서)
3. LED가 흰색 0.5초 깜빡임
4. 자동으로 다른 저장된 기기로 재연결 시도
5. 저장된 기기가 자동 재연결 (Windows/macOS/iOS는 자동, Android TV는 수동일 수 있음)

**순환:** 저장된 기기 1 → 2 → 3 → 1 순환

### 페어링 완전 초기화

- 웹 UI에서 Factory Reset
- 또는 부팅 시 Side C 를 6초 이상 누름 (일부 모델)

## ⚙️ 웹 UI 사용법

### 접속 방법

**Wi-Fi AP 모드 (기본):**

1. 스마트폰/PC의 Wi-Fi 목록에서 "EliteAirMouse" 선택
2. 비밀번호: `12345678`
3. 브라우저에서 `http://192.168.4.1` 접속

**Wi-Fi STA 모드 (설정 후):**

1. 브라우저에서 `http://elite-airmouse.local` 접속
2. (또는 할당된 IP로 직접 접속)

### Dashboard 탭

- Uptime, Heap, Wi-Fi 상태
- DPI / Precision 모드
- 커서 RMS / 온도
- **Quick Control:**
  - PPT Mode ON/OFF
  - Precision OFF
  - DPI 1/2/3 버튼
  - 자이로 캘리브레이션
  - 강제 릴리즈 (버튼 stuck 해제)
  - I2C 복구
  - SafeBoot 상태 / 해제
  - Factory Reset

### Config 탭

**Wi-Fi 설정:**

- Mode: AUTO (STA 시도 후 실패 시 AP) / AP / STA
- STA SSID / PASS: 집 Wi-Fi
- AP SSID / PASS: 기기 자체 Wi-Fi
- mDNS Host: `elite-airmouse` (변경 가능)

**E10 설정:**

- DPI Level (1~3)
- Hard Click Lock (true/false)
- LED Brightness (0~255)
- Accel Threshold (0~50)
- Scroll Cursor Damp (0~1)

**Precision 설정:**

- Mode (OFF/LOW/MED/HIGH/PPT)
- Deadzone / Gain / Accel / Max Step / Smooth
- Entry/Exit 시간

**버튼:**

- Config 로드 / 검증 / Apply / Save
- Export / Import / Rollback

### Mode Slots 탭

**3개 Mode의 슬롯을 편집.**

- Mode 1/2/3 탭 선택
- 각 Mode에 4 그룹:
  - **Button Slots (S1~S15)**: 물리 버튼 트리거
  - **Flick (L/R/U/D)**: 손목 회전 제스처
  - **Linear (L/R/U/D)**: 손목 평행 이동
  - **Tilt Hold**: Mode 3 D-Pad
- 각 슬롯에 **Action kind** 지정:
  - NONE / MOUSE_CLICK / MOUSE_HOLD / MOUSE_WHEEL
  - KB_TAP / KB_COMBO / KB_REPEAT
  - CONSUMER_TAP / CONSUMER_REPEAT
  - SPECIAL
- 파라미터 입력 (mask / usage / mod 등)
- 저장 → 즉시 적용

### Diagnostics 탭

- **카운터:**
  - body_too_large / bad_json / safe_blocked / ota_blocked
  - mpu_nan / mutex_miss / task_overrun
  - i2c_recover / failsafe_rel
- **E10 에러 이력:** 최근 16개
- **웹 이벤트 이력:** 최근 16개
- **raw JSON:** 상세 정보

문제 발생 시 개발자에게 이 화면 스크린샷을 전달.

### OTA 탭

**펌웨어 업데이트:**

1. `.bin` 파일 선택
2. 업로드 클릭
3. 진행 바 확인 (0% → 100%)
4. 완료 시 자동 재부팅 (5~10초)
5. 페이지 새로고침

**주의:** 업로드 중 전원 차단 금지.

## 🔧 자주 발생하는 문제

### 커서가 안 움직임

**원인 1:** Top M 을 안 누르고 있음
- **해결:** Top M 을 누른 상태에서 움직이세요

**원인 2:** BLE 연결 끊김
- **해결:** 웹 UI의 Dashboard에서 `BLE: OFF` 확인 → Side C 2초로 재페어링

**원인 3:** 자이로 캘리브 실패
- **해결:** 기기를 평평한 곳에 놓고 웹 UI의 "자이로 캘리브" 클릭

### 버튼이 눌린 채로 멈춤 (stuck)

**원인:** BLE 신호 끊김, 배터리 부족
- **해결:** 웹 UI의 "강제 릴리즈" 클릭
- 또는 기기 재부팅

### 스크롤이 너무 빠름 / 느림

- **빠름:** `wheel_threshold_deg`를 높임 (60 → 100)
- **느림:** `wheel_threshold_deg`를 낮춤 (90 → 60)

웹 UI의 Config 탭에서 조정.

### 스크롤 중 커서가 같이 움직임

- `scroll_cursor_damp`를 낮춤 (0.25 → 0.1)
- `0.0`으로 설정하면 커서 완전 정지

### 정지 상태에서 커서가 떨림

- **Precision Mode** 활성화 (Mode: MED)
- 또는 `zero_snap` 조정 (개발자 문의)

### 제스처가 오작동

- `flick.p2p_th` 상향 (400 → 600)
- `flick.cooldown_ms` 상향 (600 → 900)

### 배터리가 빨리 닳음

- 절전 시간 확인 (`sleep_idle_timeout_ms` = 60000ms)
- LED 밝기 낮춤 (`led_brightness` 128 → 64)
- 사용 안 할 땐 전원 OFF

### 페어링이 안 됨

- **Side C 2초 hold** → 페어링 모드
- LED가 1Hz 깜빡이는지 확인
- 기존 페어링 삭제: 호스트의 Bluetooth 설정에서 "Elite AirMouse S3" 삭제 후 재시도

### SafeBoot 모드 진입

**증상:** 부팅 후 LED가 파란색이지만 커서가 안 움직임, 웹 UI 접속 시 "-SAFE" 붙은 AP 표시

**원인:** 이전 부팅이 2회 연속 비정상 종료

**해결:**
1. 웹 UI 접속 (`EliteAirMouse-SAFE`)
2. Config 탭에서 Rollback 또는 Factory Reset
3. 또는 `/api/safeboot {exit:true}` API

### Factory Reset 방법

**웹 UI:**

- Dashboard → Factory Reset → 확인

**부팅 시:**

- Top M (13번 GPIO) 을 6초 이상 누른 채 부팅

**결과:** 모든 설정/부팅 상태 초기화 후 재부팅.

## 📚 부록: 웹 UI 파라미터 설명

### scale_base [3]

DPI 1/2/3 단계별 기본 감도 배율.

| 값 | 효과 |
|---|---|
| 0.55 | DPI 1: 느림 |
| 0.75 | DPI 2: 중간 |
| 1.00 | DPI 3: 빠름 |

### accel_gain [3]

DPI 단계별 가속 강도. 높을수록 빠른 스윙에 크게 반응.

### accel_threshold

가속 시작 임계. 이 값 이하의 움직임은 가속 없음.

### scroll_cursor_damp

Front Hold 중 커서 감쇠율.
- `0.25` = 25% 속도
- `0.0` = 커서 완전 정지

### wheel_threshold_deg

스크롤 반응 임계 기울기. 낮을수록 민감.

### wheel_step_max

스크롤 한 번에 최대 이동량.

### gesture.flick_deg

제스처 인식 최소 회전 속도. 낮으면 민감.

### gesture.cooldown_ms

제스처 인식 후 재인식까지 대기 시간.

### precision.deadzone

정밀 모드 진입 시 커서 무시 영역.

### precision.gain

정밀 모드 감도 (낮을수록 느림).

### led_brightness

LED 밝기 (0~255).

## 🎯 활용 시나리오

### 시나리오 1: 회의실 프레젠테이션

1. 회의실 TV에 페어링
2. Side C 더블클릭 → Mode 2 (초록 LED)
3. Top L 클릭으로 슬라이드 넘김
4. Side C 클릭으로 레이저 포인터 ON
5. Top M Hold + 움직임 → 포인터 이동
6. 발표 종료 후 Side C 더블클릭 → Mode 3

### 시나리오 2: 거실 HTPC (Kodi / Plex)

1. HTPC에 페어링
2. Mode 1 (파랑 LED)
3. Top M Hold + 움직임 → 커서 이동
4. Side F Hold + 위/아래 → 목록 스크롤
5. Top L 클릭 → 항목 선택

### 시나리오 3: 스마트 TV

1. TV에 페어링
2. Side C 더블클릭 → Mode 3 (주황 LED)
3. Top M 놓고 위/아래 기울여 유지 → 메뉴 네비게이션
4. Top M 클릭 → 확인
5. Top L 클릭 → 뒤로가기

### 시나리오 4: 침대에서 PC 조작

1. 노트북에 페어링
2. Mode 1
3. Top M Hold + 손목 움직임 → 커서 이동
4. Side C 클릭 → 동영상 재생
5. Side F Hold + 위/아래 → 스크롤

## 🎓 팁 & 요령

### 커서 미세 조정

- DPI를 1로 낮춤
- Precision Mode 활성화 (MED)
- Zero Snap 자동 작동 (매우 느린 움직임 무시)

### 빠른 커서 이동

- DPI를 3으로 높임
- 큰 손목 동작 (Sigmoid 가속으로 자연 가속)
- 화면 반대편: 손목 크게 회전

### 커서와 클릭 분리

- 커서 이동 중엔 Top M 을 놓음 → 커서 정지
- 놓은 상태에서 Top L 클릭 → 정확한 클릭

### 배터리 절약

- 사용 안 할 땐 전원 OFF
- LED 밝기 낮춤
- 60초 자동 절전 신뢰

### 스크롤 정확도

- Side F Hold 중엔 커서 25% 감쇠 → 정확한 스크롤
- 필요 시 `scroll_cursor_damp` 0.0으로 완전 정지
