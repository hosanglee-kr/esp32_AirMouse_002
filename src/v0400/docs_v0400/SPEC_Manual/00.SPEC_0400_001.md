2. 하드웨어 최종

2-1. 물리 배치

```
        [Top]
     [L] [M] [R]
     
   ┌──────────────┐
[F]│              │
[C]│              │  [측면 좌측]
[R]│              │
   └──────────────┘
```

2-2. GPIO 배정

기능 GPIO RTC Wake
I2C SDA 4 ✓ -
I2C SCL 5 ✓ -
MPU INT1 6 ✓ WoM
Top L 12 ✓ EXT1
Side C 13 ✓ EXT1
Side F 14 ✓ EXT1
Top R 15 ✓ EXT1
Top M 16 ✓ EXT1
Side R 7 ✓ EXT1
WS2812 DIN 21 ✗ -
Battery ADC 1 ✗ (미구현)

2-3. Wake 회로

```cpp
// MPU6050 INT: open-drain, active-low
writeRegister(MPU6050_INT_PIN_CFG, 0x80);  // INT_OD=1, INT_LEVEL=0
writeRegister(MPU6050_INT_ENABLE, 0x40);   // MOT_EN

// ESP32 EXT1: 모든 소스 LOW active
esp_sleep_enable_ext1_wakeup(
    BIT64(6) | BIT64(7) | BIT64(12) | BIT64(13) | BIT64(14) | BIT64(15) | BIT64(16),
    ESP_EXT1_WAKEUP_ANY_LOW
);

// Wake 후 소스 구분
uint64_t status = esp_sleep_get_ext1_wakeup_status();
```

```
ESP32-S3 GPIO21 ──> WS2812 DIN
라이브러리: Adafruit_NeoPixel (RMT 기반)
밝기: config `led_brightness` (0~255)
```

3. IMU 좌표계 (확정)

3-1. 용어 정의 (문서/웹/코드 주석 통일)

사용자 용어 물리 축 코드 변수 용도
Roll (긴 축) gy v_gy 커서 좌우, 휠
Pitch (좌우 축) gx v_gx 커서 상하
Yaw (수직 축) gz v_gz Flick 좌우

3-2. Zero-rate Bias Tracking

런타임 지속 보정 (기존 1회 캘리브 확장):

```cpp
매 프레임:
  if (|gx| + |gy| + |gz| < 2.0f):
     still_count++
     if (still_count > 250ms):
        bias_x = bias_x * (1-0.001f) + gx * 0.001f
        bias_y = ...
        bias_z = ...
  else:
     still_count = 0
```

웹 노출: Action Registry "Gyro Recalibration" — bias 즉시 리셋 + 재수집 시작.

3-3. 상보 필터 (유지)

```cpp
_roll  = 0.98f * (_roll  + gy * dt) + 0.02f * accelRoll
_pitch = 0.98f * (_pitch + gx * dt) + 0.02f * accelPitch
```

4. 모드 시스템 (확정)

4-1. 3 Modes

Mode 이름 LED 색 주 용도
1 PC Air Mouse Blue PC 커서/클릭
2 Presentation Green PPT 슬라이드/제스처
3 Smart TV Orange TV D-Pad/미디어

4-2. 전환 (고정)

트리거 동작
Side Center Double Click Mode 1 → 2 → 3 → 1 순환
Side Center Long Click (2초+) Pairing Mode 진입 (LED White Blink)
Side Center 3초 Hold + Top L Click Multi-Host Peer 순환

Mode 전환 피드백:

· 신규 Mode 색 0.5초 solid → 사용자 밝기로 복귀

4-3. 모드별 고정 vs 설정

고정 (Config 불가, 하드코딩):

· Top L Hold = 마우스 좌클릭 유지 (드래그)
· Top M Hold = IMU 활성화 (Push-to-Activate)
· Side Center Double/Long/3초 = 모드 전환/페어링/호스트 순환
· Mode 3: Top M Click = Enter (D-Pad Select)
· Mode 2: Top L Click = 다음 슬라이드
· Mode 1: Top L Click = 마우스 좌클릭

설정 가능 (사용자 선택, 아래 §6):

· Top L Double/Long
· Top M Click (Mode 1, 2만)
· Top R Click/Double/Long
· Side F/R Click/Long
· Side C Click (Mode별)
· 제스처 Flick L/R/U/D
· Linear 4방향 (Middle Hold 중)
· Tilt Hold (Mode 3)

5. Action Registry

5-1. Action Kind

```cpp
enum EN_ACTION_KIND_t : uint8_t {
    ACT_NONE          = 0,
    ACT_MOUSE_CLICK   = 1,   // param16: mask, hold 지원
    ACT_MOUSE_WHEEL   = 2,   // param16: axis(bit4-7) | dir(bit0-3)
    ACT_KB_TAP        = 3,   // param16: usage, param32: modifier
    ACT_KB_COMBO      = 4,   // param32: mod|u1|u2|u3 packed
    ACT_CONSUMER      = 5,   // param32: 32-bit consumer mask
    ACT_SPECIAL       = 6,   // param16: EN_SPECIAL_t
    ACT_MOUSE_HOLD    = 7,   // param16: mask (release on up)
    ACT_KB_REPEAT     = 8,   // param16: usage, hold repeat
    ACT_CONSUMER_REPEAT = 9, // param32: mask, hold repeat
};

enum EN_SPECIAL_t : uint8_t {
    SP_NONE          = 0,
    SP_GYRO_RECALIB  = 1,
    SP_SLEEP_NOW     = 2,
    SP_MODE_CYCLE    = 3,   // 내부용 (예약)
    SP_PAIRING       = 4,   // 내부용
};
```

5-2. Action 구조

```cpp
struct ST_Action_t {
    uint8_t  kind;      // EN_ACTION_KIND_t
    uint8_t  holdMode;  // 0=NONE, 1=PRESS_HOLD, 2=REPEAT
    uint16_t param16;
    uint32_t param32;
};  // 8 bytes
```

8. 전원 관리

8-1. Light-sleep

```cpp
if (idle_60s && !any_hold_active) {
    // 1) 진행 중 hold/repeat 해제
    release_all_actions();
    
    // 2) HID release
    mouse.release_all();
    keyboard.release_all();
    
    // 3) LED off
    led.off();
    
    // 4) Wake 소스
    esp_sleep_enable_ext1_wakeup(mask, ANY_LOW);
    
    // 5) 진입
    esp_light_sleep_start();
    
    // 6) Wake 후
    wake_source = esp_sleep_get_ext1_wakeup_status();
    // bias 재수집, FSM 재시작
}
```

Idle 판정 리셋 조건:

· 물리 버튼 변화
· IMU 유의미 움직임 (WoM 임계)
· BLE 이벤트

8-2. 배터리 (향후)

· battery_adc_enabled = false (기본)
· config 필드만 존재
· 코드 훅만 (#if 0)

11. Multi-Host 페어링

11-1. 요구

· 최대 3 peer bonding 슬롯
· 버튼 조합으로 순환 전환

11-2. 전환 UX

```
Side Center Hold (3초) + Top L Click
  ↓
1. 현재 HID disconnect
2. bond 슬롯 순환 (1→2→3→1)
3. 해당 peer로 connect 시도
4. LED: 전환 중 White Blink, 성공 시 Mode 색
5. 실패 시 이전 peer 복귀 (5초 타임아웃)
```

11-3. 저장

· Bond 정보: NimBLE 자동 (NVS)
· 현재 활성 peer index: config 저장

12. 제스처 알고리즘

12-1. Flick (Peak-to-Peak)

```cpp
// 200ms 슬라이딩 윈도우
gz_window.push(gz);
peak_max = max(gz_window);
peak_min = min(gz_window);
p2p = peak_max - peak_min;

if (p2p > 400.0f && cooldown_elapsed) {
    sign = (|peak_max| > |peak_min|) ? +1 : -1;
    if (sign > 0) trigger_flick_left();   // Roll
    else trigger_flick_right();
    cooldown_start();
}
```

활성 조건 (D15):

· L/R Flick: Middle Hold 상태 무관 (기존 유지)
· U/D Flick: Middle Hold 해제 시만
· Mode 2, 3만 활성 (Mode 1은 옵션)

12-2. Linear 4방향

활성 조건 (D14): Middle Hold 중만

```cpp
if (MiddleHeld) {
    // 중력 제거
    a_lin = a_raw - R(roll, pitch) * g;
    
    // 축별 임펄스 적분
    for axis in {x, y, z}:
        if (|a_lin[axis]| > 0.3f):
            window[axis] += a_lin[axis] * dt;
    
    // 300ms 윈도우 종료
    if (window_elapsed) {
        dominant = argmax(|window[axis]|);
        if (|window[dominant]| > 0.5f):
            trigger_linear(dominant, sign(window[dominant]));
        reset_windows();
    }
} else {
    reset_windows();
}
```

12-3. Tilt Hold (Mode 3, D23)

활성 조건: Middle Hold 해제 + Mode 3

```cpp
// 상보 필터 roll/pitch 기반
if (|roll| > 15° || |pitch| > 15°) {
    if (tilt_hold_timer > 300ms) {
        direction = 판정(roll, pitch);
        if (repeat_elapsed >= 333ms) {  // 3Hz
            trigger_dpad(direction);
            repeat_start();
        }
    }
} else {
    tilt_hold_timer = 0;
}
```

방향 판정: 지배 축 + 부호.
