# 📊 파워포인트 프레젠테이션 모드 단축키 요약

발표의 흐름을 끊지 않고 전문적으로 진행하기 위한 필수 단축키들입니다.

---

## 1. 슬라이드 쇼 시작 및 종료
| 단축키 | 기능 |
|:---:|---|
| **F5** | 첫 번째 슬라이드부터 시작 |
| **Shift + F5** | 현재 선택된 슬라이드부터 시작 |
| **Alt + F5** | 발표자 도구 모드로 시작 |
| **Esc** | 슬라이드 쇼 종료 |

---

## 2. 슬라이드 이동 및 화면 제어
| 단축키 | 기능 |
|:---:|---|
| **N / Enter / Space** | 다음 슬라이드 또는 애니메이션 진행 |
| **P / Backspace** | 이전 슬라이드 또는 애니메이션으로 이동 |
| **숫자 + Enter** | 해당 페이지 번호로 즉시 이동 |
| **B** | 화면 블랙아웃 (시선 집중용) |
| **W** | 화면 화이트아웃 |
| **S** | 자동 전환 일시 중지/재개 |

---

## 3. 포인터 및 그리기 도구 (판서)
| 단축키 | 기능 |
|:---:|---|
| **Ctrl + L** | 레이저 포인터 활성화 |
| **Ctrl + P** | 펜 도구로 변경 |
| **Ctrl + I** | 형광펜 도구로 변경 |
| **Ctrl + E** | 지우개로 변경 |
| **E** | 화면의 모든 판서 지우기 |
| **Ctrl + M** | 잉크 주석 표시/숨기기 |
| **Ctrl + H** | 마우스 포인터 즉시 숨기기 |

---

## 4. 유용한 추가 기능
| 단축키 | 기능 |
|:---:|---|
| **F1** | 슬라이드 쇼 도움말(단축키 목록) 보기 |
| **Ctrl + '+' / '-'** | 화면 확대 및 축소 |
| **Ctrl + T** | 작업 표시줄 보기 |

---

> **💡 Tip:** 발표 중 특정 슬라이드로 급하게 돌아가야 할 때 **'숫자 + Enter'**를 활용하면 청중 앞에서 당황하지 않고 페이지를 넘길 수 있습니다.
