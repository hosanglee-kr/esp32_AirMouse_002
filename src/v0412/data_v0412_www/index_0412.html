마우스 기본 특성 (E10 Core)

마우스 기본 이동 감도 (1~3단계)
버튼을 누를 때 손가락 힘으로 화살표가 미끄러지는 현상 방지
0 (꺼짐) ~ 255 (최대 밝기)
손목을 빠르게 스냅할 때 가속이 붙기 시작하는 기준 속도
스크롤 중 화살표 이동 속도 감속 비율 (0.25 = 25%로 감속)

모드별 세부 감도 (Arrays)

PC / PPT / TV 모드별 기본 속도 배율
빠른 손목 스냅 시 추가 가속 계수
스크롤 시작 기울기 각도(도) / 1회 최대 스크롤 스텝
손목 털기 인식 각속도(도/초) / 중복 방지 대기시간(ms)

동작 정밀도 고도화 (Phase 1: 클릭 순간 커서 동결 Click-Freeze)

클릭 버튼을 누르는 순간 손가락 힘으로 화살표가 튀는 현상 방지
이 회전 속도(deg/s) 이하의 미세 떨림 상태에서만 동결 발동
150ms 초과 시 드래그(끌기) 동작으로 판정하여 동결 자동 해제
버튼에서 손을 뗄 때 발생하는 미세 튕김 방지 시간 (ms)
동결 상태에서 정상 화살표 이동으로 부드럽게 복귀하는 시간 (ms)
손목을 의도적으로 움직여 동결을 즉시 풀기 위한 이동 거리 (px)
동결 중 빠른 움직임이 감지되면 즉시 잠금을 해제하는 회전 속도 (deg/s)

동작 정밀도 고도화 (Phase 2: 지능형 손떨림 억제 Adaptive EMA)

정지 및 느린 이동 시 손떨림 필터링 강도 (낮을수록 더 부드러움)
빠른 손목 이동 시 지연 없는 즉시 반응 강도 (0.80 권장)
이 속도 이하에서 최대 스무딩(부드러움) 필터 적용 (rad/s)
이 속도 이상에서 필터를 끄고 지연 없이 즉각 반응 (rad/s)
좌↔우 급회전으로 인식할 반대 방향 각속도 기준 (rad/s)
방향을 갑자기 바꿀 때 뒤따라오는 위상 지연(랙)을 즉각 리셋

동작 정밀도 고도화 (Phase 3: 발표용 수평/수직 축 스냅 Snap-to-Axis)

슬라이드 밑줄 긋기 및 도표 지칭 시 수평/수직 직선 자동 정렬
축 스냅 기능을 활성화할 동작 모드 선택
직선 보정을 허용할 이동 방향 범위
한쪽 축으로의 움직임이 다른 축 대비 4배 우세할 때 직선 고정 (2.0~10.0)
1.0=완전 직선 유지, 낮을수록 부드러운 유도 (0.85 권장)
대각선 떨림으로 인한 오작동 방지 연속 판정 횟수 (3프레임 = 24ms)

절전 및 전원 관리 (P20 2단계 절전 & 자동 슬립)

블루투스 미연결 시 라이트 슬립 진입 대기 시간 (기본 60초, 흔들거나 클릭 시 깨어남, 0=끄기)
배터리 방전 방지 완전 절전 진입 대기 시간 (기본 600초 = 10분, 0=끄기)
잠든 마우스를 흔들어 깨울 때의 가속도 민감도 (기본 25 = 약 0.8g, 낮을수록 살짝 흔들어도 깸)
유효한 흔들림 동작으로 판정하는 최소 지속 시간 (ms)
슬립 모드 진입 시 빨간색 표시등이 부드럽게 페이드아웃되는 시간 (ms)
슬립 해제 직후 센서 영점 재수집 및 오작동 방지 대기 시간 (ms)

버튼 디바운스 및 타이밍 (C20 스위치 떨림 방지 & 판정 시간)

버튼을 누를 때 스위치 접점 떨림을 걸러내는 시간 (20ms 권장, 낮을수록 빠른 반응)
손을 뗄 때 발생하는 미세 튕김 방지 시간 (30ms 권장, 노후 스위치 더블클릭 오작동 방지)
단일 클릭으로 판정할 수 있는 최대 누름 유지 시간 (250ms 권장)
더블클릭으로 인정하는 첫 클릭과 두 번째 클릭 사이의 최대 시간 간격 (300ms 권장)
버튼을 꾹 길게 누르고 있는 동작으로 인식하기 시작하는 시간 (600ms 권장)
옷깃 스침이나 정전기로 인한 30ms 미만의 극히 짧은 신호는 클릭에서 완전 무시
