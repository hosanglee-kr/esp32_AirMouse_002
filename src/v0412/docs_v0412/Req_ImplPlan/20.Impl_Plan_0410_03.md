
### 7.10. 포인팅 정밀도 & 모션 알고리즘 고도화 (v0412)

> **목적**: 손떨림 억제, 클릭 순간 커서 동결, 발표용 축 스냅을 통해 실사용 정밀도 향상.
> **적용 범위**: M10 (물리 엔진), E10 (Motion 파이프라인), C10 (Config 스키마), W10 (UI 파라미터 노출)

#### 7.10.1. 모션 처리 파이프라인 (단방향, 6단계)

```
[MPU6050 Raw Gyro]
       │
       ▼
[Step 1: Adaptive Variable EMA]   ← M10 내부 (Smoothstep α + Reversal Reset)
       │
       ▼
[Step 2: Zero Snap / Deadband]    ← M10 내부
       │
       ▼
[Step 3: Sigmoid 가속]            ← M10 내부
       │
       ▼
[Step 4: Precision FSM]           ← E10 _applyPrecision()
       │
       ▼
[Step 5: Snap-to-Axis]            ← E10 _applySnapToAxis() (신규)
       │
       ▼
[Step 6: Click-Freeze 게이트]     ← E10 _applyClickFreeze() (신규)
       │
       ▼
[BLE HID Mouse Report]
```

**원칙**: 각 단계는 **단방향**으로만 이전 단계 출력을 소비. 후단에서 전단을 되돌리지 않음.

#### 7.10.2. Adaptive Variable EMA

**기존 이진 LPF 대체**:
```cpp
// 기존
float alpha = (delta > 3.0f) ? 0.50f : 0.12f;

// 신규 (Smoothstep)
float t = (|ω| - deadzone_th) / (fast_th - deadzone_th);
float t_smooth = t * t * (3.0f - 2.0f * t);  // 3t² - 2t³
float alpha = alpha_min + t_smooth * (alpha_max - alpha_min);
```

**Reversal Reset** (부호 역전 시 EMA 상태 초기화):
```cpp
if (sign(ω) != _prevSign && |ω| > reversal_th) {
    _lpf = 0.0f;   // 완전 리셋 (대안 A)
}
```

**파라미터**:
| 이름 | 기본값 | 범위 | 설명 |
|---|---|---|---|
| `alpha_min` | 0.05 | 0.01~0.2 | 저속 최대 스무딩 |
| `alpha_max` | 0.80 | 0.5~0.95 | 고속 최소 스무딩 (raw 노이즈 차단) |
| `deadzone_th` | 3.0 | 1~10 rad/s | 저속 경계 |
| `fast_th` | 15.0 | 10~30 rad/s | 고속 경계 |
| `reversal_th` | 8.0 | 5~20 rad/s | 방향 전환 임계 |
| `reversal_reset` | true | bool | 방향 전환 시 EMA 리셋 |

**물리적 근거**: Smoothstep은 1차 도함수 연속 → 경계 Jerk 없음. Reversal Reset은 좌-우 스냅 시 위상 지연 20~30ms 제거.

#### 7.10.3. Snap-to-Axis (Mode 2 프리셋 기본 ON)

**좌표계**: 화면 좌표계(픽셀 델타) 기준. **자세 보정 이후 최종 좌표에서 연산**.

**대칭 히스테리시스**:
- 진입: `|ΔX| > |ΔY| × ratio_enter` (기본 4.0)
- 이탈: `|ΔX| < |ΔY| × ratio_enter` (자동 대칭)
- Chattering 방지: 후보 축 **3프레임 연속 유지** 시 확정

**Soft Snap**:
```cpp
// 진입 시 부축(비지배 축) 감쇠
if (_snapActiveAxis == SNAP_HORIZ) fy *= (1.0f - strength);  // 기본 strength=0.85 → 부축 15% 반영
if (_snapActiveAxis == SNAP_VERT)  fx *= (1.0f - strength);
```

**파라미터**:
| 이름 | 기본값 | 범위 | 설명 |
|---|---|---|---|
| `enable` | true | bool | 기능 온/오프 |
| `mode_mask` | 0x02 | 0~7 | Mode별 활성 비트 (0x01=Mode1, 0x02=Mode2, 0x04=Mode3) |
| `axis_mode` | "both" | enum | horizontal / vertical / both |
| `ratio_enter` | 4.0 | 2~10 | 축 판정 임계 |
| `strength` | 0.85 | 0.5~1.0 | Soft Snap 강도 |
| `confirm_frames` | 3 | 1~10 | 축 확정 프레임 수 |

#### 7.10.4. Click-Freeze (4-State FSM)

**FSM 다이어그램**:
```
[FREEZE_IDLE]
     │ Btn DOWN && |ω| < gyro_th && !moveGateHeld
     ▼
[FREEZE_LOCKED]                freeze_timer = 0
     │ ├─ freeze_timer > max_ms (150)          → IDLE (드래그 전환)
     │ ├─ |ω| > freeze_move_th (30)             → IDLE (강제 이동)
     │ └─ Btn UP                                → FREEZE_HOLD
     ▼
[FREEZE_HOLD]                  hold_timer = 0, accum = 0
     │ ├─ hold_timer >= hold_ms (20)            → FREEZE_FADEOUT
     │ └─ accum_dist > move_th (2px)            → IDLE (강제 이탈)
     ▼
[FREEZE_FADEOUT]               fade_timer = 0
     │ ├─ fade_timer >= fadeout_ms (30)         → IDLE
     │ └─ accum_dist > move_th                  → IDLE
     ▼
커서 출력: scale = fade_timer / fadeout_ms
          fx = fx_pre * scale, fy = fy_pre * scale
```

**파라미터**:
| 이름 | 기본값 | 범위 | 설명 |
|---|---|---|---|
| `enable` | true | bool | 기능 온/오프 |
| `gyro_th` | 15.0 | 5~30 deg/s | 정지 클릭 판정 |
| `max_ms` | 150 | 50~300 ms | 드래그 판정 임계 |
| `hold_ms` | 20 | 0~50 ms | UP 후 완전 동결 |
| `fadeout_ms` | 30 | 0~80 ms | 감쇠 시간 |
| `move_th` | 2.0 | 1~10 px | 강제 이탈 변위 |
| `freeze_move_th` | 30.0 | 10~60 deg/s | 이동 의도 판정 |

**Move Gate 우선순위**: `_moveGateHeld == true` 상태에서는 Freeze FSM 무시 (드래그 확정).

**누적 변위 정확도**: 매 프레임 `_accumDx += rawDx; _accumDy += rawDy;`로 벡터 누적 후 `sqrt(accumDx² + accumDy²)²` 비교.

#### 7.10.5. Config 스키마 확장

```json
{
  "e10": {
    "motion_adv": {
      "click_freeze": {
        "enable": true,
        "gyro_th": 15.0,
        "max_ms": 150,
        "hold_ms": 20,
        "fadeout_ms": 30,
        "move_th": 2.0,
        "freeze_move_th": 30.0
      },
      "ema": {
        "alpha_min": 0.05,
        "alpha_max": 0.80,
        "deadzone_th": 3.0,
        "fast_th": 15.0,
        "reversal_th": 8.0,
        "reversal_reset": true
      },
      "snap": {
        "enable": true,
        "mode_mask": 2,
        "axis_mode": "both",
        "ratio_enter": 4.0,
        "strength": 0.85,
        "confirm_frames": 3
      }
    }
  }
}
```

**검증 규칙 (`validateE10`)**:
- `alpha_min < alpha_max`
- `deadzone_th < fast_th`
- `0.5 ≤ strength ≤ 1.0`
- `ratio_enter ≥ 2.0`
- `mode_mask ≤ 7`

#### 7.10.6. Mode별 프리셋

| 프리셋 | freeze.enable | ema (min~max) | snap.enable / mask |
|---|---|---|---|
| **PC (Mode 1)** | true | 0.05~0.80 | false / 0x00 |
| **PPT (Mode 2)** | true | 0.05~0.80 | true / 0x02 |
| **TV (Mode 3)** | false | 0.10~0.85 | false / 0x00 |
| **게임** | false | 0.15~0.90 | false / 0x00 |
| **정밀 (문서/그래프)** | true | 0.03~0.70 | false / 0x00 |

#### 7.10.7. 모듈 책임 분리

| 계층 | 담당 |
|---|---|
| **M10** | Adaptive EMA (Smoothstep + Reversal Reset), Zero Snap, Sigmoid |
| **E10 (Task)** | 파이프라인 오케스트레이션, DPI 스케일링, Precision FSM, Snap, Click-Freeze |
| **E10 (Motion)** | `_applyPrecision`, `_applySnapToAxis`, `_applyClickFreeze` |
| **C10** | `motion_adv` 스키마 + 검증 |
| **W10** | Config 탭 신규 섹션 (모션 고급 설정), 프리셋 버튼 |

#### 7.10.8. 실측 검증 계획 (구현 전)

| # | 측정 항목 | 방법 | 판정 기준 |
|---|---|---|---|
| 1 | 클릭 시 커서 튐 폭 | 5명 × 20회 | baseline: 3~10px |
| 2 | 튐 지속 시간 | IMU 로그 | baseline: 30~80ms |
| 3 | 손떨림 대역 | 30초 정지 FFT | 생리적: 8~12Hz |
| 4 | 방향 전환 지연 | 좌-우 스냅 도달 | baseline: 20~30ms |
| 5 | PPT 직선 편차 | 20회 반복 | 목표: < 3px |

**Phase 1 (프로토타입)**: Click-Freeze만 먼저, A/B 테스트 (프리즈 on/off)  
**Phase 2 (EMA 교체)**: 기존 이진 LPF → Smoothstep, 회귀 테스트  
**Phase 3 (Snap)**: 트리거 기반 프로토타입 → Mode 2 프리셋 확정
