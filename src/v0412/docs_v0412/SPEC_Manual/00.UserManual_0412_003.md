# Elite AirMouse S3 — v0412 사용자 매뉴얼

- 파일명 : 00.UserManual_0412_003.md

* **기기 개요**
  * 모델: 모션 센서 기반 3가지 모드(모드 1: PC (마우스), 모드 2: 프레젠테이션, 모드 3: 스마트 TV)
  * 연결 및 기능: 무선 블루투스(마우스·키보드·미디어 제어 통합 지원), WS2812 RGB 상태 표시등, 지능형 2단계 자동 절전 탑재
  * v0412 주요 기능: 최대 5개 맞춤 설정 저장 공간(프로필) 제공, 8단계 연속 동작(매크로) 8개 지원, 2단 기능 배정 방식(기본 공통 및 모드별 덮어쓰기) 지원
  * **웹 설정 환경 (v0414)**: 한국어/영문 원클릭 전환(KO/EN, 361개 키 전수 표준화), 하이브리드 가상 컨트롤러(Virtual Remote) 및 모드별 빠른 도구 탑재
  * **v0412 신규**:
    - **동작 정밀도**: 클릭 시 포인터 고정(Click-Freeze), 적응형 손떨림 보정(Adaptive EMA), 프레젠테이션 축 스냅(Snap-to-Axis)
    - **전원 관리**: 2단계 절전(60초 라이트 슬립 + 10분 딥 슬립), 모션 흔듦 감지(WoM) 및 버튼 즉시 깨어남, 부드러운 LED 페이드 복원, 슬립 복귀 후 자이로 영점 고속 재수집(Fast Recalibrate)
    - **버튼 타이밍**: 비대칭 디바운스(누름 20ms / 뗌 30ms), 2-Stage 하이브리드 판정, 스위치 채터링 방지(30ms 미만 초단 글리치 필터)
  * 문서 대상: 최종 사용자(일반 사용자, 발표자, 게이머, 스마트 TV 사용자)
  * 소프트웨어 버전: **v0412** (웹 에셋: **v0414**)

## 📌 30초 요약 (처음 사용자용)

* **1단계: 전원 켜기**
  * 스위치 ON 조작 시 상태 표시등 파란색 점등 확인(모드 1: PC (마우스) 모드 진입)
* **2단계: 기기 연결(페어링)**
  * PC나 스마트폰의 블루투스 설정 화면에서 "Elite AirMouse S3" 검색 후 연결 진행
* **3단계: 포인터(화살표) 이동**
  * 윗면 가운데 버튼(Top M)을 누른 상태에서 손목을 움직여 마우스 화살표 조작
* **4단계: 좌클릭 및 끌기(드래그)**
  * 윗면 왼쪽 버튼(Top L)을 누르면 클릭 동작 수행, 누른 채로 움직이면 끌기(드래그) 동작 수행
* **5단계: 우클릭**
  * 윗면 오른쪽 버튼(Top R)을 누르면 마우스 우클릭 동작 수행
* **6단계: 모드 변경**
  * 측면 가운데 버튼(Side C)을 연속 두 번(더블클릭) 누르면 모드 순환 전환
  * 1번 PC (마우스) 모드(파란색) → 2번 프레젠테이션 모드(초록색) → 3번 스마트 TV 모드(주황색)
* **7단계: 화면 스크롤 및 좌우 이동(팬)\***
  * 측면 앞쪽 버튼(Side F)을 누른 상태에서 마우스를 위·아래로 기울이면 상하 스크롤 작동
  * 측면 앞쪽 버튼(Side F)을 누른 상태에서 마우스를 좌·우로 기울이면 좌우 화면 이동(팬) 작동
* **8단계: 상세 설정 웹 화면 접속**
  * WiFi 연결 후 웹브라우저 주소창에 `http://192.168.4.1` 입력하여 가상 컨트롤러, 한국어/영어(KO/EN) 선택, 맞춤 프로필(최대 5개), 27개 동작 매핑, 연속 동작(매크로) 설정 화면 접근 가능

> **각주 1 (팬 / Pan):** 카메라나 시선을 좌우로 돌리듯, 긴 문서나 넓은 웹페이지를 좌우로 밀어서 이동하는 기능(가로 스크롤)을 의미함.

## 🔋 기본 연결 및 작동법

### 1단계: 전원 켜기

* 측면 또는 하단 스위치를 켜면 상태 표시등이 파란색으로 켜지며 PC 기본 모드로 대기함

### 2단계: 기기 연결(블루투스 페어링)

* **PC (Windows / Mac / Linux)**: 블루투스 설정에서 "Elite AirMouse S3" 선택 후 연결
* **스마트폰 및 태블릿 (Android / iOS)**: 블루투스 검색 창에서 기기 선택 후 등록
* **스마트 TV (Android TV / Tizen / webOS)**: 기기 추가 화면에서 등록
* **연결 대기 모드 진입**: 기기 목록에 나타나지 않을 시 측면 가운데 버튼(Side C)을 2초간 길게 누르면 표시등이 깜빡이며 연결 대기 상태가 됨

### 3단계: 기본 마우스 조작

* 윗면 가운데 버튼(Top M) 누름 유지: 마우스 화살표 이동 허용
* 윗면 가운데 버튼(Top M) 뗌: 화살표 이동 즉시 정지(내려놓았을 때 제멋대로 움직이는 오작동 차단)
* 윗면 왼쪽(Top L): 좌클릭
* 윗면 오른쪽(Top R): 우클릭

## 🎛️ 버튼 배치 및 명칭

```
        [윗면 조작부]
     [L]   [M]   [R]      ← 상단 3개 버튼
     
   ┌─────────────┐
[F]│             │
[C]│             │        ← 좌측 측면 3개 버튼 (앞/가운데/뒤)
[R]│             │
   └─────────────┘
```

* **Top L (윗면 왼쪽)**: 좌클릭, 누른 채 이동 시 끌기(드래그)
* **Top M (윗면 가운데)**: 화살표 이동 스위치(누르고 있을 때만 커서 활성화)
* **Top R (윗면 오른쪽)**: 우클릭
* **Side F (측면 앞쪽)**: 화면 스크롤 전환 스위치
* **Side C (측면 가운데)**: 사용 모드 변경 및 연결(페어링) 스위치
* **Side R (측면 뒤쪽)**: 보조 기능 스위치

## 🖱️ 1번 모드: PC 일반 작업 모드 (표시등: 파란색)

### 커서 조작 방식

* 윗면 가운데(Top M)를 누른 상태로 공중에서 손을 움직이면 마우스 화살표가 반응함
* 버튼을 떼면 화살표가 멈추므로 조작 안전성이 확보됨

### 공장 초기 버튼 매핑

| 버튼 | 동작 |
|---|---|
| Top L 한 번 누름 | 좌클릭 |
| Top L 길게 누름 | 좌클릭 누른 상태 유지(끌기/드래그) |
| Top L 두 번 연속 누름 | 더블클릭 |
| Top R 한 번 누름 | 우클릭 |
| Top R 두 번 연속 누름 | 취소(ESC 키) |
| Top R 길게 누름 | 화면 캡처 창 열기(Win + Shift + S) |
| Top M 한 번 누름 | 마우스 휠 클릭 |
| Side F 한 번 누름 | 음량 키우기 |
| Side F 길게 누름 | 다음 곡 재생 |
| Side R 한 번 누름 | 음량 줄이기 |
| Side R 길게 누름 | 이전 곡 재생 |
| Side C 한 번 누름 | 재생 및 일시정지 |

### 화면 스크롤 및 가로 화면 이동(틸트)\*

* Side F를 누른 채 기기 앞머리를 위나 아래로 기울임: 상하 페이지 스크롤
* Side F를 누른 채 기기를 좌측이나 우측으로 기울임: 좌우 가로 화면 이동(팬)
* 손을 놓으면 일반 화살표 조작 상태로 복귀하며 조작 중에는 화살표 이동 속도가 평소의 25% 수준으로 정밀 감속됨

### 공중 제스처 조작(선택 기능)

* 손목을 좌/우로 휙 돌림: 가상 바탕화면 전환(Ctrl + Win + 방향키)
* 손목을 위로 휙 올림: 모든 창 내리고 바탕화면 보기(Win + D)
* 손목을 아래로 휙 내림: 실행 중인 창 전환(Alt + Tab)
* 상하 제스처는 윗면 가운데(Top M) 버튼에서 손을 뗀 상태에서만 인식됨

> **각주 2 (틸트 / Tilt):** 기기를 수평 상태에서 앞뒤나 좌우 방향으로 비스듬히 기울이는 동작을 의미함.

### ✨ [v0412 신규] 클릭 정밀도 향상 기능

* **클릭 순간 커서 동결**: 마우스 좌클릭 시 손가락 압력으로 화살표가 미세하게 튀는 현상을 자동 감지하여 순간적으로 잡아줌(기본 활성화)
* **지능형 손떨림 억제**: 정지 상태의 미세한 떨림은 부드럽게 걸러내고, 빠른 손목 동작은 지연 없이 즉시 반응함
* 별도 설정 없이 자동 작동하며, 세부 조정은 웹 UI의 '동작 정밀도' 탭에서 가능

## 🎤 2번 모드: 발표 모드 (표시등: 초록색)

### 진입 방법

* 측면 가운데(Side C)를 두 번 연속 누름(표시등이 초록색으로 변경되며 흰색으로 0.5초 깜빡임)

### 발표 화면 제어 버튼 매핑

| 버튼 | 동작 |
|---|---|
| Top L 한 번 누름 | 다음 슬라이드 넘김(PageDown) |
| Top L 두 번 연속 누름 | 이전 슬라이드 넘김(PageUp) |
| Top L 길게 누름 | 현재 쪽부터 슬라이드 쇼 재생(Shift + F5) |
| Side F 한 번 누름 | 다음 슬라이드 |
| Side R 한 번 누름 | 이전 슬라이드 |
| Side R 길게 누름 | 슬라이드 쇼 종료(ESC) |
| Top R 한 번 누름 | 쇼 종료(ESC) |
| Top R 두 번 연속 누름 | 화면 일시 숨김(검은 화면 전환, B 키) |
| Top R 길게 누름 | 흰 화면 전환(W 키) |

### 포인터 및 가상 레이저 조작

* Top M 누른 채 이동: 화살표 포인터 이동
* Top M 한 번 누름: 화면 내 빨간색 레이저 포인터 켜기(Ctrl + L)
* Side C 한 번 누름: 펜 → 레이저 → 일반 화살표 모드 순환 변경

### 발표 공중 제스처

* 손목 좌측 털기: 다음 슬라이드
* 손목 우측 털기: 이전 슬라이드
* 손목 위로 털기: 화면 일시 숨김(검은 화면)

### ✨ [v0412 신규] 발표용 축 스냅 (Snap-to-Axis)

* **수평/수직 자동 정렬**: 슬라이드 위에서 화살표로 밑줄을 긋거나 도표를 가리킬 때, 손목이 살짝 흔들려도 자동으로 수평 또는 수직 방향으로 정렬됨
* **동작 방식**: 화살표를 대략 수평으로 움직이면 자동으로 수평선을 유지, 수직으로 움직이면 수직선을 유지
* **자연스러운 탈출**: 대각선으로 방향을 바꾸면 자동으로 축 스냅이 해제되어 자유롭게 이동 가능
* **발표 모드 전용**: 1번 PC 모드나 3번 TV 모드에서는 자동으로 비활성화됨
* **세부 설정**: 웹 UI '동작 정밀도' 탭에서 축 스냅 강도·민감도 조정 가능

## 📺 3번 모드: 스마트 TV 모드 (표시등: 주황색)

### 진입 방법

* 2번 발표 모드 상태에서 측면 가운데(Side C)를 두 번 연속 누르면 주황색으로 전환됨

### 스마트 TV 전용 버튼 매핑

| 버튼 | 동작 |
|---|---|
| Top L 한 번 누름 | 뒤로 가기 |
| Top L 두 번 연속 누름 | 홈 화면 이동 |
| Top L 길게 누름 | 전원 켜기/끄기 |
| Top M 한 번 누름 | 선택(확인/Enter) |
| Top R 한 번 누름 | 홈 화면 이동 |
| Top R 두 번 연속 누름 | 외부 입력 목록 호출 |
| Top R 길게 누름 | 전원 끄기 |
| Side F 한 번 누름 | 음량 키우기 |
| Side F 길게 누름 | 채널 올리기 |
| Side R 한 번 누름 | 음량 줄이기 |
| Side R 길게 누름 | 채널 내리기 |
| Side C 한 번 누름 | 영상 재생 및 일시정지 |

### 기울여 유지하기(틸트 홀드)를 통한 4방향 키 제어

* 윗면 가운데(Top M)에서 손을 뗀 상태로 기기를 전후좌우로 15도 이상 기울여 유지함
* 0.3초 이상 유지 시 해당 방향의 방향키가 연속으로 입력됨(초당 3회)
* 기기를 평평하게 세우면 방향키 입력이 멈춤
* **해당 기능은 TV 화면 메뉴를 쉽게 넘기기 위한 3번 모드 전용 기능임**

> **왜 TV 모드에서만 작동하나요?** PC나 발표 중에는 손목을 자연스럽게 기울이는 상황이 많아 오작동 위험이 큽니다. TV 리모컨의 방향키 대체 용도에만 활성화했습니다.

### 커서 방식 지원

* 넷플릭스나 TV 웹브라우저 등 화살표가 필요한 앱에서는 윗면 가운데(Top M)를 누르면 에어마우스 화살표가 즉시 활성화됨

### TV 공중 제스처

* 손목 좌측 털기: 10초 뒤로 감기
* 손목 우측 털기: 10초 앞으로 빨리 감기
* 손목 위로 털기: 음소거 켜기/끄기

## 🔄 모드 전환 및 상태 표시등 규격

### 모드 순환

* Side C를 연속 두 번 누르면 1번(PC) → 2번(발표) → 3번(TV) 순서로 바뀜

### 상태 표시등 안내

| 색상 | 상태 |
|---|---|
| 🔵 파란색 켜짐 | 1번 PC 모드 정상 작동 중 |
| 🟢 초록색 켜짐 | 2번 발표 모드 정상 작동 중 |

## 🔌 충전 및 절전 모드

* **충전**: 표준 USB-C 단자를 통해 충전 진행 (5V 충전기 사용)
* **2단계 지능형 자동 절전 시스템**:
  * **1단계: 라이트 슬립 (Light-sleep)**
    - 블루투스 미연결 상태에서 **60초 동안 조작이 없으면** 자동으로 라이트 슬립에 진입합니다.
    - 진입 시 상태 표시등이 빨간색으로 약 0.8초간 서서히 어두워지며 꺼집니다(`Fadeout`).
    - **깨우기**: 마우스를 가볍게 흔들거나(WoM 모션 센서 감지) 본체의 아무 버튼이나 누르면 즉시 깨어납니다.
    - **부드러운 복귀**: 깨어날 때 현재 모드 색상 불빛이 약 0.3초간 서서히 밝아지며(`Fadein`) 원래 상태로 복원됩니다.
    - **자이로 영점 자동 보정 (Fast Recalibrate)**: 슬립 중 발생할 수 있는 센서 온도 변화로 인한 커서 쏠림을 방지하기 위해 깨어난 직후 0.3초간 자동으로 영점을 신속하게 재수집합니다.
  * **2단계: 딥 슬립 (Deep-sleep)**
    - 장시간(**기본 10분, 600초**) 동안 아무 조작이 없으면 센서 및 LED 전원을 완전히 차단하는 초절전 딥 슬립 상태로 진입하여 배터리 방전을 완벽하게 방지합니다.
    - **깨우기**: 본체의 버튼을 누르면 기기가 다시 켜집니다.
* **사용 중 오작동 방지**: 마우스 조작 버튼을 누르고 있거나 제스처/입력 동작 중일 때, 또는 웹 설정 모드 중에는 절전 모드로 진입하지 않습니다.

## 🎰 3. 버튼 및 동작 맞춤 할당 화면 (슬롯 관리)

### 개념 정의

**슬롯(Slot)**이란 27개의 물리적 누름이나 제스처 동작에 원하는 키나 마우스 기능을 배정하는 매핑 단위임

### 27가지 조작 동작 분류

* **버튼 조작 (15개)**: Top L/M/R 및 Side F/C/R의 단일 누름, 길게 누르기, 두 번 연속 누름
* **공중 제스처 (4개)**: 기기를 손목 스냅으로 동서남북 방향으로 휘두르기 (Flick)
* **선택적 제스처 (4개)**: 윗면 가운데(Top M)를 누른 상태에서 상하좌우로 이동
* **기울여 유지 (4개)**: 모드 3: 스마트 TV 전용으로 특정 방향으로 기울인 채 유지하기 (Tilt & Hold)

### 절대 수정 불가 잠금 동작 (오작동/브릭 차단용)

| 트리거 | 동작 | 잠금 사유 |
|---|---|---|
| S1 | Top L 짧게 누름 | 기본 마우스 좌클릭 및 선택 기능 (고정) |
| S5 | Top M 누르고 있음 | 포인터 이동 허용 스위치 (Move Gate 고정) |
| S12 | Side C 두 번 연속 누름 | 모드 변경 필수 스위치 (Mode Cycle 고정) |
| S13 | Side C 2초 길게 누름 | 블루투스 페어링 모드 진입 스위치 (Pairing 고정) |

### 전체 공통 적용 vs 모드별 덮어쓰기 기능

* 상단 뷰 탭에서 **기본 공통 (Global Default)**, **모드 1: PC (마우스)**, **모드 2: 프레젠테이션**, **모드 3: 스마트 TV** 중 하나를 선택하여 화면을 전환함
* 동작 이름 옆 파란색 **[G]** 표시는 기본 공통 설정을 그대로 상속받는다는 의미임
* 특정 모드에서 [G]를 클릭하면 주황색 **[M]** 표시로 바뀌며 해당 모드 전용 재정의(오버라이드)가 생성됨

### 지원되는 10가지 실행 동작 종류

| 종류 | 설명 |
|---|---|
| NONE | 동작 없음 (할당 안 함) |
| MOUSE_CLICK | 마우스 단일 클릭 (왼쪽, 오른쪽, 가운데 휠, 뒤로 가기, 앞으로 가기) |
| MOUSE_HOLD | 마우스 버튼 누른 상태 유지 (드래그용) |
| MOUSE_WHEEL | 휠 스크롤 (위/아래 또는 좌/우 팬) |
| KB_TAP | 키보드 단일 키 입력 (글자, 숫자, F1~F12 기능 키 등) |
| KB_COMBO | 단축키 조합 동시 입력 (예: Ctrl + C, Win + Shift + S 등 최대 3개) |
| KB_REPEAT | 키 반복 입력 (누르는 동안 연속 입력) |
| CONSUMER_TAP | 미디어 및 리모컨 제어 (음량 조절, 재생/일시 정지, 홈, 전원 등) |
| SPECIAL | 기기 특수 제어 (자이로 영점 조절\*, 지금 절전 모드, 호스트 기기 전환 등) |
| MACRO | 등록된 연속 동작 매크로 자동 실행 |

### 실시간 동작 확인 (Test) 및 저장

* 우측의 '테스트(Test)' 버튼을 누르면 기기 설정 저장 전에도 기능이 올바르게 실행되는지 즉시 시험 가능함
* 변경 후 반드시 상단 '저장' 버튼을 눌러야 기기 내부 플래시 메모리에 영구 저장됨

> **각주 3 (자이로 영점 조절 / Gyro Zero Calibration):** 마우스 포인터가 손을 움직이지 않아도 혼자 흐르거나 움직일 때, 평평한 바닥에 기기를 가만히 두고 자이로 센서 오프셋을 재계측하여 0점을 맞추는 교정 작업임.

## 🎬 4. 자동 연속 동작 화면 (매크로 관리)

### 개념 정의

단 한 번의 버튼 조작으로 복잡한 단축키나 연속 입력을 정해진 순서와 시간 간격에 맞춰 자동으로 실행해 주는 기능임

### 시스템 제약 규격

* 설정 세트당 최대 8개의 연속 동작을 보관 가능함
* 연속 동작 1개당 최대 8단계의 순차 명령을 넣을 수 있음
* 단계별 대기 시간(지연 시간)은 0초에서 2초(2000밀리초)까지 지정 가능함

### 생성 및 편집 절차

* **1단계**: + 새 매크로 선택 후 알기 쉬운 이름 입력
* **2단계**: + 단계 추가 버튼으로 실행할 키보드나 마우스 조작을 순서대로 나열
* **3단계**: 각 단계 사이에 프로그램이 반응할 수 있도록 적절한 지연 시간(예: 100~500밀리초) 입력
* **4단계**: '저장' 버튼을 누른 뒤 버튼 매핑 화면으로 돌아가 원하는 버튼에 해당 매크로를 연결

### 실생활 추천 활용 구성

* **작업 관리자 호출**: Ctrl + Shift + ESC 단축키를 묶어 측면 뒤쪽 버튼에 배정
* **자동 복사 후 붙여넣기**: Ctrl + C 실행 후 0.1초 뒤 Ctrl + V가 바로 실행되도록 구성
* **원터치 화면 캡처**: Win + Shift + S 실행 후 0.5초 뒤 저장 단축키가 연쇄 작동하도록 구성
* **화상회의 즉시 끄기**: 마이크 음소거(Ctrl + Shift + M)와 화면 끄기(Ctrl + Shift + V)를 연달아 실행

### 비상 중단 안전장치

동작 도중 다른 모드로 전환하거나 블루투스 연결이 끊어지면 누르고 있던 키가 컴퓨터에 계속 눌린 채로 멈추지 않도록 모든 키를 즉시 자동으로 떼어줌

## 📊 5. 마우스 민감도 및 세부 환경 설정

### 기본 파라미터

* **커서 속도(DPI)**: 1~3단계로 마우스 화살표의 기본 반응 민감도 설정
* **손떨림 보정 기능**: 공중에서 버튼을 딸깍 누를 때 손목이 흔들려 화살표가 빗나가지 않도록 일시적으로 화살표를 잡아줌
* **상태 표시등 밝기**: 본체 불빛의 밝기를 조절
* **스크롤 중 커서 속도 감속**: 화면을 위아래로 넘기는 도중에는 화살표가 마구 튀지 않도록 속도를 느리게 줄여주는 비율 설정
* **제스처 감도**: 손목을 털었을 때 이를 명령으로 인식할 회전 속도 기준 설정
* **설정 파일 백업 및 복원**: 내가 세팅한 모든 버튼 설정을 파일로 내려받거나 다른 사람의 설정을 불러오기 가능

| **PC** | 클릭 정밀, 축 스냅 OFF | 사무 작업, 일반 사용 |
| **PPT** | 클릭 정밀 + 축 스냅 ON | 발표자, 강사 |
| **TV** | 클릭 정밀 OFF, 부드러운 이동 | TV 리모컨 사용자 |
| **게임** | 지연 최소화, 필터 OFF | 게이머 |
| **정밀** | 최대 안정성, 저속 강화 | 그래픽 작업, 문서 편집 |

### ⚡ [v0412 신규] 절전 및 전원 관리 (Power Management) 설정

**웹 설정 화면의 Config 탭에서 기기의 배터리 절전 대기 시간 및 깨어남 민감도를 직접 조정할 수 있습니다:**

| 설정 항목 | 기본값 | 단위 및 범위 | 설명 |
|---|---|---|---|
| **Idle Sleep (라이트 슬립)** | 60 | 초 (0~3600) | 블루투스 미연결 시 라이트 슬립에 진입할 유휴 대기 시간 (0 입력 시 끄기) |
| **Deep Sleep (딥 슬립)** | 600 | 초 (0~86400) | 배터리 방전을 막기 위해 완전 절전 상태로 진입할 대기 시간 (600초 = 10분, 0 입력 시 끄기) |
| **WoM 감도 (흔듦 감지)** | 25 | 1~255 (32mg) | 잠자고 있는 마우스를 흔들어서 깨울 때의 가속도 감도 (기본 25 = 약 0.8g, 숫자가 낮을수록 살짝만 흔들어도 깸) |
| **WoM 지속시간** | 2 | 밀리초 (1~255) | 흔들림이 유효한 동작인지 판정하는 최소 지속 시간 |
| **LED Fade Time** | 800 | 밀리초 (100~3000) | 슬립 모드로 들어갈 때 빨간색 불빛이 부드럽게 꺼지는 시간 |
| **Wake Debounce** | 150 | 밀리초 (50~1000) | 깨어난 직후 센서 신호가 안정될 때까지 대기하는 시간 (연속 재슬립 방지) |

### 🔘 [v0412 신규] 버튼 디바운스 및 타이밍 (Button Timings) 설정

**스위치 노후화로 인한 채터링(더블클릭 오탐)이나 둔한 반응성을 내 손에 딱 맞게 정밀 튜닝할 수 있습니다:**

| 설정 항목 | 기본값 | 권장 범위 | 설명 |
|---|---|---|---|
| **Debounce Press (누름 디바운스)** | 20 ms | 10~30 ms | 버튼을 누르는 순간 접점 떨림을 걸러내는 시간 (낮을수록 클릭 반응이 즉각적임) |
| **Debounce Release (뗌 디바운스)** | 30 ms | 20~50 ms | 손을 뗄 때 발생하는 미세 튕김을 방지하는 시간 (노후 스위치의 원치 않는 더블클릭 방지) |
| **Click 인식 시간** | 250 ms | 150~400 ms | 단일 클릭으로 판정할 수 있는 최대 누름 지속 시간 |
| **Double-Click 간격** | 300 ms | 200~500 ms | 더블클릭으로 인정하는 첫 클릭과 두 번째 클릭 사이의 최대 허용 시간 간격 |
| **Long-Press 시간** | 600 ms | 400~1000 ms | 버튼을 길게 누르는 동작으로 인식하기 시작하는 시간 |
| **Min-Click 시간 (글리치 필터)** | 30 ms | 10~50 ms | 스위치 스침이나 정전기로 인한 30ms 미만의 극히 짧은 펄스는 클릭에서 완전 무시 (`DISCARD`) |

### 대시보드 (작업 현황 요약 및 문제 해결)

* 배터리 및 무선 통신 상태, 시스템 메모리 사용량 한눈에 확인
* **자이로 영점 조절 버튼**: 평평한 책상에 올린 뒤 누르면 화살표 쏠림 현상 해결
* **눌린 키 강제 해제**: 컴퓨터에 특정 키가 계속 눌려 있는 상태가 되었을 때 모든 입력을 원상복구
* **공장 초기화**: 모든 프로필과 설정을 지우고 기기 출고 상태로 복원

* 센서 통신 에러 발생 횟수 집계
* 키보드 개별 신호 즉시 전송 테스트 창 제공 (Key Test)

### 무선 펌웨어 업데이트 (OTA)

* 펌웨어 파일(.bin)을 무선으로 전송하여 기기 소프트웨어를 최신 버전으로 업데이트
* 업데이트 중에는 보안 잠금(OTA Guard)이 활성화되어 마우스/키보드 입력이 안전하게 일시 중단됨

## 🔧 자주 묻는 문제 및 해결책

### 마우스 화살표가 움직이지 않는 현상

* 윗면 가운데(Top M) 버튼을 꾹 누른 채로 움직이고 있는지 확인 필요함
* 컴퓨터의 블루투스 설정에서 연결이 끊어졌는지 확인하고 측면 가운데(Side C)를 2초간 눌러 재연결함
* 책상 위에 평평하게 내려놓은 뒤 웹 화면에서 '자이로 영점 조절'을 진행함

### 버튼이 계속 눌린 것처럼 작동하는 현상

* 무선 신호 일시 혼선으로 발생할 수 있으며 웹 화면 문제 해결 도구의 '눌린 키 강제 해제' 버튼을 클릭함

### 클릭할 때마다 화살표가 살짝 튀는 현상

* **v0412 자동 해결**: 클릭 시 포인터 고정(Click-Freeze) 기능이 기본 활성화되어 있어 자동으로 억제됨
* 그래도 문제가 지속되면 웹 UI '포인터 및 센서 설정' 탭에서 '정지 판단 자이로 임계값'을 20~25로 높임

### 화살표가 손 떨림으로 흔들리는 현상

* 웹 UI '포인터 및 센서 설정' 탭에서 **정밀 작업 프리셋**을 적용하면 저속 스무딩이 강화됨
* 'Alpha Min'을 0.03~0.04로 낮추면 더 부드러워짐

### 프레젠테이션 중 수평선이 흔들리는 현상

* **v0412 자동 해결**: 2번 프레젠테이션 모드에서는 축 스냅이 기본 활성화되어 자동으로 수평 정렬됨
* 만약 스냅이 너무 강하게 느껴지면 '고정 강도'를 0.6~0.7로 낮춤
* 스냅이 전혀 작동하지 않으면 웹 UI '포인터 및 센서 설정' 탭에서 '직선 스냅'이 '사용'인지, '적용 모드'에 2번 모드가 체크되어 있는지 확인

### 화면 스크롤이 지나치게 둔하거나 빠른 현상

* 세부 설정 화면에서 휠 스크롤 감도(Wheel Threshold) 값을 조절함

### 손목 제스처가 내 의도와 달리 자주 발동하는 현상

* 세부 설정에서 휘두르기 제스처 감도(Flick Deg) 수치를 높여 조금 더 강하게 털었을 때만 반응하도록 조정함

### 안전 부팅 모드로 켜지는 현상 (SafeBoot)

* 비정상적인 전원 종료가 반복되었을 때 시스템 보호를 위해 진입함
* 웹 화면 대시보드에서 '안전 부팅 모드 종료'를 누르면 기기가 다시 시작되며 일반 모드로 돌아옴

### 버튼을 한 번만 눌렀는데 두 번 연속 눌리는 현상 (더블클릭 오탐)

* 스위치 부품 노후화로 버튼에서 손을 뗄 때 접점이 미세하게 떨리는 채터링 현상입니다.
* **v0412 해결법**: 웹 설정 화면의 Config 탭 → `버튼 타이밍` 항목에서 `뗌 디바운스 (Release Debounce)`를 **40~50 ms**로 늘리고, `글리치 필터 (Min Click)`를 **30~40 ms**로 조정하면 스위치 교체 없이도 더블클릭 오탐이 90% 이상 제거됩니다.

### 절전 모드에서 깨어난 직후 화살표가 살짝 쏠리는 현상

* 슬립 중 내부 센서 온도가 미세하게 변화하여 발생할 수 있는 자연스러운 현상입니다.
* **v0412 자동 보정**: 마우스가 깨어난 직후 0.3초간 자이로 영점을 자동으로 고속 재수집(`Fast Recalibrate`)합니다. 마우스를 쥐고 약 0.3초간 잠시 멈춘 뒤 조작을 시작하면 화살표 쏠림이 자동으로 보정됩니다.

### 배터리를 더 오래 절약하고 싶은 경우

* 웹 설정 화면의 Config 탭 → `절전 및 전원 관리` 항목에서 `2단계 절전 (Deep Sleep)` 시간을 **300초 (5분)** 정도로 줄이면 장시간 미사용 시 완전 전원 차단 상태로 신속하게 전환되어 배터리를 최대한 아낄 수 있습니다.

## 🔒 안전 주의사항

* **물기 및 습기 차단**: 방수 설계가 적용되지 않았으므로 액체 노출 주의 필요함

* **정격 전압 충전기 사용**: 일반 규격의 5V 충전기 사용 권장
* **시스템 무선 업데이트 주의**: 소프트웨어 업데이트 진행 중 배터리가 방전되거나 전원이 꺼지면 기기가 작동 불능 상태에 빠질 수 있으므로 충전선을 연결한 상태에서 진행 권장됨
