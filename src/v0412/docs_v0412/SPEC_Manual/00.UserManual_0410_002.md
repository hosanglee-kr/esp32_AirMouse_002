# Elite AirMouse S3 — v0412 사용자 매뉴얼
 * 기기 개요
   * 모델: ESP32-S3 및 모션 센서(MPU6050) 기반 3가지 모드 에어마우스
   * 연결 및 기능: 무선 블루투스(마우스·키보드·미디어 제어 통합 지원), RGB 상태 표시등, 자동 절전 모드 탑재
   * v0412 주요 기능: 최대 5개 맞춤 설정 저장 공간(프로파일) 제공, 8단계 연속 동작(매크로) 8개 지원, 2단 기능 배정 방식(공통 및 모드별 덮어쓰기) 지원
   * 문서 대상: 최종 사용자(일반 사용자, 발표자, 게이머, 스마트 TV 사용자)
   * 소프트웨어 버전: v0412
## 📌 30초 요약 (처음 사용자용)
 * 1단계: 전원 켜기
   * 스위치 ON 조작 시 상태 표시등 파란색 점등 확인(1번 모드: PC 일반 마우스 모드 진입)
 * 2단계: 기기 연결(페어링)
   * PC나 스마트폰의 블루투스 설정 화면에서 Elite AirMouse S3 검색 후 연결 진행
 * 3단계: 포인터(화살표) 이동
   * 윗면 가운데 버튼(Top M)을 누른 상태에서 손목을 움직여 마우스 화살표 조작
 * 4단계: 좌클릭 및 끌기(드래그)
   * 윗면 왼쪽 버튼(Top L)을 누르면 클릭 동작 수행, 누른 채로 움직이면 끌기(드래그) 동작 수행
 * 5단계: 우클릭
   * 윗면 오른쪽 버튼(Top R)을 누르면 마우스 우클릭 동작 수행
 * 6단계: 모드 변경
   * 측면 가운데 버튼(Side C)을 연속 두 번(더블클릭) 누르면 모드 순환 전환
   * 1번 PC 모드(파란색) → 2번 발표 모드(초록색) → 3번 TV 모드(주황색)
 * 7단계: 화면 스크롤 및 좌우 이동(팬)*
   * 측면 앞쪽 버튼(Side F)을 누른 상태에서 마우스를 위·아래로 기울이면 상하 스크롤 작동
   * 측면 앞쪽 버튼(Side F)을 누른 상태에서 마우스를 좌·우로 기울이면 좌우 화면 이동(팬) 작동
 * 8단계: 상세 설정 웹 화면 접속
   * Wfi 연결 후 웹브라우저 주소창에 [http://192.168.4.1](http://192.168.4.1) 입력하여 맞춤 환경(최대 5개), 27개 동작 매핑, 연속 동작(매크로) 설정 화면 접근 가능
> * **각주 1 (팬 / Pan):** 카메라나 시선을 좌우로 돌리듯, 긴 문서나 넓은 웹페이지를 좌우로 밀어서 이동하는 기능(가로 스크롤)을 의미함.
>

## 🔋 기본 연결 및 작동법
 * 1단계: 전원 켜기
   * 측면 또는 하단 스위치를 켜면 상태 표시등이 파란색으로 켜지며 PC 기본 모드로 대기함
 * 2단계: 기기 연결(블루투스 페어링)
   * PC(Windows / Mac / Linux): 블루투스 설정에서 Elite AirMouse S3 선택 후 연결
   * 스마트폰 및 태블릿(Android / iOS): 블루투스 검색 창에서 기기 선택 후 등록
   * 스마트 TV(Android TV / Tizen / webOS): 기기 추가 화면에서 등록
   * 연결 대기 모드 진입: 기기 목록에 나타나지 않을 시 측면 가운데 버튼(Side C)을 2초간 길게 누르면 표시등이 깜빡이며 연결 대기 상태가 됨
 * 3단계: 기본 마우스 조작
   * 윗면 가운데 버튼(Top M) 누름 유지: 마우스 화살표 이동 허용
   * 윗면 가운데 버튼(Top M) 뗌: 화살표 이동 즉시 정지(내려놓았을 때 제멋대로 움직이는 오작동 차단)
   * 윗면 왼쪽(Top L): 좌클릭
   * 윗면 오른쪽(Top R): 우클릭
## 🎛️ 버튼 배치 및 명칭
```
        [윗면 조작부]
     [L]   [M]   [R]      ← 상단 3개 버튼
     
   ┌─────────────┐
[F]│             │
[C]│             │        ← 좌측 측면 3개 버튼 (앞/가운데/뒤)
[R]│             │
   └─────────────┘

```
 * Top L (윗면 왼쪽): 좌클릭, 누른 채 이동 시 끌기(드래그)
 * Top M (윗면 가운데): 화살표 이동 스위치(누르고 있을 때만 커서 활성화)
 * Top R (윗면 오른쪽): 우클릭
 * Side F (측면 앞쪽): 화면 스크롤 전환 스위치
 * Side C (측면 가운데): 사용 모드 변경 및 연결(페어링) 스위치
 * Side R (측면 뒤쪽): 보조 기능 스위치
## 🖱️ 1번 모드: PC 일반 작업 모드 (표시등: 파란색)
 * 커서 조작 방식
   * 윗면 가운데(Top M)를 누른 상태로 공중에서 손을 움직이면 마우스 화살표가 반응함
   * 버튼을 떼면 화살표가 멈추므로 조작 안전성이 확보됨
 * 공장 초기 버튼 매핑
   * Top L 한 번 누름: 좌클릭
   * Top L 길게 누름: 좌클릭 누른 상태 유지(끌기/드래그)
   * Top L 두 번 연속 누름: 더블클릭
   * Top R 한 번 누름: 우클릭
   * Top R 두 번 연속 누름: 취소(ESC 키)
   * Top R 길게 누름: 화면 캡처 창 열기(Win + Shift + S)
   * Top M 한 번 누름: 마우스 휠 클릭
   * Side F 한 번 누름: 음량 키우기
   * Side F 길게 누름: 다음 곡 재생
   * Side R 한 번 누름: 음량 줄이기
   * Side R 길게 누름: 이전 곡 재생
   * Side C 한 번 누름: 재생 및 일시정지
 * 화면 스크롤 및 가로 화면 이동(틸트)*
   * Side F를 누른 채 기기 앞머리를 위나 아래로 기울임: 상하 페이지 스크롤
   * Side F를 누른 채 기기를 좌측이나 우측으로 기울임: 좌우 가로 화면 이동(팬)
   * 손을 놓으면 일반 화살표 조작 상태로 복귀하며 조작 중에는 화살표 이동 속도가 평소의 25% 수준으로 정밀 감속됨
 * 공중 제스처 조작(선택 기능)
   * 손목을 좌/우로 휙 돌림: 가상 바탕화면 전환(Ctrl + Win + 방향키)
   * 손목을 위로 휙 올림: 모든 창 내리고 바탕화면 보기(Win + D)
   * 손목을 아래로 휙 내림: 실행 중인 창 전환(Alt + Tab)
   * 상하 제스처는 윗면 가운데(Top M) 버튼에서 손을 뗀 상태에서만 인식됨
> * **각주 2 (틸트 / Tilt):** 기기를 수평 상태에서 앞뒤나 좌우 방향으로 비스듬히 기울이는 동작을 의미함.
> 
## 🎤 2번 모드: 발표 모드 (표시등: 초록색)
 * 진입 방법
   * 측면 가운데(Side C)를 두 번 연속 누름(표시등이 초록색으로 변경되며 흰색으로 0.5초 깜빡임)
 * 발표 화면 제어 버튼 매핑
   * Top L 한 번 누름: 다음 슬라이드 넘김(PageDown)
   * Top L 두 번 연속 누름: 이전 슬라이드 넘김(PageUp)
   * Top L 길게 누름: 현재 쪽부터 슬라이드 쇼 재생(Shift + F5)
   * Side F 한 번 누름: 다음 슬라이드
   * Side R 한 번 누름: 이전 슬라이드
   * Side R 길게 누름: 슬라이드 쇼 종료(ESC)
   * Top R 한 번 누름: 쇼 종료(ESC)
   * Top R 두 번 연속 누름: 화면 일시 숨김(검은 화면 전환, B 키)
   * Top R 길게 누름: 흰 화면 전환(W 키)
 * 포인터 및 가상 레이저 조작
   * Top M 누른 채 이동: 화살표 포인터 이동
   * Top M 한 번 누름: 화면 내 빨간색 레이저 포인터 켜기(Ctrl + L)
   * Side C 한 번 누름: 펜 → 레이저 → 일반 화살표 모드 순환 변경
 * 발표 공중 제스처
   * 손목 좌측 털기: 다음 슬라이드
   * 손목 우측 털기: 이전 슬라이드
   * 손목 위로 털기: 화면 일시 숨김(검은 화면)
## 📺 3번 모드: 스마트 TV 모드 (표시등: 주황색)
 * 진입 방법
   * 2번 발표 모드 상태에서 측면 가운데(Side C)를 두 번 연속 누르면 주황색으로 전환됨
 * 스마트 TV 전용 버튼 매핑
   * Top L 한 번 누름: 뒤로 가기
   * Top L 두 번 연속 누름: 홈 화면 이동
   * Top L 길게 누름: 전원 켜기/끄기
   * Top M 한 번 누름: 선택(확인/Enter)
   * Top R 한 번 누름: 홈 화면 이동
   * Top R 두 번 연속 누름: 외부 입력 목록 호출
   * Top R 길게 누름: 전원 끄기
   * Side F 한 번 누름 / 길게 누름: 음량 키우기 / 채널 올리기
   * Side R 한 번 누름 / 길게 누름: 음량 줄이기 / 채널 내리기
   * Side C 한 번 누름: 영상 재생 및 일시정지
 * 기울여 유지하기(틸트 홀드)를 통한 4방향 키 제어
   * 윗면 가운데(Top M)에서 손을 뗀 상태로 기기를 전후좌우로 15도 이상 기울여 유지함
   * 0.3초 이상 유지 시 해당 방향의 방향키가 연속으로 입력됨(초당 3회)
   * 기기를 평평하게 세우면 방향키 입력이 멈춤
   * 해당 기능은 TV 화면 메뉴를 쉽게 넘기기 위한 3번 모드 전용 기능임
 * 커서 방식 지원
   * 넷플릭스나 TV 웹브라우저 등 화살표가 필요한 앱에서는 윗면 가운데(Top M)를 누르면 에어마우스 화살표가 즉시 활성화됨
 * TV 공중 제스처
   * 손목 좌측 털기: 10초 뒤로 감기
   * 손목 우측 털기: 10초 앞으로 빨리 감기
   * 손목 위로 털기: 음소거 켜기/끄기
## 🔄 모드 전환 및 상태 표시등 규격
 * 모드 순환: Side C를 연속 두 번 누르면 1번(PC) → 2번(발표) → 3번(TV) 순서로 바뀜
 * 상태 표시등 안내
   * 🔵 파란색 켜짐: 1번 PC 모드 정상 작동 중
   * 🟢 초록색 켜짐: 2번 발표 모드 정상 작동 중
   * 🟠 주황색 켜짐: 3번 TV 모드 정상 작동 중
   * ⚪ 흰색 번쩍임: 조작 명령이 전송되는 중
   * 🔴 빨간색 켜짐: 오류 상태 또는 전원 절전 모드 진입
   * 💡 1초 주기 깜빡임: 새 장비 연결 대기 중(페어링 모드)
## 📡 기기 재연결 및 다중 장치(멀티 호스트) 관리
 * 신규 장비 연결 절차
   * Side C 버튼을 2초간 꾹 누름(표시등 깜빡임 시작)
   * 대상 기기의 블루투스 검색 창에서 Elite AirMouse S3 등록
 * 연결 장치 전환(최대 3대 등록 가능)
   * 1단계: Side C를 누른 상태를 유지함
   * 2단계: 그 상태에서 윗면 왼쪽(Top L)을 한 번 클릭함
   * 3단계: 흰색 불빛이 깜빡이며 기존에 등록된 다른 컴퓨터/TV로 연결이 전환됨
   * 웹 설정 화면의 대시보드 내 '기기 순환' 버튼을 클릭해도 동일하게 전환 가능함
## 🔌 충전 및 절전 모드
 * 기본 USB-C 단자를 통해 충전 진행
 * 60초 동안 아무 조작이 없으면 자동으로 절전 모드에 진입하여 불빛이 꺼짐
 * 본체를 살짝 흔들거나 아무 버튼을 누르면 즉시 깨어남
 * 컴퓨터와 블루투스 신호가 유지되는 동안에는 임의로 꺼지지 않음
## ⚙️ 브라우저 기반 상세 설정 화면(웹 UI)
 * 1단계: 접속 방식
   * 기기 자체 와이파이 직접 연결 방식: PC나 스마트폰의 Wifi에서 SSID "EliteAirMouse"(비밀번호: 12345678)에 연결, 웹브라우저로 [http://192.168.4.1](http://192.168.4.1) 주소 입력
   * 공유기 연결 방식: 공유기 연결 후 웹브라우저로 [http://elite-airmouse.local](http://elite-airmouse.local) 주소 입력
 * 2단계: 상단 프로파일(설정 세트) 관리 바
   * 프로파일 드롭다운: 최대 5개(0~4번)의 사전 맞춤 설정을 전환하여 즉시 적용
   * + 새로: 새로운 빈 맞춤 설정 생성(예: '사무용', '게임용', '강의용')
   * 이름: 현재 설정 세트의 이름 변경
   * 삭제: 필요 없는 세트 삭제(최소 1개는 기본 유지)
   * ↻: 최신 설정 다시 불러오기
   * 상단 노란색 알림 띠: 시스템 재부팅이 필요한 주요 설정 변경 시 화면 상단에 표시됨
## 🎰 3. 버튼 및 동작 배정 화면 (슬롯 관리)
 * 개념 정의: 슬롯(Slot)이란 27개의 물리적 누름이나 흔들기 동작에 특정 키나 마우스 명령을 짝지어 주는 매핑 칸을 의미함
 * 27가지 조작 동작 분류
   * 버튼 누름 동작(15개): Top L/M/R 및 Side F/C/R의 단순 누름, 길게 누름, 연속 두 번 누름
   * 공중 털기 제스처(4개): 기기를 손목 스냅으로 동서남북 방향으로 휙 털기
   * 누르고 밀기 제스처(4개): 윗면 가운데(Top M)를 누른 상태에서 상하좌우로 쓱 밀기
   * 기울여 유지하기(4개): 3번 TV 모드 전용으로 특정 각도로 기울인 채 버티기
 * 절대 수정 불가 잠금 동작(오작동 차단용)
   * S1 (Top L 짧게 누름): 기본 마우스 좌클릭 및 선택 기능
   * S5 (Top M 누르고 있음): 화살표 이동 허용 스위치
   * S12 (Side C 두 번 연속 누름): 모드 변경 필수 스위치
   * S13 (Side C 2초 길게 누름): 블루투스 신규 기기 등록 스위치
 * 전체 공통 적용 vs 모드별 덮어쓰기 기능
   * 상단 탭에서 전체 공통(Global), 1번 모드, 2번 모드, 3번 모드 중 하나를 선택하여 화면을 전환함
   * 동작 이름 옆 파란색 [G] 표시는 전체 공통 규칙을 그대로 물려받아 쓴다는 의미임
   * 특정 모드에서 [G]를 클릭하면 주황색 [M] 표시로 바뀌며 해당 모드에서만 다른 기능으로 덮어써서 작동하도록 분리됨
 * 지원되는 10가지 실행 명령 종류
   * NONE: 아무 동작도 하지 않음
   * MOUSE_CLICK: 마우스 단일 클릭(좌클릭, 우클릭, 휠클릭, 앞/뒤 탐색 버튼 중 선택)
   * MOUSE_HOLD: 마우스 버튼을 손으로 누르고 있는 상태 유지
   * MOUSE_WHEEL: 화면 위/아래 또는 좌/우 굴리기
   * KB_TAP: 키보드의 일반 글자, 숫자, 펑션키(F1~F12) 1회 단독 입력
   * KB_COMBO: 조합 단축키 동시 입력(예: Ctrl + C, Win + Shift + S 등 최대 3개 키 조합)
   * KB_REPEAT: 버튼을 누르고 있는 동안 해당 키가 연속으로 계속 쳐짐
   * CONSUMER_TAP: 미디어 리모컨 단축키(음량 조절, 재생, 일시정지, 홈, 전원 등)
   * SPECIAL: 마우스 센서 영점 재조정*, 강제 절전 모드 등 하드웨어 내부 명령
   * MACRO: 미리 만들어 둔 일련의 연속 동작을 차례대로 자동 실행
 * 실시간 동작 확인(Test) 및 저장
   * 우측의 '테스트(Test)' 버튼을 누르면 기기를 컴퓨터에 저장하기 전에도 기능이 올바르게 실행되는지 즉시 시험 가능함
   * 변경 후 반드시 상단 '저장' 버튼을 눌러야 기기 내부 메모리에 반영됨
> * **각주 3 (영점 재조정 / 캘리브레이션):** 마우스 화살표가 가만히 두어도 스르륵 혼자 흐르거나 움직일 때, 평평한 바닥에 기기를 두고 흔들림 없는 기준 상태를 다시 측정하여 0점을 맞추는 교정 작업을 의미함.

## 🎬 4. 자동 연속 동작 화면 (매크로 관리)
 * 개념 정의: 단 한 번의 버튼 조작으로 복잡한 단축키나 연속 입력을 정해진 순서와 시간 간격에 맞춰 자동으로 실행해 주는 기능임
 * 시스템 제약 규격
   * 설정 세트당 최대 8개의 연속 동작을 보관 가능함
   * 연속 동작 1개당 최대 8단계의 순차 명령을 넣을 수 있음
   * 단계별 대기 시간(지연 시간)은 0초에서 2초(2000밀리초)까지 지정 가능함
 * 생성 및 편집 절차
   * 1단계: + 새 매크로 선택 후 알기 쉬운 이름 입력
   * 2단계: + 단계 추가 버튼으로 실행할 키보드나 마우스 조작을 순서대로 나열
   * 3단계: 각 단계 사이에 프로그램이 반응할 수 있도록 적절한 지연 시간(예: 100~500밀리초) 입력
   * 4단계: '저장' 버튼을 누른 뒤 버튼 매핑 화면으로 돌아가 원하는 버튼에 해당 매크로를 연결
 * 실생활 추천 활용 구성
   * 작업 관리자 호출: Ctrl + Shift + ESC 단축키를 묶어 측면 뒤쪽 버튼에 배정
   * 자동 복사 후 붙여넣기: Ctrl + C 실행 후 0.1초 뒤 Ctrl + V가 바로 실행되도록 구성
   * 원터치 화면 캡처: Win + Shift + S 실행 후 0.5초 뒤 저장 단축키가 연쇄 작동하도록 구성
   * 화상회의 즉시 끄기: 마이크 음소거(Ctrl + Shift + M)와 화면 끄기(Ctrl + Shift + V)를 연달아 실행
 * 비상 중단 안전장치: 동작 도중 다른 모드로 전환하거나 블루투스 연결이 끊어지면 누르고 있던 키가 컴퓨터에 계속 눌린 채로 멈추지 않도록 모든 키를 즉시 자동으로 떼어줌
## 📊 5. 마우스 민감도 및 세부 환경 설정
 * 커서 속도(DPI): 1~3단계로 마우스 화살표의 기본 반응 민감도 설정
 * 손떨림 보정 기능: 공중에서 버튼을 딸깍 누를 때 손목이 흔들려 화살표가 빗나가지 않도록 일시적으로 화살표를 잡아줌
 * 상태 표시등 밝기: 본체 불빛의 밝기를 조절
 * 스크롤 중 커서 속도 감속: 화면을 위아래로 넘기는 도중에는 화살표가 마구 튀지 않도록 속도를 느리게 줄여주는 비율 설정
 * 제스처 감도: 손목을 털었을 때 이를 명령으로 인식할 회전 속도 기준 설정
 * 설정 파일 백업 및 복원: 내가 세팅한 모든 버튼 설정을 파일로 내려받거나 다른 사람의 설정을 불러오기 가능
## 🔍 6. 상태 점검 및 문제 진단 화면
 * 대시보드(작업 현황 요약)
   * 배터리 및 무선 통신 상태, 시스템 메모리 사용량 한눈에 확인
   * 센서 영점 재조정 버튼: 평평한 책상에 올린 뒤 누르면 화살표 쏠림 현상 해결
   * 키 누름 강제 해제: 컴퓨터에 특정 키가 계속 눌려 있는 상태가 되었을 때 모든 입력을 원상복구
   * 공장 초기화: 모든 세팅을 지우고 기기 출고 상태로 복원
 * 진단 로그 및 테스트 화면
   * 센서 통신 에러 발생 횟수 집계
   * 키보드 개별 신호 즉시 전송 테스트 창 제공
 * 무선 업데이트(OTA)
   * 펌웨어 파일을 무선으로 전송하여 기기 소프트웨어를 최신 버전으로 업데이트
## 🔧 자주 묻는 문제 및 해결책
 * 마우스 화살표가 움직이지 않는 현상
   * 윗면 가운데(Top M) 버튼을 꾹 누른 채로 움직이고 있는지 확인 필요함
   * 컴퓨터의 블루투스 설정에서 연결이 끊어졌는지 확인하고 측면 가운데(Side C)를 2초간 눌러 재연결함
   * 책상 위에 평평하게 내려놓은 뒤 웹 화면에서 '센서 영점 재조정'을 진행함
 * 버튼이 계속 눌린 것처럼 작동하는 현상
   * 무선 신호 일시 혼선으로 발생할 수 있으며 웹 화면 대시보드의 '키 누름 강제 해제' 버튼을 클릭함
 * 화면 스크롤이 지나치게 둔하거나 빠른 현상
   * 세부 설정 화면에서 스크롤 반응 각도(Wheel Threshold) 값을 조절함
 * 손목 제스처가 내 의도와 달리 자주 발동하는 현상
   * 세부 설정에서 털기 인식 감도(Flick) 수치를 높여 조금 더 강하게 털었을 때만 반응하도록 조정함
 * 안전 부팅 모드로 켜지는 현상(SafeBoot)
   * 비정상적인 전원 종료가 반복되었을 때 시스템 보호를 위해 진입함
   * 웹 화면 대시보드에서 '안전 모드 해제 및 재부팅'을 누르면 일반 모드로 돌아옴
## 📋 핵심 조작 요약표
| 원하는 작업 | 실제 손동작 |
|---|---|
| 마우스 화살표 움직이기 | 윗면 가운데(Top M) 누른 채로 허공에서 움직임 |
| 마우스 좌클릭 및 선택 | 윗면 왼쪽(Top L) 한 번 누름 |
| 파일 끌어다 놓기(드래그) | 윗면 왼쪽(Top L)을 누른 상태로 이동 |
| 마우스 우클릭 | 윗면 오른쪽(Top R) 한 번 누름 |
| 화면 위아래로 굴리기 | 측면 앞쪽(Side F) 누른 채로 마우스를 앞뒤로 기울임 |
| 화면 좌우로 밀기(팬) | 측면 앞쪽(Side F) 누른 채로 마우스를 좌우로 기울임 |
| 모드 변경 (PC ↔ 발표 ↔ TV) | 측면 가운데(Side C)를 연속 두 번 누름 |
| 새 기기 블루투스 연결 등록 | 측면 가운데(Side C)를 2초간 길게 누름 |
| 등록된 다른 컴퓨터로 전환 | 측면 가운데(Side C)를 누른 채 윗면 왼쪽(Top L) 클릭 |
| 다음 슬라이드 넘김(발표 모드) | 윗면 왼쪽(Top L) 한 번 누름 |
| 스마트 TV 4방향 메뉴 이동 | 윗면 가운데에서 손을 뗀 후 원하는 방향으로 기울여 유지 |
| 화살표 쏠림 보정 | 평평한 곳에 기기를 둔 뒤 웹 화면에서 '센서 영점 재조정' 클릭 |
## 🔒 안전 주의사항
 * 물기 및 습기 차단: 방수 설계가 적용되지 않았으므로 액체 노출 주의 필요함
 * 충격 및 낙하 주의: 내부에 정밀 모션 센서가 장착되어 있어 바닥 낙하 시 센서가 영구 파손될 위험이 있음
 * 정격 전압 충전기 사용: 일반 규격의 5V 충전기 사용 권장
 * 시스템 무선 업데이트 주의: 소프트웨어 업데이트 진행 중 배터리가 방전되거나 전원이 꺼지면 기기가 작동 불능 상태에 빠질 수 있으므로 충전선을 연결한 상태에서 진행 권장됨
