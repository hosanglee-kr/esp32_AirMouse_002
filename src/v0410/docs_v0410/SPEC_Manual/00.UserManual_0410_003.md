# Elite AirMouse S3 (v0410) 사용자 매뉴얼
 * 기기 개요
   * 하드웨어: 초소형 제어 보드(ESP32-S3-Zero) 및 6축 자세 감지 센서(MPU6050) 탑재
   * 통신 및 입력: 블루투스 통합 무선 입력(마우스·키보드·미디어 제어 일체형 지원)
   * 부가 기능: 삼원색(RGB) 상태 표시등, 동작 감지 기반 자동 절전 모드 지원
   * 핵심 제어 체계: 3가지 작업 모드, 최대 5개 독립 환경 설정(프로파일), 27개 동작 매핑 슬롯, 8×8 자동 연속 동작(매크로) 지원
   * 문서 대상: 일반 PC 사용자, 프레젠테이션 발표자, 스마트 TV 사용자
## 1. 하드웨어 사양 및 조작부 인터페이스
### 1.1 하드웨어 구성 및 규격
 * 기본 구성품: 에어마우스 본체 1대, 충전 및 데이터 전송용 USB-C 케이블 1개
 * 전원 및 충전 규격: 5V 정격 전원 충전 지원, 60초 무입력 시 초절전 모드 자동 진입
 * 절전 해제 방식: 기기를 손으로 가볍게 흔들거나 물리 버튼 1회 입력 시 0.1초 내 즉시 복귀
### 1.2 버튼 배치 및 기본 명칭 정의
```
        [상단 조작부]
     [L]    [M]    [R]       ← 윗면 3버튼
     
   ┌───────────────┐
[F]│               │
[C]│               │         ← 좌측면 3버튼 (앞 / 가운데 / 뒤)
[R]│               │
   └───────────────┘

```
 * 상단 조작부 (Top)
   * Top L (상단 좌측): 선택, 마우스 좌클릭, 파일 끌어다 놓기(드래그)
   * Top M (상단 중앙): 마우스 커서 조작 스위치(누르고 있는 동안만 커서 활성화)
   * Top R (상단 우측): 보조 메뉴, 마우스 우클릭
 * 측면 조작부 (Side)
   * Side F (측면 전방): 화면 굴리기(스크롤) 및 가로 화면 이동(팬)* 활성화 스위치
   * Side C (측면 중앙): 작업 모드 순환 전환 및 블루투스 연결(페어링) 스위치
   * Side R (측면 후방): 기능 보조 및 미디어 단축키
> * **각주 1 (팬 / Pan):** 긴 도면이나 넓은 웹페이지를 볼 때 카메라를 좌우로 움직이듯 화면을 수평 방향으로 이동시키는 기능(가로 스크롤)을 의미함.
> 
## 2. 기본 연결 및 다중 장치(멀티 페어링) 관리
### 2.1 최초 연결 (블루투스 페어링)
 * 1단계: 전원 스위치 ON 조작 (상태 표시등 파란색 점등 확인)
 * 2단계: 측면 중앙(Side C) 버튼을 2초간 길게 누름 (표시등이 1초 간격으로 점멸하며 등록 대기 모드 진입)
 * 3단계: 호스트 기기(PC, 태블릿, 스마트 TV)의 블루투스 설정에서 Elite AirMouse S3 선택 후 등록 완료
### 2.2 최대 3대 장치 순환 전환 (멀티 호스트)
 * 물리 조작 방식: 측면 중앙(Side C)을 길게 누른 상태에서 상단 좌측(Top L) 버튼을 1회 누름
 * 동작 결과: 상태 표시등이 흰색으로 1회 번쩍인 후 기등록된 다음 호스트 장치(최대 3대)로 순환 재연결
 * 화면 조작 방식: 웹 설정 대시보드 내 '호스트 순환' 버튼을 클릭해도 동일하게 전환됨
## 3. 3가지 작업 모드별 제어 체계
 * 공통 모드 전환 방식: 측면 중앙(Side C) 버튼을 빠르게 두 번 연속 누름(더블클릭)
 * 모드 전환 순환 체계: 1번 PC 모드(파란색) → 2번 발표 모드(초록색) → 3번 TV 모드(주황색) → 1번 순환
### 3.1 Mode 1: PC 일반 마우스 모드 (표시등: 🔵 파란색)
 * 기본 커서 조작
   * 상단 중앙(Top M)을 누른 상태에서 공중에 손을 움직이면 마우스 화살표가 반응함
   * 버튼에서 손을 떼면 커서가 즉시 정지하여 책상에 내려놓았을 때의 오작동을 원천 방지함
 * 틸트(기울이기)* 기반 화면 스크롤 조작
   * 측면 전방(Side F)을 누른 채 기기를 위/아래로 기울임: 상하 페이지 스크롤
   * 측면 전방(Side F)을 누른 채 기기를 좌/우로 기울임: 가로 화면 이동(팬)
   * Side F 조작 중에는 화살표 속도가 평소의 25% 수준으로 자동 감속되어 정밀 제어 가능
 * 공장 출하 기본 버튼 매핑
   * Top L: [단일 클릭] 좌클릭 / [길게 누름] 드래그 유지 / [더블클릭] 더블클릭
   * Top R: [단일 클릭] 우클릭 / [더블클릭] 취소(ESC) / [길게 누름] 화면 캡처 창(Win+Shift+S)
   * Top M: [단일 클릭] 휠 클릭
   * Side F: [단일 클릭] 볼륨 업 / [길게 누름] 다음 곡
   * Side R: [단일 클릭] 볼륨 다운 / [길게 누름] 이전 곡
   * Side C: [단일 클릭] 재생 및 일시정지
> * **각주 2 (틸트 / Tilt):** 마우스 본체를 수평면 기준 앞뒤로 젖히거나 좌우로 비스듬히 기울이는 손동작을 의미함.
> 
### 3.2 Mode 2: 프레젠테이션 발표 모드 (표시등: 🟢 초록색)
 * 슬라이드 쇼 제어
   * Top L: [단일 클릭] 다음 슬라이드(PageDown) / [더블클릭] 이전 슬라이드(PageUp) / [길게 누름] 현재 쪽부터 재생(Shift+F5)
   * Top R: [단일 클릭] 쇼 종료(ESC) / [더블클릭] 화면 칠판화(검은 화면, B) / [길게 누름] 화이트보드화(흰 화면, W)
   * Side F / Side R: [단일 클릭] 다음 슬라이드 / 이전 슬라이드
 * 가상 포인터 및 펜 제어
   * Top M 누른 채 이동: 레이저 포인터 화면 조작
   * Top M [단일 클릭]: 레이저 포인터 모드 강제 켜기(Ctrl+L)
   * Side C [단일 클릭]: 펜 → 레이저 → 일반 화살표 순환 변경
### 3.3 Mode 3: 스마트 TV 리모컨 모드 (표시등: 🟠 주황색)
 * 틸트 홀드(기울여 버티기) 기반 4방향 탐색 패드 (Mode 3 전용)
   * 동작 조건: 상단 중앙(Top M)에서 손을 뗀 상태
   * 제어 방식: 기기를 상·하·좌·우로 15도 이상 기울이고 0.3초 이상 버틸 시 해당 방향키가 초당 3회 연속 자동 입력됨
   * 정지 방식: 기기를 수평으로 복귀시키면 탐색 정지
 * 스마트 TV 전용 매핑
   * Top L: [단일 클릭] 뒤로 가기 / [더블클릭] 홈 화면 / [길게 누름] 전원 제어
   * Top M: [단일 클릭] 선택(확인/Enter) / [누른 채 이동] 스마트 TV 웹브라우저용 커서 활성화
   * Top R: [단일 클릭] 홈 화면 / [더블클릭] 외부 입력 전환 / [길게 누름] 시스템 전원 끄기
   * Side F / Side R: [단일 클릭] 볼륨 조절 / [길게 누름] 채널 변경
   * Side C: [단일 클릭] 영상 재생 및 일시정지
## 4. 제스처 인터페이스 (공중 모션 인식)
 * 모션 제스처 체계
   * 털기 제스처(Flick): 손목 스냅을 이용해 특정 방향으로 순간적으로 휙 터는 동작
   * 밀기 제스처(Linear): 상단 중앙(Top M)을 누른 상태에서 특정 방향으로 쓱 밀어내는 동작
 * 모드별 제스처 기본 설정표
   * Mode 1 (PC)
     * 손목 좌/우 털기: 가상 바탕화면 좌/우 전환 (Ctrl + Win + 방향키)
     * 손목 위로 털기: 바탕화면 바로 보기 (Win + D)
     * 손목 아래로 털기: 작업 창 전환 (Alt + Tab)
   * Mode 2 (발표)
     * 손목 좌/우 털기: 다음 슬라이드 / 이전 슬라이드 이동
     * 손목 위로 털기: 발표 화면 일시 숨김 (B)
   * Mode 3 (스마트 TV)
     * 손목 좌/우 털기: 10초 되감기 / 10초 빨리감기
     * 손목 위로 털기: 음소거 토글
## 5. 웹 브라우저 상세 설정 환경 (Web UI)
### 5.1 접속 및 프로파일 관리
 * 브라우저 접속 경로
   * 기기 자체 와이파이(AP 모드): 무선 네트워크 EliteAirMouse 연결(암호: 12345678) 후 인터넷 창에 [http://192.168.4.1](http://192.168.4.1) 입력
   * 공유기 연동(STA 모드): 웹 주소창에 [http://elite-airmouse.local](http://elite-airmouse.local) 입력
 * 다중 프로파일(환경 세트) 시스템
   * 최대 5개(0~4번)의 완전 독립된 설정 세트 저장 및 드롭다운 원클릭 전환
   * 작업 성격별로 '업무용', '발표용', '게임용' 등의 환경을 완전히 분리하여 운용 가능
### 5.2 슬롯 에디터 (27개 동작 매핑 및 2단 상속 매트릭스)
 * 조작 매핑 슬롯 구성
   * 물리 버튼 조작: 15개 슬롯 (단일 클릭, 더블클릭, 길게 누름)
   * 털기 및 밀기 제스처: 8개 슬롯 (상·하·좌·우)
   * 기울여 유지하기(틸트 홀드): 4개 슬롯 (상·하·좌·우, TV 모드 전용)
 * 시스템 보호용 4대 잠금 슬롯 (수정 불가)
   * S1 (Top L 단일 클릭): 기본 마우스 좌클릭 및 조작 보장
   * S5 (Top M 누르고 있음): 커서 이동 게이트 스위치
   * S12 (Side C 더블클릭): 작업 모드 전환 필수 경로
   * S13 (Side C 2초 누름): 블루투스 페어링 모드 진입 경로
 * 2단 상속 매트릭스 (공통 적용 vs 모드별 덮어쓰기)
   * Global(공통) 탭: 모든 모드에서 기본으로 작동하는 표준 동작 정의
   * Mode 1/2/3 탭: 특정 모드에서만 다르게 작동해야 할 경우 오버라이드 지정
   * 상속 상태 전환: 각 동작 옆 뱃지가 [G](공통 상속) 상태일 때 클릭하면 [M](해당 모드 전용 덮어쓰기)으로 변경되어 독립적인 기능 지정 가능
 * 지원 실행 명령 종류 (Action Kind)
   * MOUSE_CLICK / MOUSE_HOLD: 마우스 5버튼(좌/우/휠/앞/뒤) 클릭 및 누름 유지
   * MOUSE_WHEEL: 화면 수직/수평 스크롤
   * KB_TAP / KB_REPEAT: 단일 키 1회 입력 및 누르고 있는 동안 연속 입력
   * KB_COMBO: 최대 3개 키 동시 입력 단축키 (예: Ctrl + Shift + Esc)
   * CONSUMER_TAP: 볼륨, 전원, 홈, 트랙 이동 등 미디어 제어 키
   * SPECIAL: 센서 영점 재조정*, 강제 절전 등 기기 내부 명령
   * MACRO: 순차적으로 작성된 다단계 자동 연속 동작 호출
> * **각주 3 (영점 재조정 / 캘리브레이션):** 마우스 화살표가 가만히 두어도 스스로 흐르는 드리프트 현상이 발생할 때, 평평한 바닥에 두고 센서의 기준 0점을 재측정하여 바로잡는 보정 작업을 의미함.
> 
### 5.3 매크로 라이브러리 (8×8 자동 연속 동작 체계)
 * 규격 제한: 프로파일당 최대 8개 매크로 등록 가능, 매크로당 최대 8단계(Step) 구성 가능
 * 시간 제어: 각 명령 단계 사이에 0~2000ms 범위의 대기 시간(지연) 설정 지원
 * 비상 안전장치: 매크로 실행 도중 모드가 바뀌거나 무선 연결이 해제되면 즉시 모든 키를 컴퓨터에서 자동으로 떼어내어 키 눌림 멈춤(Stuck) 현상 차단
## 6. 유지 관리 및 문제 해결
### 6.1 증상별 조치 절차
 * 커서가 움직이지 않는 경우
   * 상단 중앙(Top M) 버튼을 정상적으로 누른 상태인지 확인
   * 대시보드 화면에서 블루투스 연결 상태(BLE: ON) 확인
   * 평평한 바닥에 기기를 정지 상태로 올려둔 뒤 웹 화면 대시보드의 '센서 영점 재조정' 실행
 * 버튼이나 키가 계속 눌린 상태로 멈춘 경우
   * 웹 대시보드 중앙의 '키 누름 강제 해제(Force Release)' 버튼 클릭
 * 특정 버튼 매핑이 수정되지 않는 경우
   * 4대 안전 잠금 슬롯(S1, S5, S12, S13)인지 확인 (해당 슬롯은 벽돌 현상 방지를 위해 편집 차단)
 * 안전 부팅(SafeBoot) 모드로 켜진 경우
   * 2회 연속 비정상 전원 종료 시 진입됨
   * 웹 UI 접속 후 대시보드에서 'SafeBoot 해제 및 재부팅'을 선택하거나 '공장 초기화(Factory Reset)' 수행
### 6.2 하드웨어 취급 주의사항
 * 본체 방수 처리가 되어 있지 않으므로 물기 노출을 엄격히 금함
 * 내부에 정밀 진동 감지용 반도체 센서가 탑재되어 있으므로 강한 낙하 충격 시 센서 영구 손상 주의 필요
 * 무선 소프트웨어 업데이트(OTA) 중에는 절대 전원을 차단하거나 배터리가 방전되지 않도록 전원선 연결 상태 유지 필수
