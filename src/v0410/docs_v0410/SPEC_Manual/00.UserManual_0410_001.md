# Elite AirMouse S3 — v0410 사용자 매뉴얼

> ESP32-S3-Zero + MPU6050 기반 3-Mode Air Mouse
> BLE HID Composite (Mouse + Keyboard + Consumer) / WS2812 LED / Light-sleep
> **v0410: 다중 프로파일(최대 5개) × 8×8 매크로 라이브러리 × 2단 슬롯 매트릭스**

**문서 대상: 최종 사용자 (일반 사용자, 프레젠테이션 발표자, 게이머, TV 사용자)**
**소프트웨어 버전: v0410**

---

## 📌 30초 요약 (처음 사용자용)

1. **전원 켜기** → LED 파란색 점등 (Mode 1: PC 기본 모드)
2. **호스트에 페어링** → "Elite AirMouse S3" 검색 후 연결
3. **Top M (가운데 위 버튼) 누르고 있으면** → 에어마우스 포인팅 커서 이동
4. **Top L (왼쪽 위)** → 마우스 좌클릭 (누른 채 이동 시 드래그)
5. **Top R (오른쪽 위)** → 마우스 우클릭
6. **Side C 더블클릭 (측면 가운데)** → Mode 전환 (1: PC 🔵 → 2: PPT 🟢 → 3: TV 🟠)
7. **Side F 누르고 있으면** → 상하 틸트(스크롤) / 좌우 틸트(가로 팬)
8. **웹 UI 접속 (`http://192.168.4.1`)** → 프로파일(최대 5개), 슬롯 커스텀(27개), 매크로(8×8) 자유 설정!

## 🔋 처음 시작하기

### 1단계: 전원 켜기

- 측면 또는 하단의 전원 스위치를 ON
- LED가 파란색으로 켜짐 → Mode 1 (PC Air Mouse) 진입

### 2단계: 호스트에 페어링

**PC (Windows / macOS / Linux)**

1. PC의 Bluetooth 설정 열기
2. "Elite AirMouse S3" 검색
3. 페어링 클릭 → 자동 연결
4. LED가 파란색으로 안정화되면 완료

**스마트폰 / 태블릿 (Android / iOS)**

1. Bluetooth 설정 열기
2. "Elite AirMouse S3" 선택
3. 연결

**스마트 TV (Android TV / Tizen / webOS)**

1. 설정 → Bluetooth 입력 장치 → 추가
2. "Elite AirMouse S3" 선택
3. 연결 완료

> **팁:** 페어링이 안 되면 Side C를 **2초간 눌러** 페어링 모드로 진입하세요. LED가 1Hz로 깜빡입니다.

### 3단계: 첫 사용

- **Top M (가운데 위) 을 누른 채** 손목을 움직임 → 커서 이동
- **Top M 을 놓으면** 커서 정지
- Top L 클릭 → 좌클릭
- Top R 클릭 → 우클릭

## 🎛️ 버튼 레이아웃

```
        [Top 면]
     [L] [M] [R]      ← 위쪽 3버튼
     
   ┌─────────────┐
[F]│             │
[C]│             │  ← 왼쪽 측면 (Front/Center/Rear)
[R]│             │
   └─────────────┘
```

| 약자 | 위치 | 주요 역할 |
|---|---|---|
| **Top L** | 위 왼쪽 | 좌클릭 / (드래그) |
| **Top M** | 위 가운데 | 커서 이동 게이트 (Hold) |
| **Top R** | 위 오른쪽 | 우클릭 |
| **Side F** | 측면 앞 | 스크롤 모드 (Hold) |
| **Side C** | 측면 가운데 | Mode 전환 / 페어링 |
| **Side R** | 측면 뒤 | 보조 기능 |

## 🖱️ Mode 1: PC Air Mouse

**PC 작업에 최적화된 기본 모드. LED: 파란색**

### 커서 이동

- **Top M 누른 채** 손목 움직임 → 커서 이동
- **Top M 놓음** → 커서 정지 (오작동 방지)

> **왜 버튼을 눌러야 하나요?** 책상에 내려놨을 때 커서가 저절로 움직이는 것을 방지하기 위함입니다.

### 버튼 조작

| 버튼 | 동작 |
|---|---|
| Top L 클릭 | 마우스 좌클릭 |
| Top L 길게 | 마우스 좌클릭 유지 (드래그) |
| Top L 더블클릭 | (기본) 마우스 더블클릭 |
| Top R 클릭 | 마우스 우클릭 (컨텍스트 메뉴) |
| Top R 더블클릭 | ESC |
| Top R 길게 | 화면 캡처 (Win+Shift+S) |
| Top M 클릭 | 마우스 휠클릭 |
| Side F 클릭 | 볼륨 업 |
| Side F 길게 | 다음 트랙 |
| Side R 클릭 | 볼륨 다운 |
| Side R 길게 | 이전 트랙 |
| Side C 클릭 | 재생/일시정지 |

### 스크롤 (Front Hold)

- **Side F 를 누른 채** 마우스 위/아래 기울임 → 페이지 스크롤
- **Side F 를 누른 채** 좌/우 기울임 → 가로 스크롤
- Side F 놓음 → 원래 커서 속도 복귀
- 스크롤 중엔 커서가 25% 속도로 느려짐 (미세 조정 가능)

### 제스처 (선택)

- **손목 좌/우 빠르게 회전** → 가상 데스크톱 전환 (Ctrl+Win+Left/Right)
- **손목 위로 빠르게** → Win+D (바탕화면 보기)
- **손목 아래로 빠르게** → Alt+Tab (작업 전환)

> **참고:** 상하 제스처는 Top M 을 놓은 상태에서만 동작합니다.

### DPI 조절

- 화면 하단 또는 웹 UI의 DPI 버튼 1/2/3
- 높은 해상도 모니터에선 3 권장
- 낮은 해상도에선 1~2 권장

## 🎤 Mode 2: Presentation (프레젠테이션)

**파워포인트 / Keynote / Google Slides 발표용. LED: 초록색**

### 진입 방법

- **Side C 더블클릭** (Mode 1 → Mode 2)
- LED가 초록색 + 흰색 0.5초 깜빡임

### 슬라이드 조작

| 버튼 | 동작 |
|---|---|
| Top L 클릭 | 다음 슬라이드 (PageDown) |
| Top L 더블클릭 | 이전 슬라이드 (PageUp) |
| Top L 길게 | 현재 슬라이드부터 쇼 시작 (Shift+F5) |
| Side F 클릭 | 다음 슬라이드 |
| Side R 클릭 | 이전 슬라이드 |
| Side R 길게 | 쇼 종료 (ESC) |

### 포인터 / 레이저

- **Top M 누른 채** 움직임 → 포인터 이동
- **Top M 클릭** → 레이저 포인터 모드 (Ctrl+L)
- **Side C 클릭** → 펜 / 레이저 / 화살표 순환 (Ctrl+P → Ctrl+L → Ctrl+A)

### 화면 제어

| 버튼 | 동작 |
|---|---|
| Top R 클릭 | ESC (발표 종료) |
| Top R 더블클릭 | B (블랙아웃 토글) |
| Top R 길게 | W (화이트아웃 토글) |

### 제스처

- **손목 좌 회전** → 다음 슬라이드
- **손목 우 회전** → 이전 슬라이드
- **손목 위로** → B (블랙아웃)

### 발표 중 스크롤

- **Side F 누른 채** 위/아래 기울임 → 페이지 스크롤 (긴 슬라이드/웹 페이지용)

## 📺 Mode 3: Smart TV Remote

**TV 리모컨 대체용. LED: 주황색**

### 진입 방법

- **Side C 더블클릭** (Mode 2 → Mode 3)
- LED가 주황색 + 흰색 0.5초 깜빡임

### TV 조작

| 버튼 | 동작 |
|---|---|

| Top L 더블클릭 | 홈 (Home) |
| Top L 길게 | 전원 (Power) |
| Top M 클릭 | 확인 (Enter) |
| Top R 클릭 | 홈 (Home) |
| Top R 더블클릭 | 입력 소스 (TV Input) |
| Top R 길게 | 전원 끄기 (Power Off) |
| Side F 클릭 | 볼륨 업 |
| Side F 길게 | 채널 업 |
| Side R 클릭 | 볼륨 다운 |
| Side R 길게 | 채널 다운 |
| Side C 클릭 | 재생/일시정지 |

### D-Pad 네비게이션 (Tilt Hold)

- **Top M 을 놓은 상태**에서 마우스를 **위/아래/좌/우로 기울여 유지**
- 15° 이상 기울임 + 300ms 유지 → 방향키 자동 반복 입력 (3Hz)
- 중립 복귀 → 정지

### TV 브라우저 / 넷플릭스 등

- **Top M 누른 채** 움직임 → 커서 이동 (TV의 웹 브라우저 조작)
- Top M 놓으면 → D-Pad 모드 복귀

### 제스처

- **손목 좌 회전** → 10초 되감기 (Rewind)
- **손목 우 회전** → 10초 빨리감기 (Fast Forward)
- **손목 위로** → 음소거 (Mute)

### 채널/볼륨 스크롤

- **Side F 누른 채** 위/아래 기울임 → 볼륨 스크롤

### 순환 (Cycle)

- **Side C 더블클릭** → Mode 1 → 2 → 3 → 1 순환
- LED 색상: 파랑 → 초록 → 주황 → 파랑
- Mode 진입 시 흰색 0.5초 깜빡임 (시각 피드백)

| LED 색 | Mode |
|---|---|
| 🔵 파랑 | Mode 1 (PC) |
| 🟢 초록 | Mode 2 (Presentation) |
| 🟠 주황 | Mode 3 (Smart TV) |
| ⚪ 흰색 | 액션 실행 중 (flash) |
| 🔴 빨강 | 경고 / 슬립 진입 |
| 💡 1Hz 깜빡임 | 페어링 대기 |

### 새 기기 페어링

1. **Side C 를 2초간 누름** (LED가 1Hz 깜빡임)
2. 새 기기에서 "Elite AirMouse S3" 검색
3. 페어링 클릭 → 자동 연결

### 다른 기기로 전환 (Multi-Host)

**최대 3개 기기 저장 가능.**

1. **Side C 를 3초간 누른 채 유지**
2. **Top L 을 클릭** (Side C 누른 상태에서)
3. LED가 흰색 0.5초 깜빡임
4. 자동으로 다른 저장된 기기로 재연결 시도
5. 저장된 기기가 자동 재연결 (Windows/macOS/iOS는 자동, Android TV는 수동일 수 있음)

**순환:** 저장된 기기 1 → 2 → 3 → 1 순환

### 페어링 완전 초기화

- 웹 UI에서 Factory Reset
- 또는 부팅 시 Side C 를 6초 이상 누름 (일부 모델)

## ⚙️ 웹 UI 사용법 (v0410)

기기의 모든 버튼 기능, 제스처, 매크로, 자이로 감도를 웹 브라우저에서 시각적으로 설정할 수 있습니다.

### 1. 접속 방법

**Wi-Fi AP 모드 (기본):**
1. 스마트폰/PC의 Wi-Fi 목록에서 **"EliteAirMouse"** 선택
2. 비밀번호: `12345678`
3. 브라우저 주소창에 `http://192.168.4.1` 입력 후 접속

**Wi-Fi STA 모드 (홈 네트워크 연결 시):**
1. 브라우저에서 `http://elite-airmouse.local` 접속 (또는 공유기 할당 IP)

---

### 2. 상단 Profile Bar (다중 프로파일)

화면 상단에 고정된 Profile Bar를 통해 프로파일을 관리합니다:
- **프로파일 드롭다운**: 최대 5개 프로파일(0~4) 중 원하는 프로파일을 선택하면 기기가 즉시 해당 설정으로 전환됩니다.
- **`+ 새로` 버튼**: 새로운 프로파일을 생성합니다 (최대 5개까지 등록 가능).
- **`이름` 버튼**: 현재 선택된 프로파일의 이름을 변경합니다 (예: "Coding", "Gaming", "Presentation").
- **`삭제` 버튼**: 현재 프로파일을 삭제합니다 (최소 1개의 프로파일은 항상 유지됩니다).
- **`↻` 버튼**: 최신 프로파일 목록 및 설정을 다시 불러옵니다.

### 3. Slots 탭 (Slot Editor - 2단 슬롯 매트릭스)

총 **27개 고정 트리거**에 대해 원하는 동작을 지정합니다.

#### 뷰 선택 및 오버라이드 규칙
- **`Global` 탭**: 모든 Mode(PC/PPT/TV)에서 공통으로 적용될 기본 동작을 설정합니다.
- **`Mode 1 · PC` / `Mode 2 · PPT` / `Mode 3 · TV` 탭**: 특정 모드에서만 다르게 작동할 동작을 오버라이드(재정의)합니다.
- **뱃지 토글**:
  - `[G]` 뱃지 (파란색): 현재 Global 기본값을 상속받아 사용 중임을 의미합니다.
  - `[M1/M2/M3]` 뱃지 (주황색): 해당 모드 전용으로 오버라이드되어 있음을 의미합니다.
  - 모드 탭에서 뱃지를 클릭하면 **Global 상속 ↔ Mode 오버라이드** 상태가 원클릭으로 전환됩니다.

#### 4대 필수 기능 잠금 (🔒)
기기 조작 불능(브릭)을 방지하기 위해 다음 4개 트리거는 수정이 원천 차단됩니다:
1. `S1 (Top L Click)`: 마우스 좌클릭 홀드 (선택/드래그 보장)
2. `S5 (Top M Hold)`: 포인팅 게이트 (커서 이동 활성화)
3. `S12 (Side C Double)`: Mode 전환 (PC ↔ PPT ↔ TV)
4. `S13 (Side C 2s Hold)`: BLE 페어링 모드 진입

#### 슬롯 액션 지정 및 Live Test
- **Action Kind 선택**:
  - `NONE`: 동작 없음
  - `MOUSE_CLICK` / `MOUSE_HOLD`: 마우스 좌/우/중간/뒤/앞 버튼
  - `MOUSE_WHEEL`: 상하 휠 / 좌우 팬
  - `KB_TAP` / `KB_REPEAT`: 단일 키보드 키
  - `KB_COMBO`: 단축키 조합 (Ctrl, Shift, Alt, Win 조합 + 최대 3개 키)
  - `CONSUMER_TAP` / `REPEAT`: 볼륨, 음소거, 재생/일시정지 등 미디어 키
  - `SPECIAL`: 모드 순환, 자이로 캘리브, 강제 슬립 등 기기 특수 명령
  - **`MACRO`**: 등록된 매크로 목록 중 하나를 선택하여 실행
- **`Test` 버튼**: 기기가 PC에 연결된 상태에서 해당 액션을 즉시 PC로 전송하여 시험해 볼 수 있습니다.
- **`저장` 버튼**: 편집한 슬롯 매트릭스를 기기 플래시에 영구 저장합니다.

### 4. Macros 탭 (Macro Editor - 8×8 매크로)

복잡한 연속 키보드/마우스 입력이나 딜레이가 포함된 시퀀스를 매크로로 등록합니다:
- **매크로 목록 (좌측)**: 최대 8개 매크로를 등록/관리하며, 현재 등록 수가 표시됩니다.
- **스텝 편집기 (우측)**:
  - 하나의 매크로당 **최대 8개 Step**까지 추가할 수 있습니다.
  - 각 Step별로 액션 종류, 키, 딜레이(0~2000ms)를 설정합니다.
  - `▲` / `▼` 버튼으로 스텝 순서를 쉽게 변경할 수 있습니다.
  - `✕` 버튼으로 특정 스텝을 삭제할 수 있습니다.
- **매크로 즉시 `Test` 버튼**: 슬롯에 할당하기 전에 매크로 전체 시퀀스를 즉시 실행하여 동작을 확인합니다.
- **`+ 새 매크로` / `저장`**: 매크로를 추가하고 플래시에 영구 저장합니다.

---

### 5. Config 탭 (E10 하드웨어 파라미터)

- **DPI Level (1~3)**: 기본 커서 속도 단계
- **Hard Click Lock**: 클릭 시 손떨림으로 커서가 튀는 것을 방지
- **LED Brightness (0~255)**: 기기 LED 밝기 조절
- **Accel Threshold & Gain**: 마우스를 빠르게 휘두를 때 적용되는 가속도 곡선
- **Scroll Cursor Damp (0~1)**: Side F 스크롤 중 커서 감쇠율 (기본 0.25)
- **Wheel Threshold**: 휠 스크롤 발생 틸트 각도
- **Export / Import**: 현재 프로파일 설정을 `.json` 파일로 PC에 백업하거나 불러옵니다.

---

### 6. Diagnostics & Dashboard 탭

- **Dashboard**: Uptime, 메모리 상태, Wi-Fi 및 BLE 연결 상태, 활성 프로파일 확인
- **Quick Control**: PPT 모드 강제 ON/OFF, 자이로 수평 캘리브레이션, 강제 릴리즈(버튼 풀림), SafeBoot 해제
- **Diagnostics**: 기기 통신 패킷 에러, I2C 복구 카운터, 실시간 이벤트 로그 모니터링

## 🔧 자주 발생하는 문제

### 커서가 안 움직임

**원인 1:** Top M 을 안 누르고 있음
- **해결:** Top M 을 누른 상태에서 움직이세요

**원인 2:** BLE 연결 끊김
- **해결:** 웹 UI의 Dashboard에서 `BLE: OFF` 확인 → Side C 2초로 재페어링

**원인 3:** 자이로 캘리브 실패
- **해결:** 기기를 평평한 곳에 놓고 웹 UI의 "자이로 캘리브" 클릭

### 버튼이 눌린 채로 멈춤 (stuck)

**원인:** BLE 신호 끊김, 배터리 부족
- **해결:** 웹 UI의 "강제 릴리즈" 클릭
- 또는 기기 재부팅

### 스크롤이 너무 빠름 / 느림

- **빠름:** `wheel_threshold_deg`를 높임 (60 → 100)
- **느림:** `wheel_threshold_deg`를 낮춤 (90 → 60)

웹 UI의 Config 탭에서 조정.

### 스크롤 중 커서가 같이 움직임

- `scroll_cursor_damp`를 낮춤 (0.25 → 0.1)
- `0.0`으로 설정하면 커서 완전 정지

### 정지 상태에서 커서가 떨림

- **Precision Mode** 활성화 (Mode: MED)
- 또는 `zero_snap` 조정 (개발자 문의)

### 제스처가 오작동

- `flick.p2p_th` 상향 (400 → 600)
- `flick.cooldown_ms` 상향 (600 → 900)

### 배터리가 빨리 닳음

- 절전 시간 확인 (`sleep_idle_timeout_ms` = 60000ms)
- LED 밝기 낮춤 (`led_brightness` 128 → 64)
- 사용 안 할 땐 전원 OFF

### 페어링이 안 됨

- **Side C 2초 hold** → 페어링 모드
- LED가 1Hz 깜빡이는지 확인
- 기존 페어링 삭제: 호스트의 Bluetooth 설정에서 "Elite AirMouse S3" 삭제 후 재시도

### SafeBoot 모드 진입

**증상:** 부팅 후 LED가 파란색이지만 커서가 안 움직임, 웹 UI 접속 시 "-SAFE" 붙은 AP 표시

**원인:** 이전 부팅이 2회 연속 비정상 종료

**해결:**
1. 웹 UI 접속 (`EliteAirMouse-SAFE`)
2. Config 탭에서 Rollback 또는 Factory Reset
3. 또는 `/api/safeboot {exit:true}` API

### Factory Reset 방법

**웹 UI:**

- Dashboard → Factory Reset → 확인

**부팅 시:**

- Top M (13번 GPIO) 을 6초 이상 누른 채 부팅

**결과:** 모든 설정/부팅 상태 초기화 후 재부팅.

## 📚 부록: 웹 UI 파라미터 설명

### scale_base [3]

DPI 1/2/3 단계별 기본 감도 배율.

| 값 | 효과 |
|---|---|
| 0.55 | DPI 1: 느림 |
| 0.75 | DPI 2: 중간 |
| 1.00 | DPI 3: 빠름 |

### accel_gain [3]

DPI 단계별 가속 강도. 높을수록 빠른 스윙에 크게 반응.

### accel_threshold

가속 시작 임계. 이 값 이하의 움직임은 가속 없음.

### scroll_cursor_damp

Front Hold 중 커서 감쇠율.
- `0.25` = 25% 속도
- `0.0` = 커서 완전 정지

### wheel_threshold_deg

스크롤 반응 임계 기울기. 낮을수록 민감.

### wheel_step_max

스크롤 한 번에 최대 이동량.

### gesture.flick_deg

제스처 인식 최소 회전 속도. 낮으면 민감.

### gesture.cooldown_ms

제스처 인식 후 재인식까지 대기 시간.

### precision.deadzone

정밀 모드 진입 시 커서 무시 영역.

### precision.gain

정밀 모드 감도 (낮을수록 느림).

### led_brightness

LED 밝기 (0~255).

- 사용 안 할 땐 전원 OFF
- LED 밝기 낮춤
- 60초 자동 절전 신뢰

- Side F Hold 중엔 커서 25% 감쇠 → 정확한 스크롤
- 필요 시 `scroll_cursor_damp` 0.0으로 완전 정지
