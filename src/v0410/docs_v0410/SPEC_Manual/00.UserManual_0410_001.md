# Elite AirMouse S3 — v0410 사용자 매뉴얼

> ESP32-S3-Zero + MPU6050 기반 3-Mode Air Mouse
> BLE HID Composite (Mouse + Keyboard + Consumer) / WS2812 LED / Light-sleep
> **v0410: 다중 프로파일(최대 5개) × 8×8 매크로 라이브러리 × 2단 슬롯 매트릭스**

**문서 대상: 최종 사용자 (일반 사용자, 프레젠테이션 발표자, 게이머, TV 사용자)**
**소프트웨어 버전: v0410**

---

## 📌 30초 요약 (처음 사용자용)

1. **전원 켜기** → LED 파란색 점등 (Mode 1: PC 기본 모드)
2. **호스트에 페어링** → "Elite AirMouse S3" 검색 후 연결
3. **Top M (가운데 위 버튼) 누르고 있으면** → 에어마우스 포인팅 커서 이동
4. **Top L (왼쪽 위)** → 마우스 좌클릭 (누른 채 이동 시 드래그)
5. **Top R (오른쪽 위)** → 마우스 우클릭
6. **Side C 더블클릭 (측면 가운데)** → Mode 전환 (1: PC 🔵 → 2: PPT 🟢 → 3: TV 🟠)
7. **Side F 누르고 있으면** → 상하 틸트(스크롤) / 좌우 틸트(가로 팬)
8. **웹 UI 접속 (`http://192.168.4.1`)** → 프로파일(최대 5개), 슬롯 커스텀(27개), 매크로(8×8) 자유 설정!

## 🔋 처음 시작하기

### 1단계: 전원 켜기

- 측면 또는 하단의 전원 스위치를 ON
- LED가 파란색으로 켜짐 → Mode 1 (PC Air Mouse) 진입

### 2단계: 호스트에 페어링

**PC (Windows / macOS / Linux)**

1. PC의 Bluetooth 설정 열기
2. "Elite AirMouse S3" 검색
3. 페어링 클릭 → 자동 연결
4. LED가 파란색으로 안정화되면 완료

**스마트폰 / 태블릿 (Android / iOS)**

1. Bluetooth 설정 열기
2. "Elite AirMouse S3" 선택
3. 연결

**스마트 TV (Android TV / Tizen / webOS)**

1. 설정 → Bluetooth 입력 장치 → 추가
2. "Elite AirMouse S3" 선택
3. 연결 완료

> **팁:** 페어링이 안 되면 Side C를 **2초간 눌러** 페어링 모드로 진입하세요. LED가 1초에 1회 깜빡입니다.

### 3단계: 첫 사용

- **Top M (가운데 위) 을 누른 채** 손목을 움직임 → 커서 이동
- **Top M 을 놓으면** 커서 정지
- Top L 클릭 → 좌클릭
- Top R 클릭 → 우클릭

## 🎛️ 버튼 레이아웃

```
        [Top 면]
     [L] [M] [R]      ← 위쪽 3버튼
     
   ┌─────────────┐
[F]│             │
[C]│             │  ← 왼쪽 측면 (Front/Center/Rear)
[R]│             │
   └─────────────┘
```

| 약자 | 위치 | 주요 역할 |
|---|---|---|
| **Top L** | 위 왼쪽 | 좌클릭 / (드래그) |
| **Top M** | 위 가운데 | 커서 이동 게이트 (Hold) |
| **Top R** | 위 오른쪽 | 우클릭 |
| **Side F** | 측면 앞 | 스크롤 모드 (Hold) |
| **Side C** | 측면 가운데 | Mode 전환 / 페어링 |
| **Side R** | 측면 뒤 | 보조 기능 |

## 🖱️ Mode 1: PC Air Mouse

**PC 작업에 최적화된 기본 모드. LED: 파란색**

### 커서 이동

- **Top M 누른 채** 손목 움직임 → 커서 이동
- **Top M 놓음** → 커서 정지 (오작동 방지)

> **왜 버튼을 눌러야 하나요?** 책상에 내려놨을 때 커서가 저절로 움직이는 것을 방지하기 위함입니다.

### 버튼 조작 (기본값)

| 버튼 | 동작 |
|---|---|
| Top L 클릭 | 마우스 좌클릭 |
| Top L 길게 | 마우스 좌클릭 유지 (드래그) |
| Top L 더블클릭 | 마우스 더블클릭 |
| Top R 클릭 | 마우스 우클릭 |
| Top R 더블클릭 | ESC |
| Top R 길게 | 화면 캡처 (Win+Shift+S) |
| Top M 클릭 | 마우스 휠클릭 |
| Side F 클릭 | 볼륨 업 |
| Side F 길게 | 다음 트랙 |
| Side R 클릭 | 볼륨 다운 |
| Side R 길게 | 이전 트랙 |
| Side C 클릭 | 재생/일시정지 |

> ⚠ 위 조작은 **기본값**입니다. 웹 UI의 Slot Editor에서 자유롭게 변경 가능합니다.

### 스크롤 (Front Hold)

- **Side F 를 누른 채** 마우스 위/아래 기울임 → 페이지 스크롤
- **Side F 를 누른 채** 좌/우 기울임 → 가로 스크롤
- Side F 놓음 → 원래 커서 속도 복귀
- 스크롤 중엔 커서가 25% 속도로 느려짐 (미세 조정 가능)

### 제스처 (선택)

- **손목 좌/우 빠르게 회전** → 가상 데스크톱 전환 (Ctrl+Win+Left/Right)
- **손목 위로 빠르게** → Win+D (바탕화면 보기)
- **손목 아래로 빠르게** → Alt+Tab (작업 전환)

> **참고:** 상하 제스처는 Top M 을 놓은 상태에서만 동작합니다.

## 🎤 Mode 2: Presentation (프레젠테이션)

**파워포인트 / Keynote / Google Slides 발표용. LED: 초록색**

### 진입 방법

- **Side C 더블클릭** (Mode 1 → Mode 2)
- LED가 초록색 + 흰색 0.5초 깜빡임

### 슬라이드 조작 (기본값)

| 버튼 | 동작 |
|---|---|
| Top L 클릭 | 다음 슬라이드 (PageDown) |
| Top L 더블클릭 | 이전 슬라이드 (PageUp) |
| Top L 길게 | 현재 슬라이드부터 쇼 시작 (Shift+F5) |
| Side F 클릭 | 다음 슬라이드 |
| Side R 클릭 | 이전 슬라이드 |
| Side R 길게 | 쇼 종료 (ESC) |

### 포인터 / 레이저

- **Top M 누른 채** 움직임 → 포인터 이동
- **Top M 클릭** → 레이저 포인터 모드 (Ctrl+L)
- **Side C 클릭** → 펜 / 레이저 / 화살표 순환 (Ctrl+P → Ctrl+L → Ctrl+A)

### 화면 제어

| 버튼 | 동작 |
|---|---|
| Top R 클릭 | ESC (발표 종료) |
| Top R 더블클릭 | B (블랙아웃 토글) |
| Top R 길게 | W (화이트아웃 토글) |

### 제스처

- **손목 좌 회전** → 다음 슬라이드
- **손목 우 회전** → 이전 슬라이드
- **손목 위로** → B (블랙아웃)

## 📺 Mode 3: Smart TV Remote

**TV 리모컨 대체용. LED: 주황색**

### 진입 방법

- **Side C 더블클릭** (Mode 2 → Mode 3)
- LED가 주황색 + 흰색 0.5초 깜빡임

### TV 조작 (기본값)

| 버튼 | 동작 |
|---|---|
| Top L 클릭 | 뒤로가기 (AC Back / Android Back) |
| Top L 더블클릭 | 홈 (Home) |
| Top L 길게 | 전원 (Power) |
| Top M 클릭 | 확인 (Enter) |
| Top R 클릭 | 홈 (Home) |
| Top R 더블클릭 | 입력 소스 (TV Input) |
| Top R 길게 | 전원 끄기 (Power Off) |
| Side F 클릭 | 볼륨 업 |
| Side F 길게 | 채널 업 |
| Side R 클릭 | 볼륨 다운 |
| Side R 길게 | 채널 다운 |
| Side C 클릭 | 재생/일시정지 |

### 4방향 키 (Navigation Pad) (Tilt Hold, Mode 3 전용)

- **Top M 을 놓은 상태**에서 마우스를 **위/아래/좌/우로 기울여 유지**
- 15° 이상 기울임 + 300ms 유지 → 방향키 자동 반복 입력 (3Hz)
- 중립 복귀 → 정지

> **왜 Mode 3에서만?** PC/PPT에서는 손목을 자연스럽게 기울이는 상황이 많아 오작동 위험이 큽니다. TV의 4방향 키 대체 용도에만 활성화했습니다.

### TV 브라우저 / 넷플릭스 등

- **Top M 누른 채** 움직임 → 커서 이동
- Top M 놓으면 → 4방향 키 모드 복귀

### 제스처

- **손목 좌 회전** → 10초 되감기 (Rewind)
- **손목 우 회전** → 10초 빨리감기 (Fast Forward)
- **손목 위로** → 음소거 (Mute)

- **Side C 더블클릭** → Mode 1 → 2 → 3 → 1 순환
- LED 색상: 파랑 → 초록 → 주황 → 파랑

| LED 색 | Mode |
|---|---|
| 🔵 파랑 | Mode 1 (PC) |
| 🟢 초록 | Mode 2 (Presentation) |
| 🟠 주황 | Mode 3 (Smart TV) |
| ⚪ 흰색 | 액션 실행 중 (flash) |
| 🔴 빨강 | 경고 / 슬립 진입 |
| 💡 1Hz 깜빡임 | 페어링 대기 |

3. LED가 흰색 0.5초 깜빡임
4. 자동으로 다른 저장된 기기로 재연결 시도

다음 4개는 **브릭 방지**를 위해 수정 차단:

잠금 트리거는 UI에서 🔒 표시되며 편집 불가 (회색 처리).

### 3.4 Global vs Mode Override (2단 매트릭스)

Slot Editor는 **4개 뷰**가 있습니다:

```
[Global]  [Mode 1·PC]  [Mode 2·PPT]  [Mode 3·TV]
```

| 뷰 | 의미 |
|---|---|
| **Global** | 모든 Mode에 공통으로 적용될 **기본값** |
| **Mode 1·PC** | PC Mode에서만 다른 값 (**오버라이드**) |
| **Mode 2·PPT** | PPT Mode에서만 다른 값 |
| **Mode 3·TV** | TV Mode에서만 다른 값 |

#### 🔄 뱃지 클릭으로 상속 ↔ 오버라이드 전환

각 트리거 옆에 뱃지가 있습니다:

- **[G]** (파란색) = Global 기본값 상속 중
- **[M1/M2/M3]** (주황색) = 이 Mode 전용 오버라이드

**Mode 뷰에서** [G] 뱃지를 클릭하면 → **[M2]** 로 변경 (오버라이드 생성)  
**[M2]** 뱃지를 클릭하면 → **[G]** 로 되돌림 (Global 상속)

#### 실전 예시

**목표**: Flick Left를 평소엔 "가상 데스크톱 좌측"로, PPT 발표 중엔 "이전 슬라이드"로 만들기

1. **Global 뷰**에서 `F1 (Flick Left)` → `KB_COMBO` (Ctrl+Win+Left)
2. **Mode 2·PPT 뷰** 클릭
3. `F1` 옆 [G] 뱃지 클릭 → [M2] 로 전환
4. 액션 드롭다운에서 `KB_TAP PageUp` 선택
5. 상단 **저장** 클릭

**결과**: Mode 1/TV에서는 데스크톱 전환, Mode 2에서는 슬라이드 이전

### 3.5 Action Kind — 10가지 액션 종류

드롭다운의 **Action Kind**를 선택하면 파라미터 입력 필드가 나타납니다.

#### 🖱 1. `NONE` — 동작 없음

사용 안 함. 트리거를 비활성화하고 싶을 때.

#### 🖱 2. `MOUSE_CLICK` — 마우스 버튼 1회 클릭

**파라미터**: `mask` (버튼 선택)

| mask | 버튼 |
|---|---|
| 1 | 좌 |
| 2 | 우 |
| 4 | 휠(중간) |
| 8 | 뒤로가기 |
| 16 | 앞으로가기 |

**예시**: S3 (Top L Long) → `MOUSE_CLICK` mask=4 → Top L 길게 누르면 휠클릭

#### 🖱 3. `MOUSE_HOLD` — 마우스 버튼 누름 유지

**파라미터**: `mask` (동일)

**예시**: S5 (Top M Hold) → `MOUSE_HOLD` mask=1 → Top M 누른 채 이동 = 드래그

#### 🖱 4. `MOUSE_WHEEL` — 마우스 휠 스크롤

**파라미터**: `axis` / `dir`

- `axis`: Y (수직) / X (수평 팬)
- `dir`: Up/Left / Down/Right

**예시**: S15 (Side R Long) → `MOUSE_WHEEL` Y/Down → 페이지 아래로 스크롤

#### ⌨ 5. `KB_TAP` — 키보드 키 1회 입력

**파라미터**: 
- `modifier`: L_CTRL / L_SHIFT / L_ALT / L_GUI 등 (선택)
- `usage`: 키 이름 (드롭다운)

**키 드롭다운 그룹**:
```
없음 / 알파벳 (A~Z) / 숫자 (1~0) / 기본 키 (Enter/Esc/Tab) /
펑션 키 (F1~F12) / 네비게이션 (PageUp/PageDown/↑↓←→) / 기타
```

**예시**: 
- S8 → `KB_TAP` mod=None, usage=Esc → Top R 길게 누르면 ESC
- S7 → `KB_TAP` mod=L_ALT, usage=Tab → Top R 더블클릭 = Alt+Tab

#### ⌨ 6. `KB_COMBO` — 키보드 단축키 (여러 키 동시)

**파라미터**: 
- `modifier`: 하나 이상 조합
- `u1`, `u2`, `u3`: 최대 3개 키

**예시**:
| 목표 | mod | u1 | u2 |
|---|---|---|---|
| Ctrl+C | L_CTRL | C | – |
| Ctrl+Shift+T | L_CTRL + L_SHIFT | T | – |
| Win+Shift+S | L_GUI + L_SHIFT | S | – |
| Ctrl+Alt+Del | L_CTRL + L_ALT | Del | – |
| Ctrl+Win+Left | L_CTRL + L_GUI | Left | – |

> 💡 **KB_TAP과의 차이**: KB_TAP은 modifier 1개 + 키 1개. KB_COMBO는 modifier 여러 개 조합 + 키 3개까지.

#### ⌨ 7. `KB_REPEAT` — 키 누른 채 반복

**파라미터**: KB_TAP과 동일

**동작**: 누르고 있으면 100ms 주기로 반복 입력 (10Hz)

**예시**: S13에서 → `KB_REPEAT` → 키 누른 채 계속 입력

#### 🔊 8. `CONSUMER_TAP` — 미디어 키 1회

**파라미터**: `mask32` (드롭다운)

**종류**:
| 이름 | 기능 |
|---|---|
| VOL_UP | 볼륨 업 |
| VOL_DOWN | 볼륨 다운 |
| MUTE | 음소거 |
| PLAY_PAUSE | 재생/일시정지 |
| NEXT_TRACK | 다음 트랙 |
| PREV_TRACK | 이전 트랙 |
| FF | 빨리감기 |
| REWIND | 되감기 |
| POWER | 전원 |
| AC_HOME | 홈 |
| AC_BACK | 뒤로가기 |
| TV_INPUT | 입력 소스 |
| CH_UP / CH_DOWN | 채널 |

**예시**: S9 (Side F Click) → `CONSUMER_TAP VOL_UP` → 볼륨 업

#### 🔊 9. `CONSUMER_REPEAT` — 미디어 키 반복

동일 mask, 누르고 있으면 반복.

#### ⚙ 10. `SPECIAL` — 펌웨어 내부 기능

**파라미터**: Special ID (드롭다운)

| 이름 | 기능 |
|---|---|
| GYRO_RECALIB | 자이로 재캘리브 |
| SLEEP_NOW | 즉시 슬립 |
| MODE_CYCLE | Mode 순환 |
| PAIRING | 페어링 모드 |
| HOST_CYCLE | 호스트 순환 |

**예시**: S15 (Side R Long) → `SPECIAL GYRO_RECALIB` → 자이로 재캘리브

#### 🎬 11. `MACRO` — 매크로 실행

**파라미터**: 매크로 인덱스 (0~7, 드롭다운)

자세한 내용은 §4 Macro Editor 참조.

### 3.6 Live Test

각 슬롯 우측의 **Test** 버튼:
1. 클릭 → confirm 창
2. BLE 연결 상태면 즉시 실행
3. 슬롯 저장 전에도 테스트 가능 (단, 화면엔 저장 안 됨)

### 3.7 저장

- **저장** 버튼: 현재 편집 내용을 기기 플래시에 영구 저장
- **재로드**: 저장 안 한 편집 내용 폐기, 현재 저장된 값 복원
- 저장 안 하면 재부팅 시 사라짐

## 🎬 4. Macros 탭 — Macro Editor 상세 가이드

### 4.1 매크로(Macro)란?

**"매크로"** = 여러 액션을 순서대로 실행하는 **시퀀스**입니다.

예를 들어 "Ctrl+C → 100ms 대기 → Ctrl+V"를 하나의 버튼에 할당할 수 있습니다.

### 4.2 제약 사항

- 프로파일당 **최대 8개 매크로**
- 매크로당 **최대 8개 Step**
- 각 Step의 delay: **0~2000ms**
- ⚠ 매크로 안에 **매크로(MACRO)** 또는 **SPECIAL** 넣을 수 없음 (중첩 금지)

### 4.3 편집 방법

#### 화면 구성

```
┌──────────────────┬────────────────────────────┐
│ 매크로 목록       │ 매크로 편집기               │
│                  │                             │
│ [0] TaskMgr  3s  │ [이름: TaskMgr]  [Test][삭제] │
│ [1] CopyPaste 4s │                             │
│ [2] Screenshot   │ Step 1: [KB_COMBO ▼] [LCtrl][LSHift] [Esc] │
│                  │         delay: [0] ms        │
│                  │         [▲] [▼] [✕]         │
│                  │                             │
│                  │ Step 2: [KB_TAP ▼] [None] [Enter] │
│                  │         delay: [50] ms       │
│                  │                             │
│                  │ [+ Step 추가]                │
│                  │ 2 / 8 step                   │
└──────────────────┴────────────────────────────┘
```

#### 편집 절차

1. **`+ 새 매크로`** 클릭 → 이름 입력 (최대 15자)
2. 좌측 목록에서 매크로 선택
3. **`+ Step 추가`** 로 액션 추가 (기본값: `KB_TAP A`)
4. 각 Step에서:
   - Kind 선택 (KB_TAP / KB_COMBO / MOUSE / CONSUMER 등)
   - 파라미터 입력 (드롭다운으로 선택)
   - delay 입력 (0~2000ms)
5. **`▲` `▼`** 로 순서 변경, **`✕`** 로 삭제
6. **`저장`** 클릭 → 플래시 저장

#### 매크로 실행 Test

- 매크로 편집기 우측 상단 **Test** 버튼
- 저장 후 자동으로 기기에서 즉시 실행
- 실제 동작 확인 후 슬롯에 할당

### 4.4 매크로 슬롯 할당

1. **Slots 탭**으로 이동
2. 원하는 트리거 선택 (예: S10 Side F Long)
3. Action Kind 드롭다운 → **MACRO** 선택
4. 옆에 나타나는 드롭다운 → 매크로 인덱스 선택 (예: `0: TaskMgr`)
5. **저장** 클릭

**결과**: Side F 길게 누르면 TaskMgr 매크로 실행

### 4.5 실전 매크로 예시 7가지

## 📊 5. Config 탭 (E10 하드웨어 파라미터)

- **DPI Level (1~3)**: 기본 커서 속도 단계
- **Hard Click Lock**: 클릭 시 손떨림 방지
- **LED Brightness (0~255)**: LED 밝기
- **Accel Threshold & Gain**: 빠른 스윙 시 가속 곡선
- **Scroll Cursor Damp (0~1)**: Side F 스크롤 중 커서 감쇠율 (기본 0.25)
- **Wheel Threshold**: 휠 스크롤 발생 틸트 각도
- **Gesture Flick**: 제스처 인식 감도
- **Export / Import**: 프로파일 JSON 백업 / 복원

> **Rollback (폐기)**: v0410에서는 프로파일 스위치 또는 Factory Reset으로 대체되었습니다.

## 🔧 자주 발생하는 문제

### 커서가 안 움직임

- **원인 1**: Top M 을 안 누름 → Top M 누른 채 움직이기
- **원인 2**: BLE 끊김 → Dashboard에서 `BLE: OFF` 확인, Side C 2초
- **원인 3**: 자이로 캘리브 실패 → 평평한 곳에 놓고 "자이로 캘리브"

### 버튼이 눌린 채로 멈춤 (stuck)

- **원인**: BLE 신호 끊김, 배터리 부족
- **해결**: 웹 UI → Dashboard → **강제 릴리즈**

### 스크롤이 너무 빠름 / 느림

- Config 탭 → `wheel_threshold_deg` 조정 (60~120)

### 스크롤 중 커서가 같이 움직임

- Config 탭 → `scroll_cursor_damp` 낮춤 (0.25 → 0.1)

### 정지 상태에서 커서가 떨림

- Dashboard → **자이로 캘리브** 실행
- 또는 Config 탭 → **Precision Mode** `MED`

### 제스처가 오작동

- Config 탭 → `flick.p2p_th` 상향 (400 → 600)

### 매크로가 실행 안 됨

- **확인 1**: 매크로 저장됨? (Macros 탭 우측 상단 "저장")
- **확인 2**: 슬롯에 할당됨? (Slots 탭 → Kind=MACRO 선택 여부)
- **확인 3**: BLE 연결? (Dashboard `BLE: ON`)
- **확인 4**: 매크로 step 8개 넘지 않았나?

### 특정 트리거가 편집 안 됨

- 🔒 표시된 트리거(S1, S5, S12, S13)는 편집 불가
- Mode 1/2 뷰의 Tilt 그룹도 편집 불가 (Mode 3 전용)

### Mode 1/2에서 Tilt가 발동 안 됨

- 정상 동작. Tilt는 **Mode 3 (TV)** 에서만 발동

### SafeBoot 모드 진입

**증상**: 웹 UI 접속 시 "-SAFE" 붙은 AP, HID 안 됨

**원인**: 이전 부팅이 2회 연속 비정상

**해결**:
1. 웹 UI 접속
2. Dashboard → **SafeBoot 해제 (재부팅)**
3. 또는 Factory Reset

### Factory Reset 방법

- 웹 UI: Dashboard → Factory Reset → 확인

**결과**: 모든 설정/프로파일 초기화 후 재부팅

가속 시작 임계 (8.0 m/s²)

제스처 재인식 대기 시간 (600ms)

### precision.deadzone
정밀 모드 커서 무시 영역 (1.2)

### precision.gain
정밀 모드 감도 (0.65, 낮을수록 느림)

LED 밝기 (128)

## 🎓 팁 & 요령

### 커서 미세 조정

- DPI를 1로 낮춤
- Precision Mode 활성화 (MED)
- Zero Snap 자동 작동

### 빠른 커서 이동

- DPI 3 + 큰 손목 동작 (Sigmoid 가속)

### 커서와 클릭 분리

- Top M 놓고 → Top L 클릭 (정확한 클릭)

### 배터리 절약

- 사용 안 할 땐 전원 OFF
- LED 밝기 낮춤
- 60초 자동 절전 신뢰

### 프로파일 관리

- 업무용 / 게임용 / 발표용을 별도 프로파일로
- 드롭다운 한 번으로 전환

### 매크로 팁

- delay는 **충분히** (100~500ms): 너무 짧으면 대상 앱이 못 따라감
- 8 step 제약 → 긴 시퀀스는 여러 매크로 + 슬롯에 나눠 할당
- Test 버튼으로 먼저 검증
