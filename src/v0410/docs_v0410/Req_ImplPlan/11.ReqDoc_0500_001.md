# Elite AirMouse S3 기능적 관점 보완 사항
 * 분석 개요
   * 목적: 전문 프레젠터 및 상용 에어마우스 대비 도출된 순수 기능적 결함을 보완하기 위한 엔지니어링 과제 도출
   * 핵심 방향: 하드웨어 추가 최소화, 펌웨어 알고리즘 개선, ESP32-S3 무선 역량 극대화, 물리적 촉각/시각 인터페이스 강화
## 1. 프레젠테이션 전용 기능 보완
 * 타이머 기반 무음 진동(ERM/LRA) 햅틱 알림 시스템 탑재
   * 소형 동전형 진동 모터(ERM) 또는 선형 공진 액추에이터(LRA) 하드웨어 추가
   * 웹 UI 내 발표 시간 설정 항목 신설 (예: 발표 총 시간 15분, 20분 지정)
   * 마일스톤 진동 피드백: 종료 5분 전(단발 진동), 종료 1분 전(2회 진동), 종료 시점(길게 1회 진동)
   * 조작 촉각 피드백: 모드 전환(Side C 더블클릭) 및 매크로 실행 시 LED 시선 분산 없이 손끝 진동으로 성공 여부 인지
 * 소프트웨어 기반 화면 강조 도구(스포트라이트/확대경) 우회 구현
   * 문제점: 호스트 드라이버 미설치 원칙 하에서 OS 화면을 어둡게 하는 그래픽 오버레이 자체 생성 불가
   * 펌웨어 레벨 해결책:
     * OS 접근성(Ease of Access) 표준 단축키 매핑 자동화:
       * Windows 돋보기 실행: Win + + (확대), Win + Esc (해제)
       * Mac 화면 확대 단축키 연동
     * 웹 기반 경량 런처(Zero-Install Web Presenter Tool) 제공:
       * 기기 내 웹서버([http://192.168.4.1/presenter](http://192.168.4.1/presenter))에 캔버스 기반 투명 스포트라이트/타이머 웹앱 내장
       * 호스트 브라우저에서 전체화면(F11)으로 띄워 로지텍 수준의 가상 하이라이트 원형 빔 구현
 * 하드웨어 물리 레이저 다이오드 모듈 옵션화
   * 본체 전면에 3.3V 구동 532nm 그린 또는 650nm 레드 레이저 다이오드 실장 패드 배치
   * Mode 2(발표 모드)에서 상단 특정 버튼(Top M 클릭 또는 별도 핀)으로 구동 가능한 전원 스위칭 회로(MOSFET) 연동
## 2. 연결성 및 호환성(Plug & Play) 보완
 * ESP-NOW 기반 무설치 2.4GHz 전용 USB 동글 구성
   * 호스트 PC의 블루투스 비활성화 환경 및 관공서/폐쇄망 보안 정책 극복
   * 구성 방식: 초소형 수신기(ESP32-C3 또는 ESP32-S2 USB 동글)를 호스트에 장착
   * 통신 프로토콜: BLE 대신 ESP-NOW 독자 2.4GHz RF 프로토콜로 수신기와 1ms 단위 초저지연 통신
   * 수신기 역할: 수신받은 좌표 및 키 데이터를 표준 USB Composite HID(Mouse+KB) 유선 신호로 변환하여 호스트에 즉각 전달
   * 동작 모드: 동글 삽입 시 즉각 연결(Zero Pairing), 동글 부재 시 기존 BLE HID로 자동 전환(Fallback)
## 3. 포인팅 정밀도 및 모션 알고리즘 고도화
 * 손떨림 억제 및 클릭 순간 락(Click-Freeze) 알고리즘 강화
   * 문제점: 공중에서 버튼을 딸깍 누르는 순간의 물리적 압력으로 커서가 3~10픽셀 튀어 목표 클릭 실패
   * 보완 알고리즘:
     * 클릭 이벤트 발생 시점 기준 전후 50~80ms 동안 커서 좌표 출력을 강제 동결(Freeze)
     * 버튼을 떼는 시점(Release)에서도 추가 30ms 지연 후 좌표 복귀
 * 동적 데드존(Adaptive Deadzone) 및 가변 이동평균 필터(EMA)
   * 미세 손떨림 영역: 자이로 각속도 \omega < \text{Threshold} 구간에서 지수이동평균(EMA) 가중치를 높여 미세 떨림 완전 소거
   * 고속 회전 영역: 빠른 손목 스냅 시 필터를 우회하여 지연(Latency) 없는 즉각 추종
 * 발표 전용 직선 모드(Snap-to-Axis) 추가
   * 슬라이드 내 텍스트나 도표를 가리킬 때 수평/수직 축에서 일정 범위 내 이탈 시 수평선을 강제 유지하는 스냅 기능(Mode 2 전용) 제공
## 4. 사용자 인지 부하 감소 및 조작 안전성 보완
 * 모드별 조작 단순화 락(Presentation Simple Lock)
   * 발표 모드(Mode 2) 진입 시 제스처(Flick/Linear) 및 복합 매크로 기능을 강제로 비활성화하는 단순 모드 토글 지원
   * 오직 '다음 슬라이드', '이전 슬라이드', '포인터 게이트'의 3개 동작만 허용하여 긴장된 발표 현장에서의 조작 실수(모드 이탈, 원치 않는 단축키 입력) 원천 차단
 * 상태 알림 인터페이스 직관화
   * 단일 RGB LED의 색상/점멸 패턴에 의존하던 체계를 보완
   * 0.42인치 또는 0.91인치 초소형 I2C OLED/전자종이(E-paper) 디스플레이 실장 검토:
     * 현재 모드 명칭(PC / PPT / TV) 텍스트 표시
     * 배터리 잔량 백분율(%) 표시
     * 발표 타이머 남은 시간 카운트다운 표시
## 5. 기능 보완 구현 로드맵 요약
 * 1단계: 펌웨어 개선만으로 즉시 적용 가능한 과제
   * 클릭 순간 좌표 동결(Click-Freeze) 알고리즘 고도화
   * Mode 2 전용 단순 조작 모드(Simple Lock) 및 OS 돋보기 표준 키 매핑 추가
   * 웹 기반 스포트라이트 런처 HTML 기기 내 내장
 * 2단계: 하드웨어 마이너 리비전(v0420) 과제
   * 무음 진동 모터(ERM/LRA) 실장 및 타이머 햅틱 알림 기능 추가
   * 물리 레이저 다이오드 제어 핀 배치
 * 3단계: 시스템 에코시스템 확장 과제
   * ESP-NOW 기반 무설치 USB 리시버 동글 펌웨어 개발
   * 상태 확인용 초소형 OLED 디스플레이 모듈 일체화 설계
