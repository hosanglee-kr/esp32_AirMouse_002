논리적 오류 효율적 점검 방법론

대규모 임베디드 펌웨어(12+ 백엔드 모듈, 5 태스크, 7 프론트 모듈)를 체계적이고 반복 가능하게 점검하는 프레임워크입니다.

---

📋 개요: 3단계 접근법

```
[1단계] 자동 분석 (도구)     ← 즉시 실행, 기계적 오류 90% 발견
    ↓
[2단계] 패턴 검색 (grep)     ← 수동, 알려진 함정 패턴
    ↓
[3단계] 카테고리별 리뷰      ← 수동, 논리적/아키텍처 오류
    ↓
[4단계] 회귀 방지 (자동화)   ← 지속, 재발 방지
```

소요: 1단계 1~2일, 2단계 반나절, 3단계 2~3일, 4단계 지속

    -Wundef                     ; 미정의 매크로

    -Wswitch-enum               ; enum case 누락
    -Woverloaded-virtual

1.2. cppcheck — 정적 분석

설치:

```bash
# Windows: choco install cppcheck
# macOS: brew install cppcheck
# Linux: apt install cppcheck
```

실행:

```bash
cppcheck --enable=all \
         --inconclusive \
         --std=c++17 \
         --platform=unix32 \
         --suppress=missingIncludeSystem \
         --inline-suppr \
         --template="{file}:{line}: [{severity}] {id}: {message}" \
         --output-file=cppcheck.log \
         src/
```

주요 탐지 항목:

카테고리 예시
arrayIndexOutOfBounds 배열 범위 초과
uninitvar 미초기화 변수
nullPointer 널 포인터 역참조
memleak 메모리 누수
unusedVariable 미사용 변수
knownConditionTrueFalse 항상 참/거짓 조건
duplicateCondition 중복 조건
invalidPointerCast 잘못된 포인터 캐스트
shiftTooManyBits 시프트 오류
redundantAssignment 불필요한 대입

1.4. PVS-Studio (선택, 무료 for OSS)

임베디드에서 강력. 특히 V550 (부동소수 비교), V547 (항상 참 조건) 유용.

1.5. sanitizers (호스트 시뮬레이션)

로직 시뮬레이터를 호스트 PC에서 컴파일 후 실행:

```bash
g++ -std=c++17 -fsanitize=address,undefined \
    -fno-omit-frame-pointer -g \
    sim_main.cpp -o sim && ./sim
```

탐지: 메모리 오류, UB, 데이터 레이스 (TSan).

🔍 2단계: 패턴 검색 (grep) — 30분

알려진 함정 패턴을 코드베이스 전체에서 검색.

2.1. 시간 관련 오류 (최우선)

millis() wrap-around:

```bash
# 위험: signed 비교
grep -rn "millis()" src/v0410/ | grep -v "uint32_t\|int32_t\|int64_t"

# 위험: 직접 비교 (wrap 시 오류)
grep -rn "if.*millis()\s*[<>]" src/v0410/

# 안전 패턴: (now - start) < timeout  → 확인
grep -rn "(uint32_t)millis() - " src/v0410/
```

주의:

```cpp
// 위험 (wrap 시 오류)
if (millis() > lastMs + timeout) { ... }

// 안전
if ((uint32_t)(millis() - lastMs) > timeout) { ... }
```

2.2. 문자열 안전성

```bash
# 위험 함수
grep -rn "strcpy\|sprintf\|strcat\|gets\|scanf" src/v0410/

# 안전 함수 확인
grep -rn "strlcpy\|strlcat\|snprintf" src/v0410/ | wc -l
```

2.3. 동적 할당

```bash
grep -rn "malloc\|calloc\|realloc\|free\|new \|delete" src/v0410/
```

ESP32 임베디드에서는 동적 할당 최소화 원칙.

2.4. 큐 반환값 무시

```bash
# xQueueSend 결과 무시
grep -rn "xQueueSend\|xQueueReceive\|xSemaphoreTake" src/v0410/ | grep -v "==\|!=\|if\|return"
```

2.5. 상태 변수 접근 (락 없이)

```bash
# 공유 상태 변경 지점
grep -rn "_state\." src/v0410/ | grep "=" | grep -v "_lock"
grep -rn "_cfgProfile\." src/v0410/ | grep "=" | grep -v "_lock\|Snapshot"
```

2.6. Switch break 누락

```bash
# default 없는 switch (Wswitch-default로 컴파일러가 잡음)
grep -rn "switch" src/v0410/*.cpp | head -50
```

2.7. volatile 누락

```bash
# ISR/태스크 간 공유 플래그
grep -rn "_req\|_flag\|_pending\|_active\|_busy" src/v0410/*.h | grep -v "volatile\|static"
```

2.8. 배열 인덱싱

```bash
# 상수 인덱스 접근
grep -rn "\[[0-9]\+\]" src/v0410/*.cpp | grep -v "//\|G_\|EN_"
```

2.9. = vs == 오타

```bash
grep -rn "if.*[^=!<>]=[^=]" src/v0410/ | grep -v "==\|!=\|<=\|>=\|+=\|-=\|*=\|/="
```

2.10. 초기화 순서

```bash
# 초기화 함수 호출 순서
grep -rn "\.begin(" src/v0410/ | sort
```

📊 3단계: 카테고리별 수동 리뷰 — 2~3일

3.1. 카테고리 1: 시간 기반 로직 (최우선)

점검 항목:

항목 확인 방법
millis() wrap (49.7일) 모든 시간 비교에 (uint32_t)(now - start) 사용
micros() wrap (71분) 위와 동일
vTaskDelay(0) 무한 루프 방지
xTaskGetTickCount() tick 기반 계산
시간 기반 상태 전이 초기값, 리셋 조건

점검 스크립트:

```bash
# 시간 관련 함수 사용 지점 전수
grep -rn "millis\|micros\|vTaskDelay\|xTaskGetTickCount" src/v0410/ | \
    awk -F: '{print $1":"$2}' > time_points.txt
```

3.2. 카테고리 2: 동시성 (FreeRTOS)

점검 항목:

항목 확인 방법
태스크별 상태 소유권 SPEC §3.3 대조
락 순서 (데드락) _lock() 중첩 확인
큐 overflow xQueueSend timeout=0 시 drop 확인
volatile 태스크 간 공유 플래그
초기화 순서 태스크 생성 vs 큐 생성 순서

점검 매트릭스 (예시):

```
변수              | Reader      | Writer      | 보호
_state.x          | web, sensor | sensor      | _lock()
_qFrame           | comm        | sensor      | queue
_cfgProfile       | sensor,comm | web,sensor  | _lock()  ← 누락?
_macroAbortToken  | comm        | all         | volatile
_activeMode       | all         | sensor      | volatile
```

3.3. 카테고리 3: 상태 머신

점검 항목:

항목 확인 방법
도달 불가 상태 모든 상태 열거 + 전이 그래프
리셋 조건 Mode 전환, 에러 시
재진입 resetAll 후 재호출
초기 상태 ctor 초기값
종료 조건 FSM 루프 탈출

점검 방법 — 상태 전이표:

예: C20_BtnDispatcher phase FSM

```
From        | Event         | To          | Action
IDLE        | press(stable) | PRESSED     | DOWN emit
PRESSED     | release       | WAIT_CLICK  | UP emit
PRESSED     | long(800ms)   | PRESSED     | LONG emit
...
```

모든 전이가 명시되어야 논리 오류 없음.

3.4. 카테고리 4: 경계값

점검 항목:

항목 예시
배열 범위 arr[EN_C10_TRIG_MAX] ← off-by-one
부호 비교 uint8_t i; i >= 0 ← 항상 참
오버플로 uint16_t sum; sum += x
시프트 1 << 31 (signed overflow)
널 포인터 ptr->field
반올림 정수 나눗셈

점검 스크립트:

```bash
# 잠재적 경계 문제
grep -rn "<=.*MAX\|>=.*MIN\|== MAX" src/v0410/*.cpp
```

3.5. 카테고리 5: 리소스

점검 항목:

항목 확인
메모리 누수 new 대비 delete
File 핸들 open 대비 close
세마포어 take 대비 give
태스크 스택 uxTaskGetStackHighWaterMark
큐 크기 실제 사용량 추적

3.6. 카테고리 6: API 계약

점검 항목:

항목 확인
반환값 무시 xQueueSend(...) 결과
선행 조건 초기화 전 호출
후행 조건 반환 후 상태

📋 프로젝트 특화 점검 항목

이 프로젝트에서 자주 발생 가능한 5대 오류

# 오류 유형 실제 예 탐지 방법
1 큐 인큐 누락 _pushFrame() 안 함 grep _pushFrame 호출 위치
2 락 재진입 _lock 중 _lock recursive mutex 확인
3 millis() wrap if (now > last + 1000) grep 패턴
4 volatile 누락 태스크 간 플래그 태스크 매트릭스
5 초기화 순서 _qFrame 전 _pushFrame begin() 순서

커스텀 점검 스크립트

tools/audit.sh (신규):

```bash
#!/bin/bash
# v0410 자동 점검 스크립트

echo "=== 1. millis() wrap 위험 ==="
grep -rn "millis()" src/v0410/ | grep -v "(uint32_t)\|(int32_t)"

echo ""
echo "=== 2. xQueueSend 반환값 무시 ==="
grep -rn "xQueueSend" src/v0410/ | grep -v "if\|==\|!="

echo ""
echo "=== 3. unsafe string ==="
grep -rn "strcpy\|sprintf\|strcat" src/v0410/

echo ""
echo "=== 4. 직접 공유 상태 접근 (락 없이) ==="
grep -rn "_state\.[a-z_]* =" src/v0410/ | grep -v "_lock"

echo ""
echo "=== 5. volatile 누락 후보 ==="
grep -rn "volatile\|_req\|_pending\|_flag" src/v0410/*.h

echo ""
echo "=== 6. 배열 상수 인덱싱 ==="
grep -rn "\[[0-9]\+\]" src/v0410/*.cpp | grep -v "EN_\|G_\|//"

echo ""
echo "=== 7. switch without default ==="
grep -rn "switch" src/v0410/*.cpp | wc -l

echo ""
echo "=== 8. TODO/FIXME/HACK ==="
grep -rn "TODO\|FIXME\|HACK\|XXX\|BUG" src/v0410/

echo ""
echo "=== 9. 부동소수 == 비교 ==="
grep -rn "float.*==\|double.*==" src/v0410/

echo ""
echo "=== 10. 초기화 순서 (begin 호출) ==="
grep -rn "\.begin(" src/v0410/ | sort
```

실행:

./tools/audit.sh > audit_report.txt
